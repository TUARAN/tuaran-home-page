# 内容信息架构与新访客起点指标

更新日期：2026-07-31
状态：在用

## 决策

公开内容采用“一套用途层级 + 多组独立筛选维度”：

- 主层级：全部、精选、分析、实践、资源。
- `contentKind`：内容形态，必须且只能有一个。
- `subjects`：主题，必须有 1–3 个。
- `entityType`：研究对象，可选。
- `companyIndustry`：公司所属行业，仅公司内容可选。
- `companyRole`：公司在生态中的角色，仅公司内容可选。
- `delivery`：使用方式，必须且只能有一个。
- `series`：固定系列，可选。

分类定义与兼容映射的代码正本是 `lib/contentTaxonomy.js`。旧字段仍可用于内容加载和旧 URL
兼容，不能继续直接生成同级前台菜单。

## 分类治理

每个受控值需要具备：

- 稳定英文 ID；
- 面向读者的中文名称；
- 一句话定义；
- 包含与排除示例；
- 生效、合并或废弃状态；
- 旧名称与旧 URL 别名。

维护规则：

1. 中文名称可以调整，稳定 ID 不随文案变化。
2. “精选、热门、最新”属于编辑状态，不属于内容分类。
3. “公司、人物、产品、技术、行业”属于研究对象，不与主题并列。
4. 公司分类必须把行业和生态角色分开；旧 `company_type` 只用于兼容映射。
5. RSS、X、YouTube 属于来源渠道；国内、国外属于来源地区；二者都不能充当主题。
6. 新主题至少需要 5 条现有内容，或有 90 天内达到 8 条的明确计划。
7. 少于 3 条且连续 90 天没有增长的主题，应合并为更高层主题。
8. 不发布“其他”分类；无法归类的条目进入待治理队列。
9. 顶层用途控制在 5 个以内；主题控制在 7 个以内。
10. 内容新增或迁移后运行分类契约测试。

## 新访客定义

浏览器没有 `tuaran_first_seen_at` 时，当前会话标记为 `new`；后续新会话标记为
`returning`。这个定义用于匿名趋势分析，不用于跨设备用户识别。

## 有效起点

每个会话只记录一次 `qualified_start`。以下行为可以触发：

- 内容页前台活跃至少 30 秒，且滚动达到 50%；
- 搜索结果被打开；
- 工具开始使用；
- 资源被打开、下载、订阅或跳转到外部来源。

普通入口点击不直接算有效起点。它需要与后续有效行为组合，才能判断入口质量。

## 指标

### 主指标

`有效起点率 = new 会话中触发 qualified_start 的会话数 / new 会话数`

### 结果指标

- 首次价值耗时：`landing_view` 到 `qualified_start` 的
  `time_to_value_seconds` 中位数与 P75。
- 7 日回访率：首次观察后 7 日内再次访问的访客比例。

### 诊断指标

- 无有效行为退出率；
- 首页起点、主导航和目录入口的点击率；
- 入口点击后的有效起点转化率；
- 菜单打开后未点击率；
- 搜索结果点击率；
- 搜索零结果率；
- 不同落地页、来源和设备的有效起点率。

### 防误判约束

- 不用点击率单独代表成功。
- 搜索词原文不上报，只记录长度、结果数和是否零结果。
- 事件属性使用稳定 ID，不使用可能变化的中文菜单名称。
- 低流量时按四周滚动窗口判断，避免日级波动驱动改版。

## 事件

| 事件 | 作用 | 关键属性 |
|---|---|---|
| `landing_view` | 首次落地 | `landing_type`, `landing_path`, `visitor_stage` |
| `menu_open` | 主导航主动打开 | `destination_id` |
| `entry_click` | 入口选择 | `surface`, `destination_kind`, `destination_id` |
| `filter_apply` | 目录筛选 | `facet`, `value`, `result_count` |
| `search_submit` | 搜索提交 | `query_length`, `results_count`, `zero_results` |
| `search_result_click` | 搜索结果打开 | `destination_kind`, `position` |
| `content_engaged` | 有效阅读 | `active_seconds`, `scroll_percent`, `content_kind` |
| `resource_action` | 资源使用 | `action`, `delivery` |
| `qualified_start` | 会话首次有效起点 | `method`, `time_to_value_seconds` |

## 评审节奏

1. 上线后先收集 2–4 周基线，不用上线首周数据设硬目标。
2. 每月查看主指标、首次价值耗时、无效退出和 7 日回访。
3. 每季度抽取 30–50 个代表页面做卡片分类，并用真实任务做目录树测试。
4. 目录改版采用前后同口径对比；流量足够时再使用随机实验。

基线稳定后可以先使用以下内部方向性目标：

- 有效起点率提高 15%；
- 首次价值耗时中位数下降 20%；
- 无有效行为退出率下降 15%；
- 7 日回访率提高 10%。

这些数值用于判断改版方向，不作为外部行业基准。
