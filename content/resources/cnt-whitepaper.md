# 一、项目摘要

传统 Web2 内容平台存在核心痛点：平台垄断流量与收益、创作者变现低效、用户互动无偿、数据可篡改可删除、规则由中心化方随意更改。平台掌握所有价值分配权，用户与创作者的长期贡献无法沉淀为个人资产。

本项目基于 L2 底层公链搭建去中心化内容生态，构建「创作-互动-确权-流通-治理」全链路 Web3 内容基础设施。依托智能合约自动化执行规则，打造行为挖矿、链上确权、通缩销毁、持币分红、DAO 自治的闭环经济体系。

我们彻底解决传统内容挖矿项目三大致命问题：无限代币通胀、机器人批量刷量、代币无真实使用场景、挖抛循环崩盘，让内容价值链上沉淀、用户贡献可量化、生态价值与代币价值深度绑定，实现无人运维、合约永续运行的去中心化内容社区。

生态唯一原生权益代币：CNT（Content Token）

# 二、项目定位与技术架构

## 2.1 核心定位

新一代去中心化内容价值公链生态，以「内容贡献即价值、价值通证化、规则自动化、生态自治化」为核心，覆盖图文创作、社区互动、版权确权、内容分润、生态治理、权益解锁等全场景，打造完全由社区共建共享的 Web3 内容生态。

## 2.2 技术层级架构（精准定义 L1 / L2 / L3 / DApp）

- **L1 底层公链：** 以太坊主网，负责最终数据结算、资产安全兜底、核心合约最终确权，保障生态底层绝对安全。
- **L2 扩容运算层：** Arbitrum / Base 主流 L2，承接高频互动交易、降低 Gas 手续费、承载海量用户日常挖矿与交互行为，解决 L1 拥堵、高成本问题。
- **L3 应用专属链（AppChain）：** 定制化内容生态应用链，承载内容哈希存储、用户信誉数据、挖矿权重核算，实现生态规则专属化、高效化。
- **DApp 生态应用层：** 前端内容社区、创作工具、权益中心、DAO 治理界面、资产交易入口，面向普通用户的交互终端。

## 2.3 核心技术特性

- 内容原文存储于 IPFS 去中心化存储，链上存哈希、链下存原文，兼顾不可篡改性与合规可屏蔽性；
- 所有激励、销毁、分红、处罚逻辑 100% 由智能合约执行，无人为干预；
- 项目方停止运营不影响生态运行，合约永久存续、规则永久有效。

# 四、通胀根治体系：双因子动态衰减模型

彻底摒弃传统项目「固定产出、无限挖矿」的通胀死局，不做简单减半，采用生态联动双因子衰减机制，代币产出速度随生态壮大自动放缓，实现产出与价值增长动态平衡。

## 4.1 核心计算公式（合约固化）

当周可挖矿总量 = 上周剩余挖矿池额度 ×（1 - 基础衰减 5% - 生态活跃动态因子 0%~5%）

## 4.2 分阶段释放节奏

- **冷启动期（0-6 个月）：** 生态动态因子趋近于 0，衰减幅度最小，挖矿奖励丰厚，快速吸纳首批创作者与真实用户；
- **成长期（6-24 个月）：** 用户、内容量稳步增长，动态因子逐步拉高，每周代币产出持续递减；
- **成熟期（24 个月后）：** 生态规模稳定，衰减系数拉满，挖矿产出极低，生态核心收益切换为手续费分红、内容分润；
- **终局稳态（10 年期满）：** 社区挖矿池彻底耗尽，无新增代币产出，生态完全进入通缩循环。

# 五、行为挖矿体系：质量加权机制（杜绝无脑刷量）

摒弃「点击即挖矿、动作即发币」的漏洞模式，采用先算贡献分（CP）、每周统一结算、信誉权重加权的挖矿逻辑，只奖励真实、高质量内容互动，从机制层面过滤无效刷量。

## 5.1 核心行为贡献分规则

| 用户行为 | 基础贡献分 | 加权加成规则 |
| --- | ---: | --- |
| 原创内容发帖 | +10 | 收藏、转发、精选可叠加加分 |
| 有效深度阅读（阅读进度 ≥80%） | +0.5 | 停留时长 ≥3 分钟分数翻倍，单账号单帖每日限 1 次 |
| 有效短评（字数 ≥10 字） | +1 | 被作者回复、点赞额外加分 |
| 深度评论（字数 ≥50 字） | +5 | 多人点赞入选精选，分数 ×3 |
| 评论被作者设为精华 | +20 | 单次最高互动奖励，无叠加上限 |
| 有效举报（机器人 / 灌水判定成立） | +15 | 恶意误举报倒扣 10 分，累计多次封禁挖矿权限 |
| 连续每日活跃签到 | +0.1 / 天 | 每日分数封顶 1 分，杜绝签到刷分 |

## 5.2 挖矿结算核心规则

每日统计用户贡献分，每周统一汇总，按照「用户个人总分 / 全生态总分」的比例，瓜分当周可释放 CNT 额度，彻底杜绝单一动作刷币、批量账号薅羊毛的漏洞。

挖矿最终收益 = 基础贡献分 ×（信誉分 / 100）

# 六、四层反女巫 / 反机器人体系（彻底解决刷量漏洞）

单一风控无法抵御脚本攻击，本生态搭建资金门槛 + 行为风控 + 信誉权重 + DAO 审判四层防御体系，将机器人攻击成本拉高至无利可图。

## 6.1 资金质押门槛层

所有账号需质押 50 枚 CNT 方可开启挖矿权益，账号被判定为灌水、机器人刷量，质押金直接罚没。机器人批量注册账号需承担巨额本金成本，从源头遏制批量薅羊毛。

## 6.2 AI 行为风控层

链下 AI 节点实时识别异常行为：同 IP 批量操作、固定间隔滑动、极速评论、无逻辑灌水内容，可疑账号直接降低挖矿权重，严重者暂停挖矿权限。

## 6.3 信誉分权重层（核心壁垒）

生态设立独立不可转让信誉分（0-100 分），仅由用户长期真实行为积累，无法购买、无法转移。挖矿最终收益 = 基础贡献分 ×（信誉分 / 100）。新账号初始信誉分仅 10 分，挖矿收益极低；机器人无法长期养号积累信誉，自然淘汰。违规账号直接清零信誉分，永久失去挖矿权益。

## 6.4 DAO 社区审判层

用户可举报恶意刷量、灌水账号，由持币社区 24 小时投票裁定，判定违规后罚没质押金，80% 销毁、20% 奖励举报人，形成社区自治风控闭环。

# 七、代币价值闭环：销毁 + 分红 + 刚需场景（终结挖抛循环）

彻底解决「代币无用途、挖到即砸盘」的行业通病，搭建持续通缩销毁 + 被动持币分红 + 生态刚需消耗三维价值支撑，让用户愿意持有、长期锁仓，而非短期抛售。

## 7.1 通缩销毁场景（持续减少流通量）

| 生态场景 | 销毁规则 |
| --- | --- |
| 内容置顶、作品推广 | 消耗 CNT 100% 销毁 |
| 付费内容解锁、专栏订阅 | 50% 销毁，50% 分配给原创作者 |
| 创作者付费专栏开通认证 | 质押消耗 CNT 全额销毁 |
| 机器人、违规账号罚没质押金 | 80% 销毁，20% 奖励举报用户 |

## 7.2 持币分红场景（核心持币动力）

生态内所有付费行为（付费阅读、专栏订阅、内容推广、版权分润）产生的平台手续费，100% 按用户持币比例每周自动空投分红。无需锁仓、无需质押，快照持币即可享受收益。

核心价值：让 CNT 成为生态「股权凭证」，持有即享受生态长期收益，彻底改变用户「挖到就卖」的短期行为，催生长期持币需求。

## 7.3 生态刚需使用场景（绝对价值支撑）

- **权益刚需：** 解锁优质付费内容、创作者专属社群、高阶创作工具；
- **身份刚需：** 创作者官方认证、专栏开通、优质作品流量扶持；
- **治理刚需：** 持有并锁仓 CNT 可参与 DAO 投票，决定生态规则、挖矿参数、处罚机制、财库资金使用；
- **版权刚需：** 链上内容确权、转载分润、作品维权，仅 CNT 持有者可开通。

# 八、DAO 去中心化治理体系（无人运维永续运行）

## 8.1 提案门槛

用户持有 ≥10000 枚 CNT 且锁仓 30 天，可发起生态治理提案，涵盖挖矿参数调整、销毁比例修改、违规处罚规则、财库资金使用、生态激励方案等。

## 8.2 投票权重

投票权重 = 持仓数量 × 锁仓时长系数，最长锁仓 1 年权重翻倍，杜绝巨鲸短期控盘，鼓励长期价值持有。

## 8.3 执行机制

提案投票通过后，由社区多签钱包（7 选 4）执行，无中心化团队干预。核心底层规则（代币总量、团队解锁周期）永久固化合约，不可通过治理修改，保障生态根基稳定。

# 附录 智能合约模块清单

适配前面白皮书，基于 ERC-20 + L2（Arbitrum / Base）。合约之间采用权限隔离、事件驱动，核心参数硬编码或多签管控；所有挖矿、销毁、分红、治理逻辑上链。

分类：基础层、代币经济层、挖矿贡献层、风控身份层、业务场景层、DAO 治理层、工具与审计辅助层。

## 基础底层合约

1. **CNTToken.sol（ERC-20 主代币合约）**
    - ERC-20 标准 + 扩展：销毁接口、授权、批量转账、快照接口
    - 硬编码最大总供应量，禁止增发
    - 权限：多签管理员，仅可暂停（紧急开关，审计后可考虑移除暂停权）
    - 事件：Transfer、Approval、Burn、Mint（仅挖矿池合约有权 mint）
2. **Timelock.sol 时间锁合约**
    - 所有治理提案执行前置时间锁，防闪电攻击、巨鲸突袭改参数
    - 延迟执行，所有参数变更必须经过时间锁
3. **MultiSigWallet.sol 多签财库合约**
    - DAO 财库资金管理，7/4 多签；仅治理提案通过后才可调用
    - 资金出入全部链上留痕
4. **AddressRegistry.sol 地址注册表**
    - 全局白名单：记录各模块合约地址，统一注册；防止合约之间调用假冒地址
    - 只有时间锁可更新注册表

## 代币经济核心模块

5. **TokenVesting.sol 线性释放锁仓合约**
    - 多实例部署：团队池、私募池、流动性池、创作者激励池独立 Vesting
    - 支持悬崖期 + 线性解锁；不可提前解锁；可查询待释放额度、已释放额度
    - 释放出来的代币直接打到目标地址，不经过项目方钱包
6. **MiningPool.sol 挖矿池合约（双因子衰减）**
    - 固化双因子衰减计算公式，每周自动计算本轮可发放代币额度
    - 读取地址注册表，仅允许贡献结算合约调用 mint
    - 记录挖矿池剩余总量，池耗尽后永久停止 mint
7. **BurnManager.sol 销毁管理器**
    - 统一入口：所有业务消耗、罚没资金的销毁逻辑收口
    - 支持按比例销毁（例如付费内容：50% 销毁、50% 给创作者）
    - 记录累计销毁总量，对外提供查询接口
8. **DividendDistributor.sol 持币分红分发合约**
    - 周期快照（每周快照持币地址余额）
    - 收集生态手续费，按持仓比例自动分发分红
    - 支持用户批量申领分红；记录已申领标记，防止重复领取
    - 快照数据可链上验证

## 贡献与挖矿结算模块

9. **ContributionPoint.sol 贡献分 CP 记录合约**
    - 记录用户周期贡献分；贡献分不是代币，不可转账、不可交易
    - 仅链下可信节点（有授权）写入贡献分数据；合约只做存储，不做内容 AI 判断
    - 周期重置：每周结算后清空当周贡献分
10. **MiningCalculator.sol 挖矿权重计算器**
    - 输入：用户 CP、全局总 CP、用户信誉分、质押状态
    - 输出：用户本轮挖矿奖励份额
    - 公式固化，时间锁才能修改系数
11. **MiningSettlement.sol 挖矿结算合约**
    - 每周触发一次结算，调用 MiningCalculator 批量计算所有用户奖励
    - 请求 MiningPool mint 对应 CNT，发放至用户账户
    - 完整结算事件日志，方便前端 / 索引器抓取数据

## 身份、质押、反女巫风控模块

12. **StakeManager.sol 质押管理器**
    - 用户质押 50 CNT 开启挖矿权限；质押资金存入合约
    - 违规判定通过后，罚没质押金，转给 BurnManager（80% 销毁）+ 举报人（20%）
    - 正常用户可解锁质押（冷却期）
13. **Reputation.sol 信誉分合约**
    - 信誉分：0–100，不可转让，不可交易
    - 授权风控节点增减信誉分；违规可清零信誉分
    - 挖矿计算自动读取信誉分做加权
14. **AntiSuspicionOracle.sol 风控预言机（链下 AI 上报）**
    - 链下风控系统输出账号异常判定结果，通过授权预言机写入链上状态
    - 仅预言机账户可标记账号可疑；可被 DAO 提案推翻判定结果
    - 不存储原始行为数据，仅存储判定标签

## 业务场景合约

15. **ContentNFT.sol 内容确权 NFT**
    - ERC-721，作品链上确权，存储 IPFS 内容哈希
    - 支持版权分润配置，二次转载自动分润
16. **ContentPay.sol 付费内容合约**
    - 付费解锁专栏、单篇内容；收取 CNT
    - 自动调用 BurnManager 执行分润 + 销毁逻辑
17. **BoostMarket.sol 内容推广置顶市场**
    - 用户消耗 CNT 购买作品置顶流量；全额销毁
18. **CreatorCert.sol 创作者认证合约**
    - 开通专栏需要质押 CNT；注销专栏可解质押，违规罚没质押金

## DAO 治理合约模块

19. **Governor.sol DAO 提案核心合约（OpenZeppelin Governor）**
    - 提案门槛：持有并锁仓 CNT ≥10000
    - 投票权重 = 持仓 × 锁仓时长系数
    - 投票、计票、提案状态管理
20. **VotingEscrow.sol 锁仓加权合约（veCNT，不可转让）**
    - 用户锁仓 CNT 获得 veCNT，用于提升投票权重；veCNT 不能交易
21. **TreasuryProposalRouter.sol 财库提案路由**
    - 财库资金调用必须绑定通过的治理提案 ID，防止任意挪用

## 辅助工具、事件索引、审计相关合约

22. **EventIndexerHelper.sol 事件辅助合约**

23. **EmergencyPause.sol 紧急暂停模块（可选）**

## 模块依赖关系

```
CNTToken
├─ TokenVesting（释放代币）
├─ MiningPool（挖矿铸造）
│  └─ MiningSettlement → MiningCalculator → ContributionPoint + Reputation + StakeManager
├─ BurnManager（销毁入口）
├─ DividendDistributor（分红快照）
└─ DAO（Governor + VotingEscrow + Timelock + MultiSig）
业务合约：ContentPay / BoostMarket / ContentNFT / CreatorCert
    ↓ 调用 BurnManager、读取 AddressRegistry
风控模块：StakeManager、Reputation、AntiSuspicionOracle
```
