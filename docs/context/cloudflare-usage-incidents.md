# Cloudflare 用量故障与优化记录

## 2026-10-25：D1 用量异常

- **观察**：事后从 Cloudflare GraphQL 查询 2026-10-25 UTC 完整日，D1 读取 3,934,755 行、写入 134,672 行，写入超过 Free 套餐每日 100,000 行参考额度；读查询 95,250 次、写查询 52,998 次。账号 Workers 调用 71,792 次。`/api/community-actions/report` 有 26,734 次入口请求，其中 25,331 次返回 200、1,403 次返回 500。事后快照能确认全天量，无法单靠它确定当天首次触顶的时刻。
- **已上线的处理**：2026-10-26 09:15 +0800 的提交 `c2d367b8` 为 `community_action_devices` 心跳写入加了 3 分钟条件，并限制 `x_extension_runtime` 的重复写入。这个改动减少了相同心跳的 D1 写入，但仍会对每次报告执行鉴权和远端指令查询。
- **后续观察**：2026-10-26 23:14 +0800 的当日部分统计为 D1 写入 53,105 行、读取 4,423,445 行。两天流量结构和时间窗口不同，不能把总量差直接归因于 3 分钟写入节流。新每日快照上线后，应比较 D1 每日读写行数、查询次数及 X 插件报告量。

## 2026-10-26：Pages Functions 免费调用额度耗尽

- **观察**：2026-10-26 23:14 +0800 的 Cloudflare 账号 GraphQL 查询显示，当日 Workers 调用 119,054 次，其中公开站 Pages Worker `pages-worker--6819507-production` 113,451 次，超过免费套餐账号每日 100,000 次参考额度。`/login`、`/register`、`/api/auth/login` 返回 404，静态页面仍可访问。免费额度按 UTC 00:00 重置（北京时间 08:00）。同次查询显示 D1 当天读取 4,423,445 行、写入 53,105 行，不能把今日登录故障归因于 D1 写入额度。
- **主要入口**：同次查询显示 `/api/community-actions/report` 161,709 次入口请求，其中 86,669 次返回 200、74,853 次返回 405、187 次返回 503。405 多数发生在 Functions 不再运行时，因此入口请求数不能直接当作实际函数调用数。`/api/site-status` 当时 11,980 次（10,652 次 200、1,328 次 404），是次要来源。
- **原因**：X 插件 `content.js` 每秒渲染面板，等待倒计时也每秒变化；运行时状态因此反复更新，`background.js` 每次更新都触发远端心跳。每个心跳还会同步日报，并在服务端轮询远端指令。两台活跃 X 设备产生的请求量与该链路吻合。
- **本次修复**：远端任务详情改用稳定的等待状态和固定 `waitUntil` 时间戳，界面倒计时仍在本地显示；后台遥测增加每分钟一次的上限，回执模块对重叠的面板状态更新与闹钟心跳做 55 秒去重。每分钟闹钟仍负责远端指令轮询。正常状态下站点公告的浏览器轮询从每分钟改为每 5 分钟，隐藏标签页不再发请求；故障公告期间仍每分钟刷新。运行中心新增 Cloudflare 用量页，按 UTC 日归档 Workers 调用、D1 读写行数和高流量入口路径。
- **本地验证**：专项测试覆盖等待倒计时不改变远端详情、后台一分钟限频、重叠心跳去重、Cloudflare 用量归一化与 R2 快照读写，6 项通过。完整插件测试另有 1 条后台筛选按钮文案断言失败，失败位置与本次遥测改动无关。
- **部署后验证**：检查 X 插件更新后的 `/api/community-actions/report` 每设备约每分钟一次，Workers 当日调用低于 100,000，登录接口恢复正常，并在次日查看完整的 D1/Workers 日报。2026-10-26 23:09 +0800 复查时登录页、`/api/site-status` 和后台运行中心仍返回 404；代码尚未部署，这些部署后指标尚未取得。

数据口径：Workers 调用取 Cloudflare 账号 GraphQL 的 `workersOverviewRequestsAdaptiveGroups`；路径入口量取区域 `httpRequestsAdaptiveGroups`；D1 行数和查询次数取 `d1AnalyticsAdaptiveGroups`。这些口径不同，不可直接相加。
