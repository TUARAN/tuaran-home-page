# AI 分发大师后台监控接入

更新于 2026-11-02。新增的插件身份为 `ai-distributor`，目标平台与插件身份分离。旧 X / 小红书 / 掘金实例、动作表和命令协议保持兼容。

## 部署与启用

1. 在主站及后台共享的 D1 执行 `migrations/0129_plugin_monitor.sql`，创建独立的 `plugin_instances`、`plugin_commands` 和 `plugin_events`。迁移可重复执行，不包含文章数据。
2. 发布主站 `/api/plugins/report` 与后台 `/api/admin/plugins/monitor`、新版监控页面。主站接口只接受现有站长回执凭证，后台读写必须通过 `getOwnerOrReject`。
3. 代理在主站执行 `npm run syncblog:release`，自动打包、校验并上传私有 R2，再更新发行元数据。后台无需手选 ZIP 或生成另一套下载密码。当前发行 2.2.1，本地加载目录仍为 `apps/distribution-extension/dist/syncblog-plugin`。
4. 站长或人员码领取的 ZIP 自动内置凭证，首次安装自动读取并启用心跳；已手动关闭同步的实例保持关闭。通用开发包不带凭证，才需要手动配置。设备 UUID 独立生成，多个插件实例应分别生成人员码；站长总密钥可通用。
5. 在 `/admin/community-actions/monitor?platform=ai-distributor` 核对设备版本、心跳、批次和平台工具。首次开启前的历史不保证完整；数据统计以已经上报且去重的结果为准。

## 验收

- 没有内置凭证且未手动开启前无网络上报；领取包自动导入凭证后开启心跳。关闭后停止后续上报与远程指令领取。
- 设备 / 日期 / 目标平台筛选正确；分发准备不得计为正式发布。
- 停止批次等待当前平台步骤结束，后续目标变为已停止，不刷新目标页面。
- 停止全部同时停止后续分发、中止模型请求、关闭自动签到、通知笔记管理停止；只有确认停下后才回执成功。
- 远程更新只触发现有本地版本加载，不下载代码；服务端也检查心跳中的实际版本达到目标版本，才接受成功回执。
- 指令绑定插件身份和设备；默认有效 2 分钟，过期的待领取 / 执行中指令不能晚到执行。已领取但未确认的指令不会在重启后重复执行，显示失败或过期。
- 页面 10 秒刷新；插件每分钟及状态变化后同步；5 分钟内心跳视为在线，离线设备不提供远程按钮。
- 正文、标题、草稿、URL、Cookie、模型密钥不得出现在上报正文、D1 快照或动作日志中。只保留编号、类型、平台、状态、时间、版本与结构化笔记调整数量。

## 限制与回滚

后台不提供发布内容、启动签到或启动笔记清理。服务端未上线、迁移缺失或认证失败时，插件显示上报失败，本地工作台继续可用。

可关闭插件监控开关停止同步，或回滚插件安装包；旧监控链路不依赖新增三张表。不要删除现有 X 实例 / 指令表。新增监控历史可保留，后续清理应另行制定保留策略。
