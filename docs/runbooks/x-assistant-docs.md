# X 高频互动助手文档维护

核对日期：2026-11-02。本次基线为 manifest 与运行面板 v4.3.24。

公开手册唯一入口：`/resources/x-reply-clipboard-extension/docs`。README 保留安装、开发与补丁记录，不再复制整份操作手册。

## 分类与内容归属

- 开始使用：安装、模型、选择任务、启动与停止；不穿插版本历史。
- 任务与配置：十八项任务的对象、触发条件、完成条件、计数与设置位置。社群类目前只有「社群分发」。
- 排查与维护：等待原因、恢复动作、限制、升级和统计同步。
- 历史与观察：版本迁移、周总结与运营纪事。历史参数与假设不能作为当前默认值。

保留现有章节 ID，插件已链接的深层锚点不得随重排删除。新用户从快速开始进入，熟练用户通过目录直达。

## 每次发版同步

1. 对照 manifest、content.js、background.js 和各任务控制器，确认默认值与迁移行为；README 只作为索引，不能替代源码。
2. 核对任务数量、优先级、时段、共享冷却、单次条数、数据保存与恢复规则。分别说明默认值、用户自选值、历史值。
3. 仅在界面改变时重新实拍。至少覆盖排班台与任务子页；新增设置入口时增加设置实拍，先排除密钥。图片标版本、拍摄日期与示例设置。
4. 下载包版本与开发版分开描述。不能将未打包功能写成下载后即可用。
5. 运行页面 lint，检查目录与插件锚点、图片路径及实际尺寸，预览桌面和手机布局。
