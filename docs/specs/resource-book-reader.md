# 资源书籍阅读模板

状态：生效中  
建立日期：2026-11-06  
适用范围：站内提供全文阅读的资源、手册、白皮书和连载正文。图书介绍与购买页不适用。

## 阅读结构

- 一部书保留一个 H1。长书按篇、章、节、段组织；篇与章有独立标题和稳定锚点，节按读者需要定位的具体问题设置。
- 目录只列篇、章和有导航价值的节。正文段落靠行高和段间距区分，不把每段都塞进侧栏。
- 目录顺序必须与正文顺序相同；发布后保留旧锚点。章节改名可以修改显示文字，不能无迁移地删除锚点。
- 版本记录、运营档案与附录放在正文后面，避免打断首次阅读路线。

## 共用组件

- 资源目录中的全文书籍使用独立「书籍」分类；封面标签固定为「资源 · 书籍」。`lib/content/resourceBooks.mjs` 同时驱动书架和目录归类，避免两份书目漂移。
- `/resources/books` 是面向读者的馆藏入口，同时陈列 `lib/site/publishedWorks.js` 中已出版、已发布作品和站内全文。馆藏必须先分为「我的作品」与「外部资源书」；我的作品标明出版社图书、电子小册、指南手册、其他原创资源，外部资源标明原作者或来源机构。出版作品进入详情页，全文资源进入阅读页；筛选与搜索只改变陈列结果，不改变原有 URL。
- `lib/content/resourceBooks.mjs` 为每本站内可读书声明 `ownership`；`lib/content/libraryCatalog.mjs` 合并出版作品和阅读资源，统一生成归属、类型与署名。外部作品的文字封面不得使用 `TUARAN · 原创作品`；作者、共同作者、出版社与来源机构分别标注，不混为本站作者。
- 页头以标题和简短范围说明为主，数量只作紧凑辅助信息。不要用跨整屏的空白面板挤走第一排书卡。
- 首页「站长著作」的图书馆图标直达馆藏；旧 `/publications` 永久跳转到馆藏，站内导航和书籍详情的返回链接使用新路径。SEO 注册表只收录馆藏地址。
- 有正式封面的作品展示原封面，以固定 3:4 书卡框架陈列；不可把宣传海报当书封。缺少独立封面的全文使用统一生成的馆藏底图 `public/images/books/aran-collection-cover.jpg`，在页面上叠加准确书名、作者或来源，并显示「阿燃典藏」徽标。徽标表示本站收藏与编目，不表示外部作品归站长创作。每张书卡必须给出明确的“查看作品详情”或“在线阅读”动作。
- 每个全文阅读页在标题之前显示 `BookIdentity` 的书籍标识，统一提供返回 `/resources/books` 的路径；具体类型（原著、白皮书、实践读本、逐章阅读）放在标识右侧。
- `app/(site)/components/book-reader/BookToc.jsx` 是书籍目录唯一的交互组件。按 `groups: [{ id?, heading, items: [{ id, label, depth? }] }]` 提供数据；没有篇级锚点时可省略 `group.id`。
- 逐章路由的目录项可使用 `href`，选中状态由当前路径决定；同页章节继续用 `id` 与锚点定位。
- `bookReader.module.css` 管理目录滚动区域、细滚动条、选中态、键盘焦点和窄屏高度。页面仅负责版面宽度与主题令牌，不复制目录滚动算法。
- 目录激活依据正文标题在视口中的实际位置，跳过隐藏节点。读者手动滚动目录时暂缓自动追随；页面滚动后仅在激活项变化时移动目录，不重置移动端目录位置。
- 章节标题使用衬线字，正文保持约 65–75 字符的舒适行宽和宽松行高；表格与图版可独立横向滚动。信息卡只用于独立对象或需强调的规则。
- 书内数据表统一使用 `bookDataTable.module.css` 的边框、标题、表头和单元格间距；对照表明确列宽，窄屏只在表格容器内横向滚动。定制表格声明 `data-table-style="custom"`，避免全站通用表格规则叠加。

## 验收

1. 从页面顶部、章中、页面底部逐段滚动，目录激活项与当前章节一致；点击 `#frequency` 一类深链接后，目录能定位对应章。
2. 手动滚动侧栏时，目录不会突然跳回顶部；鼠标滚轮、触控滑动、键盘导航均可用。
3. 桌面与手机检查长目录高度、细滚动条、浅色与深色主题，以及固定站点页头下的锚点位置。
4. 对现有外链锚点做回归测试；目录数据中的 ID 必须存在于正文。

## 开源框架与内容来源

- 书架 `/resources/books` 使用 Nextra 4 的 MDX 页面机制，保持既有 Next.js App Router、站点导航和 Cloudflare 构建。陈列使用本站同一套书卡，支持类型筛选与搜索；新写的 Markdown / MDX 书籍可以沿用这条内容路径。
- 现有全文有 Markdown、预生成 HTML、逐章连载与 JSX 专题四种来源。它们保留原 URL、锚点和来源处理，外层统一使用 `BookIdentity`、`BookToc` 与书架归类；不得仅为改主题而重写原文或丢失脚注、翻页、互动功能。
- Nextra 版本与 Next.js 兼容性以 `package.json`、锁文件和构建结果为准。Docusaurus 的 GitHub Star 更多，但需要独立站点；选 Nextra 是为了让书籍继续处于本站同一导航和登录环境。

当前采用共用标识的阅读页：X 高频互动助手文档中心、AI 分发大师文档中心、《大互动理论》、《币安人生》、《建国方略》、以太坊白皮书和两份 WorkBuddy 白皮书。书籍专用章节目录由 `BookToc` 统一控制。
