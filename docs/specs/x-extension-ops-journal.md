## 开放假设（非定论）

1. **分发 / 信任被压**：推荐给新人的管子收窄（时间线降权、回复沉底一类）；还在看的人更愿意互动 → 曝光断、互动率升。
2. **原创激励规则变化**（约 2026-08 起停旧分成、推 Original Content Rewards）：强调原创合格曝光；评论 / 自动化相关不再当「有效变现流量」。解释「为何后来要刷原创、评论只当曝光入口」。
3. **短时海量相似评论**：重复 / 自动化式回复被当成 spam-like；高密度评论与「回复可见性被压」可同向。
4. **关注墙附近大批清理未回关**：清英文、不可靠号本身可解释；若几天内量大，可能与上面叠成「不真实行为」信号。
5. **本机统计虚高**：点赞以 `unlike` 按钮稳定出现为确认；发帖 / 评论以弹窗关闭或成功提示为确认——均非 X Analytics API。多账号合计也会抬高「今日合计」。
6. **评论对象错位（2026-10-30）**：评论首页主要吃 For You 推荐，容易落在小微互关号上；以前「回两百条」容易带流量，现在同量级回复也可能几乎无分发。更可能是算法改了有效互动权重，而不是单纯条数不够。大V帖评论、有质量发帖、关注侧重建应联动，单压首页评论不够。
7. **关注 / 评论搅拌叠加**：近段关注清理与评论搅拌是否共同压信任，**待核实**；目前只能并列观察，不能单归因。

## 自检清单（先做再改策略）

1. 未登录搜自己句 / 打开自己主页，看外露内容是否正常。
2. 热帖下自己的回复是否沉到「显示更多回复」。
3. 近 7 天曝光是「一天断崖」还是「一路阴跌」。
4. Analytics / 创作者后台是否出现官方「可见性受限」类标签；有再申诉。
5. 核对面板「全部账号」合计 vs 单账号；抽查几条「已确认」点赞在网页上是否仍为已赞。

## 下一观察窗口

- **窗口**：降量后继续记 48–72 小时；并另开一条「评论大V + 质量发帖 + 关注重建」联动窗口（约 2026-10-30 起）。
- **记**：曝光（相对近百万的倍数差）、回复可见性、原创帖触达、互动率、面板计数与后台差；评论首页 vs 评论大V 的本机拆分条数。
- **策略动作（实验，非定论）**：减低「只在 For You 小微流上堆回复」；补大V当天帖评论；发帖与关注侧同步抬质量，三项当一套互动，不单押评论条数。同步清浏览量低于 100 的低质存量帖，先把主页「可看内容」压回质量线。
- **仍不做定论**：直到窗口数据回来；关注搅拌 vs 评论对象错位 vs 算法改权可并存；清帖对分发的即时效果待观察。

## 调研判断（简要，可修正）

更像「分发 / 信任被压」叠「评论对象错位」，不太像「纯 v3→v4 bug」。近两天曝光约从百万级掉到五千级（约 ÷20）。以前回两百条还能带量，现在同样回 For You 小微互关帖也可能没流量——更支持算法改了有效互动权重，而不是单纯「没回够」。评论大V、质量发帖、关注重建要联动；只搅拌首页评论不够。
