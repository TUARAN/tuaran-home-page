# X 扩展提示词反馈台账

日期起算：2026-10-29。与文档中心「提示词反馈台账」对应。

用途：站长不定期把「发出来不对」或「这条挺好」的帖子 / 回复录入站内 `/admin/community-actions?tab=feedback`。站内 D1 表 `x_extension_prompt_feedback` 保存逐条原始反馈；可从后台下载 Markdown 批量复盘，也可手动点击同步按钮，将未归档条目写入本文件。综合分析后才改默认四份提示：

| 键 | 用途 |
| --- | --- |
| `replyTimelinePrompt` | 评论帖子 |
| `replyCommentPrompt` | 回复评论 |
| `postNormalPrompt` | 普通发帖 |
| `postPremiumPrompt` | 精品发帖 |

规则：

- 单条反馈只记录，不立刻改线上默认提示。
- 站内「待汇总 / 已汇总」仅表示是否完成批量复盘；标记状态不会自动改提示词，也不会自动提交仓库。
- 仓库同步是单独的显式操作，需要 Admin 环境的 `GITHUB_SYNC_TOKEN` 有仓库 Contents 写权限；同步后的原文与评价会出现在公开仓库。没有该密钥时可下载 Markdown 后交给站长助手同步。
- 反例优先写清「哪一段像 AI / 假 / 油 / 客服」；正例写清「哪一句立住」。
- 可附原帖语境、任务类型（评论帖子 / 回复评论 / 普通 / 精品）、是否带钩子或 @grok。
- 汇总改提示后，在本文件顶部「迭代记录」留一笔，并同步 `background.js` / `content.js` 默认文案。
