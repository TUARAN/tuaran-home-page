## 一、先给结论

这张图最值得警惕的是它给人的确定性太强。

| 问题 | 核验结果 |

| 是否找到“全国收入调研”原始报告 | 未找到可公开核验的正式报告、论文、调查说明或发布机构页面 |

| 图中收入分层是否可直接引用 | 不建议。缺调查口径、样本量、时间、收入定义，且存在加总错误 |
| 与官方收入数据是否完全冲突 | 不完全冲突。低收入人口规模大的方向与公开讨论相近，但具体数字无法核验 |

如果要在文章、视频或报告里使用，最稳妥的表述是：

> 网上流传一份署名张春晓的收入分层PPT，但截至本文写作，未见可核验的原始调研报告。该PPT反映的“低收入人口规模大”方向，与国家统计局居民收入数据和2020年“两会”后关于“6亿人月收入1000元左右”的公共讨论存在相近之处；但其具体分档人数、收入口径和个税推断缺乏公开依据，不宜作为官方统计引用。

## 二、图片里到底说了什么

图片标题是：

> 我国14亿人的月收入大概是多少（参考）

PPT把14亿国人的月收入分成十个等级：

| 等级 | 图中口径 | 图中人数 |
|---|---|---:|
| 一级 | 月收入为0 | 546万人 |
| 二级 | 0至500元 | 2.15亿人 |
| 三级 | 500至1000元 | 3.26亿人 |
| 四级 | 1000至1500元 | 2.43亿人 |
| 五级 | 1500至2000元 | 1.7亿人 |
| 六级 | 2000至3000元 | 2.03亿人 |
| 七级 | 3000至5000元 | 1.56亿人 |
| 八级 | 5000至10000元 | 6328万人 |
| 九级 | 10000至20000元 | 784万人 |
| 十级 | 20000元以上 | 70万人 |

图中还给出几个醒目判断：

- 月收入1000元以下有5.46亿人。
- 月收入5000元以下有13.28亿人，占总人口94.87%。
- 根据国家税务总局数据，2023年14亿人中有1亿人交个人所得税，所以14亿人中约95%的人月收入低于10000元。
- 月收入超过10000元的人，全国约5%左右。

这些说法的问题主要在三个地方：来源不明、口径混用、计算不严。

## 三、最明显的算术问题

只看图中的前七档，人数加总应为：

```text
546万 + 2.15亿 + 3.26亿 + 2.43亿 + 1.7亿 + 2.03亿 + 1.56亿
= 0.0546亿 + 2.15亿 + 3.26亿 + 2.43亿 + 1.7亿 + 2.03亿 + 1.56亿
= 13.1846亿
```

也就是说，图中“月收入5000元以下有13.28亿人”至少和前面列出的分档数字不一致。按前七档相加，更接近 **13.18亿人**，不是13.28亿人。

这不是小毛病。因为这类PPT的说服力正来自“数字很精确”。一旦基础加总都不一致，就必须反过来追问：这些数字来自哪里？是否经过转述、改写、四舍五入或二次拼接？

## 四、口径问题：月收入、可支配收入和个税人数不是一回事

这张图最大的结构性问题，是把几类不同口径放在了一起。

### 4.1 “个人月收入”不等于“居民人均可支配收入”

国家统计局常用的是“居民人均可支配收入”，它包括工资性收入、经营净收入、财产净收入、转移净收入，统计对象是住户调查中的居民，并按人口平均。

而图中写的是“月收入”。它可能指：

- 每个自然人的劳动收入；
- 每个自然人的全部现金收入；
- 居民人均可支配收入折算到月；
- 家庭收入除以家庭人口后的月均数；
- 或者某种税前/税后混合口径。

这几种口径的结果会差很多。比如一个家庭里老人、儿童、学生没有工资收入，但仍会被计入人均可支配收入的人口分母；如果按“个人劳动收入”，他们可能接近0；如果按“家庭可支配收入人均摊分”，他们又不是0。

所以，只写“月收入”而不说明定义，基本不能进入严肃引用。

### 4.2 “缴纳个人所得税人数”不能推出“月入过万人数”

图中把“2023年有1亿人交个人所得税”推成“14亿人中95%的人月收入低于10000元”。这个推理不稳。

中国个人所得税的实际纳税，受到这些因素影响：

- 工资薪金基本减除费用为每年6万元，也就是通常说的5000元/月起征点；
- 三险一金可扣除；
- 子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人、3岁以下婴幼儿照护等专项附加扣除可扣除；
- 劳务报酬、稿酬、特许权使用费存在预扣与年度汇算差异；
- 个体经营、股息红利、财产转让等又有不同计税规则。

因此，一个人月收入超过10000元，不代表一定实际缴纳个税；一个人缴过个税，也不代表全年稳定月入超过10000元。个税人数只能说明税制覆盖与申报结果，不能直接当作收入分布表。

## 五、用国家统计局数据校准一下

国家统计局2023年居民收入数据提供了一个更稳定的参照系。

| 指标 | 2023年数据 | 折合月均 |
|---|---:|---:|
| 全国居民人均可支配收入 | 39218元/年 | 约3268元/月 |
| 全国居民人均可支配收入中位数 | 33036元/年 | 约2753元/月 |
| 城镇居民人均可支配收入 | 51821元/年 | 约4318元/月 |
| 农村居民人均可支配收入 | 21691元/年 | 约1808元/月 |

按全国居民五等份收入组，2023年数据是：

| 分组 | 人均可支配收入 | 折合月均 |
|---|---:|---:|
| 低收入组 | 9215元/年 | 约768元/月 |
| 中间偏下收入组 | 20442元/年 | 约1704元/月 |
| 中间收入组 | 32195元/年 | 约2683元/月 |
| 中间偏上收入组 | 50220元/年 | 约4185元/月 |
| 高收入组 | 95055元/年 | 约7921元/月 |

这组官方数据说明两个事实：

第一，中国居民收入分布确实不是很多城市中产体感中的样子。全国居民收入中位数折合月均约2753元，高收入组人均可支配收入折合月均约7921元。把全国人口放在一起看，月均过万并不是常态。

第二，官方数据并不支持把网传PPT每一档人数照单全收。国家统计局公开的是住户调查、五等份收入组和人均可支配收入等口径；网传PPT的十级人数分布没有展示从官方口径推导到“个人月收入十档”的方法。

## 六、“6亿人月收入1000元左右”与这张图的关系

图中“月收入1000元以下有5.46亿人”，很容易让人联想到2020年全国两会后广泛传播的说法：我国还有相当规模人口月收入在1000元左右。

这类说法的公共意义在于提醒人们：用一线城市互联网从业者的收入体感理解全国，误差会很大。

但它不能自动证明这张PPT正确。原因是：

- “1000元左右”与“1000元以下”不是同一个统计区间；
- 2020年前后的口径与2023年PPT口径未必一致；
- “人均收入”与“个人月收入”仍然可能不是同一概念；
- 网传PPT没有解释它如何从公开数据得到2.15亿、3.26亿、2.43亿这些精确分档。

更准确的看法是：这张图抓住了一个真实社会背景，但给出的精确分布需要单独验证。

## 七、人物身份：哪些能说，哪些要谨慎

用户提供的身份描述包括：

> 张春晓，北京大学经济学博士，现任北京大学经济学院授课师资及经济与人类发展研究中心研究员，国务院国资委研究中心咨询部部长、学术委员会委员。

这里要分开看。

### 7.1 “北京大学经济学院授课师资”需要看具体项目

“授课师资”常见于培训项目、EDP项目、讲座项目、企业内训项目，并不一定等同于北京大学经济学院专职教师。

我核对北京大学经济学院“专职教师”公开名单，未在名单中看到张春晓。这个结果不能证明他没有在北大相关项目授课，但说明对外写作时不宜简化成“北大经济学院教师”。

更稳妥的写法是：

> 公开材料中有“北京大学经济学院授课师资”等介绍，但这类表述可能指培训或课程项目师资，不能等同于北大专职教师身份；如需引用，应以具体项目页面或主办方介绍为准。

### 7.2 “经济与人类发展研究中心研究员”需要进一步核验

北京大学经济学院官网确有“经济与人类发展研究中心”。但在我能看到的中心公开介绍页中，成员列表未显示张春晓。

这仍然不能排除兼职、过往任职、项目研究员或页面未更新的可能性。但在没有中心官网、学院官网或活动主办方正式页面支持前，不宜写成确定事实。

### 7.3 “国资委研究中心咨询部部长、学术委员会委员”也要找原始来源

这类头衔如果来自会议海报、培训课程宣传或百科式页面，可靠性不等。对外引用时最好找：

- 国务院国资委研究中心官网；
- 国资委系统会议通知或新闻稿；
- 张春晓本人署名文章的作者介绍；
- 主办方活动页面的嘉宾介绍；
- 出版物作者简介。

如果找不到，建议统一写成“公开传播材料中称其为……”，不要直接写成已核实身份。

## 八、这张PPT可能是怎么来的

在没有原始报告的情况下，只能提出几种可能：

1. **课程或内部讲座PPT**：用公开数据、媒体说法和个人估算做成通俗展示，目的是制造体感，不是发表统计报告。
2. **二次加工材料**：原作者可能不是张春晓，图片被转发时把署名、场景、上下文丢失了。
3. **估算表被包装成调研**：根据人口、收入中位数、个税人数等信息倒推分层，最后呈现成“数据报告显示”。
4. **来自未公开调查**：理论上可能存在，但只要样本量、抽样方法、问卷口径、调查时间和发布机构不公开，就无法外部复核。

其中最不能接受的是第四种被当成默认前提。严肃收入调查至少要说明：

- 调查时间；
- 样本量；
- 抽样框；
- 城乡、地区、年龄结构；
- 收入口径；
- 税前还是税后；
- 是否含转移收入、财产收入、经营收入；
- 如何处理未成年人、老人、学生、无业人口；
- 如何从样本推算全国人口。

这张图目前都没有。

## 十、个人结论

这张图适合引发讨论，不适合直接引用。

它真正有价值的地方，是提醒我们：全国收入结构和城市中产体感之间存在巨大落差。很多人谈消费、房价、税负、婚育、就业和社会保障时，会不自觉把样本限缩在城市白领、互联网从业者、公务员、国企员工和小老板身上。但把全国人口放进来以后，收入分布会立刻变得很不一样。

但这不意味着可以拿一张来源不明的PPT当作证据。收入问题越敏感，越要区分三件事：

- **方向判断**：中国低收入人口规模大，这个方向有官方数据支撑。
- **具体数字**：5.46亿、13.28亿、6328万、784万、70万这些分档数，目前缺少可核验来源。
- **归因署名**：是否为张春晓本人最新调研，尚未看到原始报告支撑。

所以我的判断是：这是一份需要继续追源的“网传收入分层材料”。如果后续能找到完整报告，最该先看的是调查方法页。
