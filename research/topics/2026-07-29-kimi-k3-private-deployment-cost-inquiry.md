## 一、调研概况

### 1. 核心结论

截至 2026 年 7 月 29 日，可以确认的费用口径如下。

1. **模型权重许可没有公开的永久授权费或年订阅费。** 月之暗面发布的 Kimi K3 License 明确以“free of charge”授予使用、修改、部署、微调、分发和销售等权利。一般企业在内部使用权重，不因用户数、并发数或算力规模向月之暗面支付公开列明的许可费。
2. **免费权重许可不包含交付服务。** 按 2026 年国内大模型项目工作量估算，单节点验证实施约 20万—50万元，单节点生产实施约 80万—180万元，高可用或 64 卡超节点实施约 180万—500万元。月之暗面尚未发布统一服务价，这些数字用于立项预留。
3. **算力是本地部署的主要成本。** K3 为 2.8 万亿总参数、1040 亿激活参数的 MoE 模型。AMD 对正式权重的测算约为 1.5609 TB；单机或单节点必须先解决 TB 级高带宽显存、互联、存储和供电问题。
4. **“能加载”与“生产可用”存在明显距离。** AMD 给出的 8×MI355X TP8 配方具备权重和单条 100 万 token 上下文的容量余量，但仍将单实例可用性表述为有待硬件可得性和通信规模验证。NVIDIA 给出 16×GB200、16×GB300 等配方。月之暗面的效率建议是 64 张以上加速卡的高带宽超节点。
5. **专属云尚无月之暗面公开标准价。** 8×MI355X 的公开云价折算约 11万—36万元/月；加上单租户网络、存储、监控、托管和 SLA 后，完整专属云预算宜按 15万—50万元/月，双节点高可用按 30万—95万元/月。具体隔离能力仍以合同为准。
6. **网传固定报价目前不可用于立项。** 未检索到月之暗面官网、Kimi 官方文档、官方模型仓库或正式采购公告披露 K3 私有化“永久授权价”“年费价”“每并发价”或“实施费”。任何具体人民币打包价在取得盖章报价单前，只能列为销售线索。

#### 总计口径

企业技术立项需要填写单一金额时，建议采用下表的“建议立项总额”，同时把“控制上限”写入采购审批，避免低价估算在实施阶段反复追加。

| 典型方案 | 建议立项总额 | 控制上限 | 总额覆盖范围 |
|---|---:|---:|---|
| **企业本地机房离线私有化，8×MI355X 单节点，三年** | **1200 万元** | **1500 万元** | 模型许可、硬件与配套、机房改造、生产实施、三年电力维保、运维人工、一次大版本升级、15% 左右风险准备 |
| **专属云私有化，8×MI355X 单节点，三年** | **1500 万元** | **2200 万元** | 模型许可、云算力、单租户网络、存储备份、平台托管、生产实施、三年 SLA 与内部运维、容量溢价 |
| 本地双节点高可用，三年 | 2200 万元 | 3000 万元 | 两套推理节点、流量切换、双副本、故障演练和三年运维 |
| 专属云双节点高可用，三年 | 2700 万元 | 4000 万元 | 两个独享节点或跨故障域副本、托管平台和三年 SLA |
| 本地 64 卡生产超节点，三年 | 4500 万元 | 6500 万元 | 64 卡硬件、网络存储、液冷配电、集群实施和三年生产运维 |

**优先建议：** 数据必须完全离线、并发要求不高的企业，立项总额先填 **1200 万元**；允许使用专属云且希望缩短交付周期，立项总额先填 **1500 万元**。两项均以三年为周期，不含业务应用研发、知识库数据治理、大规模微调和异地灾备。

### 2. 两种方案的定义边界

| 方案 | 数据与权重位置 | 基础设施归属 | 网络条件 | 费用主项 |
|---|---|---|---|---|
| 企业本地机房离线私有化 | 权重、输入、输出、日志均在企业控制域 | 企业采购或融资租赁 | 可完全断网；升级通过离线介质 | GPU 集群、机房改造、实施、运维、备件 |
| 专属云私有化 | 权重与推理服务位于专属租户、VPC 或独享裸金属 | 云厂商或推理服务商 | 通常依赖云内网络和服务商控制面 | GPU 租赁、托管平台、专线、流量、SLA |

“企业版账号”“官方公共 API”“第三方共享 API”不自动等同于私有化。采购文件应把物理独享、资源池独享、VPC 单租户、数据是否用于训练、日志保留位置、运维人员权限和删除证明分别写清。

### 3. 证据可信度分级

| 等级 | 资料类型 | 可用于何种判断 |
|---|---|---|
| A | 月之暗面官网、Kimi API 文档、官方 GitHub/Hugging Face 仓库及许可证 | 模型参数、许可边界、官方 API 价格、官方部署建议 |
| B | NVIDIA、AMD 官方部署文档或产品资料 | 可运行拓扑、显存、功耗和软件栈要求 |
| C | 云厂商正式价目表、政府采购结果、具名技术媒体 | 预算锚点和市场区间；不能替代项目报价 |
| D | 自媒体、导航站、匿名社区、厂商软文 | 发现线索；不能作为采购定价依据 |

### 4. 估算方法与统一假设

公开资料没有 K3 私有化价目表，预算采用“可核验成本锚点 + 工程工作量 + 风险系数”计算。

- **汇率：** 1 美元按 7.2 元人民币折算。
- **云资源：** 每月按 720 小时、全年 24×7 占用；公开低价取 Vultr 8×MI355X 约 20.72 美元/节点·小时，高价取 Oracle 8.60 美元/GPU·小时。
- **本地硬件：** 8×MI355X 采购价以 24—36 个月云资源成本、液冷节点 BOM 和 2026 年国内 GPU 采购结果交叉估算；Blackwell 采用公开 NVL72 整柜市场价按 GPU 比例折算，再增加非整柜交付与集成余量。
- **实施人天：** 高级 GPU/大模型工程师按 4000—6000 元/人天，普通集成、测试和培训人员按 2500—4000 元/人天，另计 15%—25% 项目管理、风险和供应商毛利。
- **人工：** 内部平台运维、安全和模型工程角色按 40万—70万元/全成本人年估算。
- **电力：** 综合电价按 0.6—1.0 元/kWh，机房 PUE 按 1.25—1.40；未单独计入地方补贴。
- **置信度：** 云租赁为中等置信度，本地新一代 GPU 采购与厂商商业支持为低至中等置信度，区间已留出供货和交付风险。

所有估算均为 2026 年 7 月含税预算口径。招标前应更新汇率、芯片可得性和供应商折扣。

## 二、成本分项询证要点

### 1. 商业授权费用

#### 已确认

- K3 代码和权重采用自定义 **Kimi K3 License**，并非 MIT License。
- 一般内部使用不触发许可证第 2、3 条的附加要求。
- 向第三方提供可控制输入、参数或训练数据的“Model as a Service”业务，若许可方及关联方连续 12 个月合计收入超过 2000 万美元，继续将 K3 或其衍生模型用于任何商业目的前，须与月之暗面另行签约。
- 使用 K3 或衍生模型的商业产品或服务，若月活超过 1 亿，或月收入超过 2000 万美元，界面须显著展示“Kimi K3”。内部使用及通过月之暗面官方产品或认证推理伙伴使用的情形不受这两项要求约束。
- 许可证未设置按 GPU 数量、并发数或企业内部用户数计费的公开条款。

#### 采购询证

| 项目 | 当前公开结论 | 要求厂商书面确认 |
|---|---|---|
| 权重永久授权 | 一般使用免费；没有公开买断价 | 集团内部、子公司、外包人员、境内外分支是否均属于同一许可范围 |
| 年订阅 | 未见权重年订阅要求 | 年费是否仅对应技术支持、企业平台或托管服务 |
| 按算力/并发/用户计费 | 权重许可证未设置 | 官方交付包、控制台、网关或支持服务是否另行计费 |
| 微调与衍生模型 | 许可证允许修改和创建衍生作品 | 微调权重能否跨关联公司分发、能否交付客户、退出合同时如何处理 |
| MaaS 商业化 | 达到收入门槛须另签协议 | 收入口径、关联方范围、存量客户过渡期、授权费计算方式 |
| 品牌标识 | 达到月活或月收入门槛须展示 | 展示位置、尺寸、白标产品安排和商标使用许可 |
| 赔偿与担保 | 权重按“as is”提供，无保证 | 知识产权索赔、输出侵权、开源组件漏洞由谁承担 |

**预算口径：**

| 使用方式 | 建议立项预算 | 估算说明 |
|---|---:|---|
| 单一法人内部推理 | 0 元模型许可费 | 直接依据 Kimi K3 License 的免费授权和内部使用豁免 |
| 集团多法人内部共享 | 0—30万元法务与合同预算 | 权重许可仍可按 0 元测算，预留法律意见、协议补充和权重治理费用 |
| 购买原厂/集成商企业支持 | 30万—80万元/年 | 包含 5×8 支持、故障协助、有限升级和季度巡检的估算 |
| 7×24 原厂级支持 | 80万—200万元/年 | 包含重大故障升级、应急响应和更多驻场人天的估算 |
| 对外 MaaS 或接近许可证收入门槛 | 100万—300万元/年风险准备金，或相关业务收入的 3%—8% | 低置信度内部预留，不代表月之暗面报价；正式费用【需向厂商官方询证】 |

永久授权和年订阅模式可以这样理解：权重使用权本身无须买断，所谓“年费”更可能对应企业支持、托管平台和 SLA。采购方不宜为许可证中已经免费授予的内部使用权重复支付“权重买断费”。

### 2. 配套硬件算力

#### 容量下限

| 依据 | 已公开配置 | 可确认的含义 | 尚不能确认 |
|---|---|---|---|
| 月之暗面官方 | 2.8T 总参数、104B 激活参数、1M 上下文；建议 64+ 加速卡超节点 | 生产效率依赖大规模高带宽互联 | 64 卡具体型号、吞吐、并发和 SLA |
| AMD 官方 | 权重约 1.5609 TB；8×MI355X、每卡 288 GiB，TP8；单条 1M 上下文已知额外状态约 14.427 GiB/卡 | 8 卡新一代高显存节点具备加载与功能验证的容量条件 | 生产吞吐、并发、框架额外内存和长稳测试 |
| NVIDIA 官方 | 16×GB200 聚合部署；16+16×GB200 预填充/解码分离；16×GB300 两副本；8+16×GB300 分离部署 | 16 卡及以上已有厂商级部署配方 | 国内供货、采购价格及等效国产算力方案 |

8×H100 80GB 只有 640GB 显存，不能容纳约 1.56TB 的正式权重。自媒体所称“4 张或 8 张 H100 即可完整生产部署”缺少容量依据。CPU 或 NVMe 卸载可以让模型在更低 GPU 显存下启动，吞吐、时延、并发和百万上下文能力会显著变化，不能直接视为生产配置。

#### 采购与租赁预算锚点

下列数字用于预算量级判断，不是月之暗面报价。美元折算人民币统一采用 **1 美元 = 7.2 元**的内部测算汇率，未含税、专线、存储、技术服务及资源稀缺溢价。

| 场景 | 计算方法 | 预算锚点 | 可信度 |
|---|---|---:|---|
| 8×MI355X 云算力低价档，24×7 | 20.72 美元/节点·小时 × 720 小时 | 约 10.7 万元/月；约 129 万元/年 | C，公开云价 |
| 8×MI355X 云算力高价档，24×7 | 8.60 美元/GPU·小时 × 8 × 720 小时 | 约 35.7 万元/月；约 428 万元/年 | C，公开云价 |
| 8×MI355X 本地单节点 | 24—36 个月云成本、2.3TB HBM 液冷节点及配套交叉估算 | 约 450万—800万元；加存储、网络和机房后约 500万—950万元 | C，低至中置信度估算 |
| 16×GB200 | GB200 NVL72 公开价 280万—340万美元按 16/72 折算，再加非整柜集成余量 | 约 500万—800万元 | C，市场价比例估算 |
| 16×GB300 | GB300 NVL72 公开价 600万—650万美元按 16/72 折算，再加非整柜集成余量 | 约 1000万—1400万元 | C，市场价比例估算 |
| 64 卡 GB200/GB300 超节点 | NVL72 整柜价按 64/72 折算，增加网络、存储和交付 | 约 1800万—4200万元硬件；整套落地约 2200万—5000万元 | C，市场价比例估算 |
| 64×MI355X 云算力，24×7 | 按公开低、高两档价格线性扩展 | 约 86万—285万元/月纯算力 | C，未计规模折扣 |

云租赁锚点不能反推硬件成交价。长期预留实例、容量承诺、地域、电力、运维和稀缺资源会改变折扣；本地采购还要计入融资成本、折旧和残值。

#### 机房与配套

- **存储：** 正式权重约 1.56TB。考虑原始权重、格式转换、中间文件、回滚版本和双副本，初期宜预留 5—10TB 高速存储；模型多版本并行时继续扩容。
- **网络：** MoE 专家并行对互联敏感。普通以太网能够连接服务器，不代表可以达到官方超节点吞吐。NVLink/NVSwitch、Infinity Fabric 或等效高速互联的拓扑和带宽须写入验收条款。
- **供电与制冷：** MI355X 单模块最大板卡功耗 1400W，8 卡仅 GPU 峰值即 11.2kW。CPU、内存、网络和制冷叠加后，应按整机实测功率与机房 PUE 计费。NVIDIA GB200 NVL72 整柜约 120kW，传统机房可能需要配电与液冷改造。
- **冗余：** 单节点可以完成技术验证，无法天然满足生产高可用。N+1、双副本或预填充/解码分离会直接增加 GPU、网络和许可外的软件成本。
- **备件与交期：** 高端 GPU、交换模块、液冷部件和电源的备件比例、到货周期、原厂保修响应均需单列。

配套预算可按以下区间先行列项。

| 配套项 | 8 卡单节点 | 64 卡超节点 |
|---|---:|---:|
| 高速存储、备份与模型仓库 | 20万—60万元 | 80万—250万元 |
| 高速网络与交换设备 | 30万—100万元 | 150万—500万元 |
| 机柜、配电、UPS 与液冷改造 | 30万—120万元 | 200万—600万元 |
| 三年备件与延保 | 硬件价的 5%—10%，约 25万—80万元 | 硬件价的 5%—10%，约 90万—420万元 |
| 电力与制冷 | 约 10万—25万元/年 | 约 80万—160万元/年 |

### 3. 实施服务费

月之暗面尚未公开 K3 私有化实施服务目录和统一人天单价。按 2026 年大模型基础设施项目的人天和复杂度估算：

| 工作包 | 最低交付内容 | 预估工作量 | 预估费用 |
|---|---|---:|---:|
| 环境勘察 | 机房、电力、制冷、网络、固件、操作系统和安全域评估 | 5—10 人天 | 2万—5万元 |
| 权重交付 | 离线介质、哈希校验、SBOM、许可证清单 | 3—6 人天 | 1万—3万元 |
| 推理部署 | vLLM/SGLang/TokenSpeed、量化格式、并行策略和 API 适配 | 15—30 人天 | 8万—18万元 |
| 性能调优 | 预填充、解码、批处理、缓存、长上下文、并发和时延 | 20—45 人天 | 10万—27万元 |
| 平台集成 | API 网关、IAM、SSO、审计、限流、计量、知识库和业务系统 | 30—80 人天 | 15万—48万元 |
| 安全合规 | 漏洞、镜像签名、基线、日志脱敏、数据删除和运维审计 | 15—35 人天 | 7万—20万元 |
| 测试验收 | 业务题集、质量、吞吐、P95/P99、长稳及故障演练 | 15—35 人天 | 7万—20万元 |
| 培训移交 | 管理员、运维、开发和业务用户培训，文档与故障手册 | 5—12 人天 | 2万—6万元 |

工作包简单相加约 52万—147万元。计入项目管理、跨厂商协调、驻场差旅和风险后，建议采用以下打包预算：

- **单节点概念验证：20万—50万元。** 覆盖权重加载、基础 API、有限性能测试和 1—2 次培训。
- **单节点生产交付：80万—180万元。** 覆盖网关、权限、审计、监控、业务压测、长稳和正式移交。
- **双节点高可用：120万—280万元。** 增加流量切换、故障演练、双副本和灾备流程。
- **64 卡超节点或复杂业务平台：180万—500万元。** 增加多节点并行、缓存、容量调度、多业务接入和 7×24 验收。

立项测算可先按“验证环境、生产环境、灾备环境”分别估算工作量。人天单价、差旅、驻场周期、夜间割接、第三方系统改造和验收失败返工应在报价单中独立列示。

### 4. 后续成本

| 成本项 | 8 卡单节点预估 | 64 卡生产集群预估 | 估算口径 |
|---|---:|---:|---|
| 5×8 技术支持 | 30万—80万元/年 | 80万—180万元/年 | 季度巡检、远程故障、有限现场人天 |
| 7×24 技术支持 | 80万—200万元/年 | 180万—400万元/年 | 应急响应、重大故障升级、驻场人天 |
| 小版本升级 | 10万—30万元/次 | 30万—80万元/次 | 框架、驱动、权重和业务回归 |
| 大版本迁移 | 40万—100万元/次 | 80万—200万元/次 | 并行策略重调、全量评测、灰度回滚 |
| 内部持续运维 | 80万—210万元/年 | 160万—350万元/年 | 2—3 人或 4—5 人的全成本人工 |
| 电力制冷 | 10万—25万元/年 | 80万—160万元/年 | 综合电价和 PUE 假设 |
| 硬件维保与备件 | 硬件价的 3%—6%/年 | 硬件价的 3%—6%/年 | 原厂延保、现场服务和备件池 |
| 安全与合规 | 15万—50万元/年 | 40万—120万元/年 | 渗透、审计、等保/密评按需选用 |
| 模型与业务运营 | 40万—120万元/年 | 100万—300万元/年 | 评测集、内容安全、提示词和人工复核 |

单节点本地方案的年度后续成本，建议按 **100万—300万元**列预算；64 卡生产集群按 **400万—1000万元**列预算。若企业已有成熟 GPU 平台、机房和运维团队，可取区间下沿。

开源推理框架可以免费取得，但集群升级、兼容性验证和故障定位仍会产生工程成本。K3 使用保留思考历史模式，多轮和工具调用必须原样回传 `reasoning_content` 与 `tool_calls`；网关或 Agent 框架不兼容会造成质量波动，也会增加联调和回归费用。

### 5. 限制条件

#### 并发与性能

- 官方没有公布自托管 K3 的固定并发上限。并发由 GPU 型号与数量、上下文长度、输出长度、批处理、缓存命中、预填充/解码拓扑和服务级目标共同决定。
- 100 万 token 是最大上下文能力，不代表每个并发请求都能以该长度运行。AMD 测算显示，单条 100 万 token 上下文在 TP8 下每卡已知额外状态约 14.427 GiB，且尚未计入内核工作区、通信缓冲、内存碎片和框架开销。
- 官方公共 API 的并发等级为 1—1000、RPM 为 3—10000、TPM 为 50 万—500 万，随累计充值档位变化。这套限流只适用于公共 API，不能套用到私有化验收。

#### 权重分发

- 复制或分发权重和实质性软件部分时，应保留版权和许可声明。
- 离线介质、镜像仓库、备份、灾备中心、集团共享及集成商临时访问均应登记副本、责任人和销毁流程。
- K3 权重约 1.56TB，跨地域同步、离线介质运输和多版本保留会产生存储、带宽和安全管理成本。

#### 商业化权限

- 企业内部办公、研发或生产辅助通常落入内部使用豁免。
- 对外提供可控制输入、参数或训练数据的推理、微调 API，可能构成许可证定义的 MaaS。
- 将模型能力嵌入固定产品功能，与向客户开放通用模型控制能力的法律后果不同。边界业务应由法务结合产品交互和合同审查。
- 月活、月收入和连续 12 个月收入阈值必须纳入合规监控，避免业务规模扩大后遗漏另签协议或品牌展示义务。

## 三、不同部署方案费用对比

### 1. 费用与门槛

| 维度 | 企业本地机房离线私有化 | 专属云私有化 |
|---|---|---|
| 模型许可 | 一般内部使用可按 0 元预算；特殊商业化另询 | 一般内部使用同上；托管平台和认证伙伴服务另收费 |
| 初始投入 | 高：GPU 集群、网络、存储、液冷、配电、实施 | 中：部署、专线、安全域和迁移；硬件转为租赁 |
| 持续费用 | 电力、制冷、维保、备件、运维人员、升级 | GPU 小时/月租、平台费、存储、流量、专线、托管和 SLA |
| 最低技术门槛 | 至少 TB 级显存和高带宽互联；8×MI355X 仅能作为已公开的功能验证参考 | 云侧需提供等效 8×MI355X、16×GB200/GB300 或经验证的其他拓扑 |
| 高效生产参考 | 官方建议 64+ 加速卡超节点；并发须压测 | 可按负载扩到多节点或 64+ 卡，须确认扩容时限和容量保证 |
| 数据控制 | 最强，可断网；离线升级流程较重 | 取决于单租户、控制面、运维权限、日志和备份位置 |
| 弹性 | 低，扩容受采购和机房周期约束 | 较高，但稀缺 GPU 可能需要长期容量承诺 |
| 退出成本 | 硬件残值、模型和平台迁移 | 数据导出、镜像与微调权重带走、专线和最低消费违约金 |
| 适用条件 | 强数据不出域、已有高密机房与 GPU 运维能力、负载长期稳定 | 需要隔离与弹性、上线周期紧、可接受云控制面和网络依赖 |

### 2. 三年总拥有成本公式

**本地离线：**

> 三年 TCO = 硬件与机房改造 + 实施集成 + 3 年电力制冷 + 3 年维保备件 + 3 年运维人工 + 升级与安全合规 − 期末残值

**专属云：**

> 三年 TCO = 初始部署迁移 + GPU 保底消费 + 平台与托管费 + 存储与流量 + 专线 + SLA 支持 + 运维人工 + 扩缩容与退出费用

两种方案必须使用同一业务负载测算：峰值并发、平均输入/输出 token、上下文分布、缓存命中率、可用性、容灾等级和数据保留期。只比较 GPU 数量或月租，会遗漏实现相同服务水平所需的副本和运维成本。

### 3. 三年预算区间

| 部署档位 | 首年主要配置 | 三年 TCO 预估 | 适用范围 | 置信度 |
|---|---|---:|---|---|
| 本地单节点验证/部门级生产 | 8×MI355X，单实例，无同城灾备 | **750万—1500万元** | 技术验证、低并发内部使用；计划停机维护 | 中低 |
| 本地双节点高可用 | 2×8 MI355X 或等效双副本 | **1500万—3000万元** | 业务连续性要求较高的内部服务 | 中低 |
| 本地 64 卡生产超节点 | 64×GB200/GB300 或经验证的等效平台 | **2800万—6500万元** | 高吞吐、多业务共享、生产级缓存和调度 | 低 |
| 专属云单节点 | 8×MI355X 独享节点，单租户网络和托管 | **750万—2200万元** | 快速上线、负载可调整、无需自建液冷机房 | 中 |
| 专属云双节点高可用 | 两个独享节点或跨故障域副本 | **1400万—4000万元** | 需要云侧高可用和容量保证 | 中低 |
| 专属云 64 卡资源池 | 64 卡独享或长期容量承诺 | **4000万元—1.35亿元** | 大规模生产；价格高度依赖预留折扣 | 低 |

三年 TCO 已计入基础实施、技术支持、运维人工、配套设施或云平台附加费。本地方案按期末硬件残值 15%—25%抵扣；专属云方案不产生硬件残值。业务应用开发、知识库数据治理、行业测评集建设和大规模微调没有纳入。

专属云月费可以拆成以下预算。

| 专属云成本 | 8 卡单节点 | 8 卡双节点高可用 | 64 卡资源池 |
|---|---:|---:|---:|
| GPU/CPU/内存纯算力 | 11万—36万元 | 22万—72万元 | 86万—285万元 |
| 单租户网络、存储和备份 | 1万—4万元 | 2万—7万元 | 5万—20万元 |
| 推理平台、监控和托管 | 2万—7万元 | 4万—12万元 | 8万—25万元 |
| SLA、技术支持和专线 | 1万—5万元 | 2万—8万元 | 3万—10万元 |
| **完整月费** | **15万—50万元** | **30万—95万元** | **100万—340万元** |

预留一年以上容量通常可以争取折扣，K3 发布初期的稀缺 GPU 也可能带来溢价。预算阶段可以用区间中位数，即单节点约 32万元/月、双节点约 63万元/月、64 卡约 220万元/月。

### 4. 公共 API 作为经济性基线

官方 K3 API 价格为缓存命中输入 0.30 美元/百万 token、未命中输入 3 美元/百万 token、输出 15 美元/百万 token，价格未含适用税费。它不属于私有化方案，但可作为采购的机会成本基线。

当数据允许进入公共 API 时，应先用真实业务流量计算年度 token 费用。低利用率或需求波动大的项目，即使要求更强隔离，也通常先比较专属云与公共 API；长期高利用率、严格数据不出域且已有机房能力的项目，再评估本地集群。

## 四、公开网传报价与官方口径差异

| 流传说法 | 核验结果 | 偏差原因 | 采购处理 |
|---|---|---|---|
| “K3 采用 MIT，企业可无条件商用” | 错误。正式许可证为 Kimi K3 License，含 MaaS 收入门槛和大规模产品品牌展示要求 | 沿用 K2 或权重发布前资料 | 以 2026 年 K3 LICENSE 原文为准 |
| “K3 输入统一 2 元/百万 token” | 不完整。约 2 元对应 0.30 美元的缓存命中输入；未命中输入为 3 美元，输出为 15 美元 | 把缓存优惠写成全部输入价 | 按命中、未命中、输出分别测算 |
| “4×/8×H100 可完整生产部署” | 与正式权重容量不符。8×H100 80GB 合计 640GB，低于约 1.56TB 权重 | 只按激活参数或早期估算计算 | 要求提供实机拓扑、权重精度、吞吐和长稳报告 |
| “开源后私有化几乎零成本” | 错误。许可费可为零，算力、互联、存储、实施和运维仍是主要成本 | 混淆权重许可与生产服务 | 按三年 TCO 评审 |
| “月之暗面提供本地机房、混合云标准企业套餐” | 官方公开页未见 K3 标准私有化产品目录和价格 | 将第三方集成能力或普通企业版泛化为官方方案 | 要求月之暗面主体或授权伙伴出具书面方案 |
| “永久授权/年订阅已有固定人民币报价” | 未找到官方公开依据；内部自用权重许可预算为 0 元，企业支持可先按 30万—200万元/年预留 | 销售口头价、其他模型报价或自媒体转载 | 将模型许可、支持、平台和 SLA 拆项比价 |

自媒体文章如果没有可核对的报价日期、模型版本、GPU 型号、精度、并发、上下文、SLA、税费和服务边界，其数字不进入采购基准库。

## 五、风险提示

1. **报价对象错位。** 权重许可、企业账号、公共 API、推理托管、专属云和本地交付是不同商品。询价函必须指定法律主体、模型版本和交付边界。
2. **新模型工程成熟度。** 权重于 2026 年 7 月 27 日发布，部署文档和推理框架仍处于快速适配期。生产采购应设置概念验证、性能验证和生产验收三个门槛。
3. **算力可得性。** MI355X、GB200、GB300 等硬件在中国境内的供货、合规、售后和交期存在不确定性。替代芯片能否运行 KDA、MXFP4/MXFP8 和多模态栈，需要实测。
4. **容量误判。** 只按 104B 激活参数估算显存会低估权重常驻需求；只按权重大小估算又会遗漏长上下文状态、工作区和副本。
5. **机房改造。** 高密 GPU 节点可能超出现有机柜的供电、承重和制冷能力。设备采购前完成电气、液冷、消防和网络勘察。
6. **性能不可直接继承。** 官方 API 使用 Mooncake 解耦推理和缓存架构。自托管相同权重不等于获得相同缓存命中率、时延、吞吐或单位 token 成本。
7. **数据与运维边界。** 专属云仍可能存在服务商控制面、远程运维、遥测、备份和跨境链路。合同应规定数据分类、地域、加密密钥、日志、删除证明和人员访问。
8. **许可证规模阈值。** MaaS 收入、产品月活和月收入增长可能改变授权义务。法务和财务需要建立持续监控。
9. **供应商锁定。** 自定义架构、量化格式、推理引擎补丁和专属云控制面会增加迁移难度。验收时要求交付配置、镜像、补丁、脚本、评测集和数据导出工具。
10. **公开报价时效。** GPU、汇率、电力、云折扣和模型版本变化快。所有预算锚点须在正式立项和招标前更新。
