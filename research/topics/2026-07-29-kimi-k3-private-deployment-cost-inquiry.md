## 一、调研概况

### 1. 核心结论

截至 2026 年 7 月 29 日，可以确认的费用口径如下。

1. **模型权重许可没有公开的永久授权费或年订阅费。** 月之暗面发布的 Kimi K3 License 明确以“free of charge”授予使用、修改、部署、微调、分发和销售等权利。一般企业在内部使用权重，不因用户数、并发数或算力规模向月之暗面支付公开列明的许可费。
2. **免费权重许可不包含交付服务。** 官方没有公开 K3 离线私有化产品包，也没有公开部署调试、适配、培训、SLA、年度技术支持、版本升级的标准报价。【需向厂商官方询证】
3. **算力是本地部署的主要成本。** K3 为 2.8 万亿总参数、1040 亿激活参数的 MoE 模型。AMD 对正式权重的测算约为 1.5609 TB；单机或单节点必须先解决 TB 级高带宽显存、互联、存储和供电问题。
4. **“能加载”与“生产可用”存在明显距离。** AMD 给出的 8×MI355X TP8 配方具备权重和单条 100 万 token 上下文的容量余量，但仍将单实例可用性表述为有待硬件可得性和通信规模验证。NVIDIA 给出 16×GB200、16×GB300 等配方。月之暗面的效率建议是 64 张以上加速卡的高带宽超节点。
5. **专属云尚无月之暗面公开标准价。** 公开可见的是官方按 token 计费 API，以及通过 Kimi Vendor Verifier 验证的第三方推理服务。独享裸金属、独享 GPU 池、单租户 VPC、数据驻留、离线更新等能力是否成立，取决于具体云厂商合同。【需向厂商官方询证】
6. **网传固定报价目前不可用于立项。** 未检索到月之暗面官网、Kimi 官方文档、官方模型仓库或正式采购公告披露 K3 私有化“永久授权价”“年费价”“每并发价”或“实施费”。任何具体人民币打包价在取得盖章报价单前，只能列为销售线索。

### 2. 两种方案的定义边界

| 方案 | 数据与权重位置 | 基础设施归属 | 网络条件 | 费用主项 |
|---|---|---|---|---|
| 企业本地机房离线私有化 | 权重、输入、输出、日志均在企业控制域 | 企业采购或融资租赁 | 可完全断网；升级通过离线介质 | GPU 集群、机房改造、实施、运维、备件 |
| 专属云私有化 | 权重与推理服务位于专属租户、VPC 或独享裸金属 | 云厂商或推理服务商 | 通常依赖云内网络和服务商控制面 | GPU 租赁、托管平台、专线、流量、SLA |

“企业版账号”“官方公共 API”“第三方共享 API”不自动等同于私有化。采购文件应把物理独享、资源池独享、VPC 单租户、数据是否用于训练、日志保留位置、运维人员权限和删除证明分别写清。

### 3. 证据可信度分级

| 等级 | 资料类型 | 可用于何种判断 |
|---|---|---|
| A | 月之暗面官网、Kimi API 文档、官方 GitHub/Hugging Face 仓库及许可证 | 模型参数、许可边界、官方 API 价格、官方部署建议 |
| B | NVIDIA、AMD 官方部署文档或产品资料 | 可运行拓扑、显存、功耗和软件栈要求 |
| C | 云厂商正式价目表、政府采购结果、具名技术媒体 | 预算锚点和市场区间；不能替代项目报价 |
| D | 自媒体、导航站、匿名社区、厂商软文 | 发现线索；不能作为采购定价依据 |

## 二、成本分项询证要点

### 1. 商业授权费用

#### 已确认

- K3 代码和权重采用自定义 **Kimi K3 License**，并非 MIT License。
- 一般内部使用不触发许可证第 2、3 条的附加要求。
- 向第三方提供可控制输入、参数或训练数据的“Model as a Service”业务，若许可方及关联方连续 12 个月合计收入超过 2000 万美元，继续将 K3 或其衍生模型用于任何商业目的前，须与月之暗面另行签约。
- 使用 K3 或衍生模型的商业产品或服务，若月活超过 1 亿，或月收入超过 2000 万美元，界面须显著展示“Kimi K3”。内部使用及通过月之暗面官方产品或认证推理伙伴使用的情形不受这两项要求约束。
- 许可证未设置按 GPU 数量、并发数或企业内部用户数计费的公开条款。

#### 采购询证

| 项目 | 当前公开结论 | 要求厂商书面确认 |
|---|---|---|
| 权重永久授权 | 一般使用免费；没有公开买断价 | 集团内部、子公司、外包人员、境内外分支是否均属于同一许可范围 |
| 年订阅 | 未见权重年订阅要求 | 年费是否仅对应技术支持、企业平台或托管服务 |
| 按算力/并发/用户计费 | 权重许可证未设置 | 官方交付包、控制台、网关或支持服务是否另行计费 |
| 微调与衍生模型 | 许可证允许修改和创建衍生作品 | 微调权重能否跨关联公司分发、能否交付客户、退出合同时如何处理 |
| MaaS 商业化 | 达到收入门槛须另签协议 | 收入口径、关联方范围、存量客户过渡期、授权费计算方式 |
| 品牌标识 | 达到月活或月收入门槛须展示 | 展示位置、尺寸、白标产品安排和商标使用许可 |
| 赔偿与担保 | 权重按“as is”提供，无保证 | 知识产权索赔、输出侵权、开源组件漏洞由谁承担 |

**预算口径：** 单纯下载权重用于企业内部推理，模型许可费可暂按 0 元列示；合同、实施和支持预算不得因此归零。涉及对外 API、代运营、SaaS 嵌入或集团多法人共享时，商业授权费用标注为【需向厂商官方询证】。

### 2. 配套硬件算力

#### 容量下限

| 依据 | 已公开配置 | 可确认的含义 | 尚不能确认 |
|---|---|---|---|
| 月之暗面官方 | 2.8T 总参数、104B 激活参数、1M 上下文；建议 64+ 加速卡超节点 | 生产效率依赖大规模高带宽互联 | 64 卡具体型号、吞吐、并发和 SLA |
| AMD 官方 | 权重约 1.5609 TB；8×MI355X、每卡 288 GiB，TP8；单条 1M 上下文已知额外状态约 14.427 GiB/卡 | 8 卡新一代高显存节点具备加载与功能验证的容量条件 | 生产吞吐、并发、框架额外内存和长稳测试 |
| NVIDIA 官方 | 16×GB200 聚合部署；16+16×GB200 预填充/解码分离；16×GB300 两副本；8+16×GB300 分离部署 | 16 卡及以上已有厂商级部署配方 | 国内供货、采购价格及等效国产算力方案 |

8×H100 80GB 只有 640GB 显存，不能容纳约 1.56TB 的正式权重。自媒体所称“4 张或 8 张 H100 即可完整生产部署”缺少容量依据。CPU 或 NVMe 卸载可以让模型在更低 GPU 显存下启动，吞吐、时延、并发和百万上下文能力会显著变化，不能直接视为生产配置。

#### 采购与租赁预算锚点

下列数字用于预算量级判断，不是月之暗面报价。美元折算人民币统一采用 **1 美元 = 7.2 元**的内部测算汇率，未含税、专线、存储、技术服务及资源稀缺溢价。

| 场景 | 计算方法 | 预算锚点 | 可信度 |
|---|---|---:|---|
| 8×MI355X 专属云算力，24×7 | Oracle 公开价 8.60 美元/GPU·小时 × 8 × 720 小时 | 约 4.95 万美元/月，约 35.7 万元/月；约 428 万元/年 | C，公开云价 |
| 64×同价加速卡，24×7 | 8.60 美元/GPU·小时 × 64 × 720 小时 | 约 39.63 万美元/月，约 285 万元/月；约 3424 万元/年 | C，仅作超节点量级推演 |
| 8×MI355X 本地采购 | GPU、CPU、内存、UBB、液冷、网络、存储、机柜、备件整体报价 | 【需向硬件厂商正式询价】 | 未公开 |
| 16×GB200/GB300 或 NVL72 | 国内可得性、出口限制和交期均会影响价格 | 【需向合规渠道正式询价】 | 未公开 |

云租赁锚点不能反推硬件成交价。长期预留实例、容量承诺、地域、电力、运维和稀缺资源会改变折扣；本地采购还要计入融资成本、折旧和残值。

#### 机房与配套

- **存储：** 正式权重约 1.56TB。考虑原始权重、格式转换、中间文件、回滚版本和双副本，初期宜预留 5—10TB 高速存储；模型多版本并行时继续扩容。
- **网络：** MoE 专家并行对互联敏感。普通以太网能够连接服务器，不代表可以达到官方超节点吞吐。NVLink/NVSwitch、Infinity Fabric 或等效高速互联的拓扑和带宽须写入验收条款。
- **供电与制冷：** MI355X 单模块最大板卡功耗 1400W，8 卡仅 GPU 峰值即 11.2kW。CPU、内存、网络和制冷叠加后，应按整机实测功率与机房 PUE 计费。NVIDIA GB200 NVL72 整柜约 120kW，传统机房可能需要配电与液冷改造。
- **冗余：** 单节点可以完成技术验证，无法天然满足生产高可用。N+1、双副本或预填充/解码分离会直接增加 GPU、网络和许可外的软件成本。
- **备件与交期：** 高端 GPU、交换模块、液冷部件和电源的备件比例、到货周期、原厂保修响应均需单列。

### 3. 实施服务费

月之暗面尚未公开 K3 私有化实施服务目录和统一人天单价。报价应拆分到可验收工作包，避免只写“部署一套”。

| 工作包 | 最低交付内容 | 当前收费口径 |
|---|---|---|
| 环境勘察 | 机房、电力、制冷、网络、服务器固件、操作系统和安全域评估 | 【需向厂商官方询证】 |
| 权重交付 | 下载或离线介质、哈希校验、软件物料清单、许可证清单 | 【需向厂商官方询证】 |
| 推理部署 | vLLM/SGLang/TokenSpeed/厂商栈安装，量化格式、并行策略和 API 适配 | 【需向厂商官方询证】 |
| 性能调优 | 预填充、解码、批处理、缓存、长上下文、并发和时延调优 | 【需向厂商官方询证】 |
| 平台集成 | API 网关、IAM、SSO、审计、限流、计量、知识库和业务系统接入 | 【需向厂商官方询证】 |
| 安全合规 | 漏洞扫描、镜像签名、端口基线、日志脱敏、数据删除和运维审计 | 【需向厂商官方询证】 |
| 测试验收 | 业务题集、质量基线、吞吐、P95/P99 时延、72 小时以上长稳及故障演练 | 【需向厂商官方询证】 |
| 培训移交 | 管理员、运维、开发、业务用户分层培训；文档和故障手册 | 【需向厂商官方询证】 |

立项测算可先按“验证环境、生产环境、灾备环境”分别估算工作量。人天单价、差旅、驻场周期、夜间割接、第三方系统改造和验收失败返工应在报价单中独立列示。

### 4. 后续成本

| 成本项 | 主要变量 | 询证要求 |
|---|---|---|
| 年度技术支持 | 5×8/7×24、响应和恢复时限、驻场、原厂或集成商支持 | 报固定年费、计次费和超范围人天价 |
| 版本升级 | 权重下载、推理框架升级、兼容改造、回归测试、灰度和回滚 | 确认首年是否包含，跨大版本是否收费 |
| 持续运维 | GPU/网络/存储监控、容量管理、漏洞和证书、故障处理 | 建议明确内部 2—4 个角色的责任，不以人数代替工作边界 |
| 电力制冷 | 整机平均功率、PUE、峰谷电价、需量电费 | 用机房账单和实测功率重算 |
| 硬件维保 | 原厂保修、备件池、上门时限、液冷维护 | 确认 3—5 年总价和停产替代方案 |
| 安全与合规 | 等保、密评、渗透、模型备案或算法合规评估 | 按行业与数据等级单列 |
| 业务运营 | 提示词、评测集、内容安全、人工复核、成本治理 | 纳入业务部门年度预算 |

开源推理框架可以免费取得，但集群升级、兼容性验证和故障定位仍会产生工程成本。K3 使用保留思考历史模式，多轮和工具调用必须原样回传 `reasoning_content` 与 `tool_calls`；网关或 Agent 框架不兼容会造成质量波动，也会增加联调和回归费用。

### 5. 限制条件

#### 并发与性能

- 官方没有公布自托管 K3 的固定并发上限。并发由 GPU 型号与数量、上下文长度、输出长度、批处理、缓存命中、预填充/解码拓扑和服务级目标共同决定。
- 100 万 token 是最大上下文能力，不代表每个并发请求都能以该长度运行。AMD 测算显示，单条 100 万 token 上下文在 TP8 下每卡已知额外状态约 14.427 GiB，且尚未计入内核工作区、通信缓冲、内存碎片和框架开销。
- 官方公共 API 的并发等级为 1—1000、RPM 为 3—10000、TPM 为 50 万—500 万，随累计充值档位变化。这套限流只适用于公共 API，不能套用到私有化验收。

#### 权重分发

- 复制或分发权重和实质性软件部分时，应保留版权和许可声明。
- 离线介质、镜像仓库、备份、灾备中心、集团共享及集成商临时访问均应登记副本、责任人和销毁流程。
- K3 权重约 1.56TB，跨地域同步、离线介质运输和多版本保留会产生存储、带宽和安全管理成本。

#### 商业化权限

- 企业内部办公、研发或生产辅助通常落入内部使用豁免。
- 对外提供可控制输入、参数或训练数据的推理、微调 API，可能构成许可证定义的 MaaS。
- 将模型能力嵌入固定产品功能，与向客户开放通用模型控制能力的法律后果不同。边界业务应由法务结合产品交互和合同审查。
- 月活、月收入和连续 12 个月收入阈值必须纳入合规监控，避免业务规模扩大后遗漏另签协议或品牌展示义务。

## 三、不同部署方案费用对比

### 1. 费用与门槛

| 维度 | 企业本地机房离线私有化 | 专属云私有化 |
|---|---|---|
| 模型许可 | 一般内部使用可按 0 元预算；特殊商业化另询 | 一般内部使用同上；托管平台和认证伙伴服务另收费 |
| 初始投入 | 高：GPU 集群、网络、存储、液冷、配电、实施 | 中：部署、专线、安全域和迁移；硬件转为租赁 |
| 持续费用 | 电力、制冷、维保、备件、运维人员、升级 | GPU 小时/月租、平台费、存储、流量、专线、托管和 SLA |
| 最低技术门槛 | 至少 TB 级显存和高带宽互联；8×MI355X 仅能作为已公开的功能验证参考 | 云侧需提供等效 8×MI355X、16×GB200/GB300 或经验证的其他拓扑 |
| 高效生产参考 | 官方建议 64+ 加速卡超节点；并发须压测 | 可按负载扩到多节点或 64+ 卡，须确认扩容时限和容量保证 |
| 数据控制 | 最强，可断网；离线升级流程较重 | 取决于单租户、控制面、运维权限、日志和备份位置 |
| 弹性 | 低，扩容受采购和机房周期约束 | 较高，但稀缺 GPU 可能需要长期容量承诺 |
| 退出成本 | 硬件残值、模型和平台迁移 | 数据导出、镜像与微调权重带走、专线和最低消费违约金 |
| 适用条件 | 强数据不出域、已有高密机房与 GPU 运维能力、负载长期稳定 | 需要隔离与弹性、上线周期紧、可接受云控制面和网络依赖 |

### 2. 三年总拥有成本公式

**本地离线：**

> 三年 TCO = 硬件与机房改造 + 实施集成 + 3 年电力制冷 + 3 年维保备件 + 3 年运维人工 + 升级与安全合规 − 期末残值

**专属云：**

> 三年 TCO = 初始部署迁移 + GPU 保底消费 + 平台与托管费 + 存储与流量 + 专线 + SLA 支持 + 运维人工 + 扩缩容与退出费用

两种方案必须使用同一业务负载测算：峰值并发、平均输入/输出 token、上下文分布、缓存命中率、可用性、容灾等级和数据保留期。只比较 GPU 数量或月租，会遗漏实现相同服务水平所需的副本和运维成本。

### 3. 公共 API 作为经济性基线

官方 K3 API 价格为缓存命中输入 0.30 美元/百万 token、未命中输入 3 美元/百万 token、输出 15 美元/百万 token，价格未含适用税费。它不属于私有化方案，但可作为采购的机会成本基线。

当数据允许进入公共 API 时，应先用真实业务流量计算年度 token 费用。低利用率或需求波动大的项目，即使要求更强隔离，也通常先比较专属云与公共 API；长期高利用率、严格数据不出域且已有机房能力的项目，再评估本地集群。

## 五、风险提示

1. **报价对象错位。** 权重许可、企业账号、公共 API、推理托管、专属云和本地交付是不同商品。询价函必须指定法律主体、模型版本和交付边界。
2. **新模型工程成熟度。** 权重于 2026 年 7 月 27 日发布，部署文档和推理框架仍处于快速适配期。生产采购应设置概念验证、性能验证和生产验收三个门槛。
3. **算力可得性。** MI355X、GB200、GB300 等硬件在中国境内的供货、合规、售后和交期存在不确定性。替代芯片能否运行 KDA、MXFP4/MXFP8 和多模态栈，需要实测。
4. **容量误判。** 只按 104B 激活参数估算显存会低估权重常驻需求；只按权重大小估算又会遗漏长上下文状态、工作区和副本。
5. **机房改造。** 高密 GPU 节点可能超出现有机柜的供电、承重和制冷能力。设备采购前完成电气、液冷、消防和网络勘察。
6. **性能不可直接继承。** 官方 API 使用 Mooncake 解耦推理和缓存架构。自托管相同权重不等于获得相同缓存命中率、时延、吞吐或单位 token 成本。
7. **数据与运维边界。** 专属云仍可能存在服务商控制面、远程运维、遥测、备份和跨境链路。合同应规定数据分类、地域、加密密钥、日志、删除证明和人员访问。
8. **许可证规模阈值。** MaaS 收入、产品月活和月收入增长可能改变授权义务。法务和财务需要建立持续监控。
9. **供应商锁定。** 自定义架构、量化格式、推理引擎补丁和专属云控制面会增加迁移难度。验收时要求交付配置、镜像、补丁、脚本、评测集和数据导出工具。
10. **公开报价时效。** GPU、汇率、电力、云折扣和模型版本变化快。所有预算锚点须在正式立项和招标前更新。
