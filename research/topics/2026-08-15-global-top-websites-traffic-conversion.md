全球访问量最大的十个网站，前四名全部属于 Alphabet 和 Meta。第五名已经变成 ChatGPT，电商网站和传统新闻网站都没有进入 Similarweb 2026 年 7 月的前十。

这组排名最容易被误读的地方，是把访问次数当成用户数，把网页流量当成平台全部流量，再把浏览深度当成商业价值。三种换算都会放大结论。

## 一、先给结论

1. **Google 仍然有数量级优势。** 2026 年 7 月，Similarweb 估算 google.com 月访问约 869.6 亿次。按 31 天和每次访问 8.68 页推算，日均约 28.1 亿次访问、243 亿 PV。
2. **头部流量由少数公司控制。** Alphabet 拥有 Google、YouTube，Meta 拥有 Facebook、Instagram、WhatsApp。两家公司控制 Similarweb 前十中的五个域名，且占据前四名。
3. **前十已经形成五类入口。** 搜索负责承接明确需求，视频和社交负责分配注意力，Reddit 承载社区经验，WhatsApp 承载关系与沟通，ChatGPT 直接生成答案和任务结果。
4. **日均 UV 普遍无法从公开数据可靠还原。** Similarweb 与 Semrush 的付费产品提供月度 unique visitors，公开页面主要提供月访问、页面深度和停留。月 UV 除以 31 得到的是“每天分摊的月度身份数”，无法代表当天去重用户。
5. **流量价值取决于转化链路。** 搜索看查询到点击、线索或订单；视频看观看到订阅、广告或商品；社交看互动到站外行动；AI 看免费到付费、个人到企业和对外部站点的引用；即时通信看对话到成交与服务完成。
6. **网站排名低估移动平台。** Similarweb 和 Semrush 的这类榜单统计桌面网页与移动网页，不含原生 App。TikTok、Instagram、WhatsApp、YouTube、Facebook 的完整使用规模远高于域名表呈现的部分。

### 为什么不填一个看起来完整的“日均 UV”

UV 要在同一天内对身份去重。登录账号、浏览器 Cookie、设备 ID 和跨设备身份图谱会给出不同结果。第三方平台还要处理 Cookie 删除、共享设备、隐私限制和机器人流量。

一些公开流量站把“月访问量 ÷ 30”标成 Daily Unique Visitors。这个计算得到的是日均 session，重复访问者仍被重复计算。Google、YouTube、X 等高频产品的误差尤其大。

Semrush 的月 UV 也代表估算的浏览器或设备身份，不一定对应真实个人。Google 约 60.54 亿月 UV 已接近 DataReportal 统计的 2025 年 10 月全球 60.4 亿互联网用户；多设备身份、模型误差和统计范围都会影响这个数字。

## 三、两套排名为什么会不同

Semrush 2026 年 7 月公开榜单按月访问量列出的前十，依次为 Google、YouTube、Facebook、Instagram、ChatGPT、Reddit、Wikipedia、X、成人网站和 WhatsApp；Bing 在 Semrush 榜单中降至第 16。Similarweb 同月把 X、Reddit、Bing、TikTok、WhatsApp排在第 6—10 位。

差异主要来自四个方面：

| 差异来源 | 会怎样改变结果 |
|---|---|
| 样本池 | 浏览器插件、合作数据、设备覆盖和国家权重不同 |
| 域名处理 | 是否合并子域名、地区域名、跳转域名和历史域名 |
| 机器人与异常流量 | 各家识别、过滤和外推规则不同 |
| 排名算法 | Similarweb 说明排名参考月 UV 与页面浏览；Semrush 公开榜单更直接展示估算访问量 |

因此，排名适合回答“谁处于同一量级”。两个供应商对 Bing 估算分别约 37.9 亿和 19.8 亿月访问，差距接近一倍，无法支持精确到百分点的市场份额判断。

[Cloudflare Radar](https://blog.cloudflare.com/radar-2025-year-in-review-internet-services/)提供了另一种旁证。它按 1.1.1.1 DNS 查询衡量“互联网服务”，会把同一服务的多个域名合并。2025 年前十是 Google、Facebook、Apple、Microsoft、Instagram、AWS、YouTube、TikTok、Amazon、WhatsApp。这个榜单衡量服务受欢迎程度，无法与单域名网页访问榜直接互换。

## 四、分门别类：十个网站在争夺什么

### 1. 搜索入口：Google、Bing

搜索流量的价值来自意图。用户主动输入问题、商品、地点或品牌，平台可以在查询发生时匹配广告、地图、购物、航旅和本地服务。

核心漏斗是：

`查询 → 搜索结果曝光 → 广告或自然结果点击 → 落地页 → 线索 / 订单 / App 安装`

值得跟踪的数据包括查询量、搜索用户数、每用户查询次数、广告覆盖率、点击率、每次点击成本、搜索后转化率、每次搜索收入、零点击比例和对外站点点击量。

Alphabet 2025 年第四季度披露，Google Search and Other 广告收入超过 630 亿美元，同比增长 17%；AI Mode 查询长度约为传统搜索的 3 倍，部分查询会继续追问。Microsoft 2026 财年第三季度披露，搜索广告收入扣除流量获取成本后同比增长 12%，Bing 月活首次达到 10 亿。两家公司都没有把网页 PV 直接换算为单次搜索收入。

### 2. 视频与推荐：YouTube、TikTok、Instagram

推荐系统先制造内容消费，再从观看中识别兴趣。广告、直播、电商和订阅可以共用同一套行为信号。

核心漏斗是：

`内容曝光 → 有效播放 → 观看时长 / 完播 → 互动或关注 → 商品点击 / 订阅 → 购买`

视频平台应重点观察有效播放率、3 秒与 10 秒留存、平均观看时长、完播率、重复观看、关注转化、广告可见率、点击率、商品详情访问、加购、支付、退款后 GMV 和创作者分成。

TikTok 的公开营销材料称，Search Ads 支持 Traffic、Landing Page View 和 Web Conversion 目标；一项平台内部案例显示，将 Search Ads 加入投放后，Eventbrite 点击率提升 66%、整体 CPA 下降 33%。这些是特定客户与广告产品的案例，不能视为全平台平均转化率。

### 3. 社交与社区：Facebook、Instagram、X、Reddit

社交平台同时处理关系、兴趣、公共事件和社区讨论。Facebook、Instagram 更依赖账号关系与推荐，X 更偏实时事件，Reddit 更偏主题社区和搜索长尾。

核心漏斗是：

`Feed 曝光 → 停留 / 互动 → 主页或链接点击 → 站内消息 / 站外页面 → 线索或订单`

共同指标包括覆盖人数、展示频次、停留时间、互动率、分享与收藏、关注转化、链接点击率、落地到达率、辅助转化和广告 ARPU。社区产品还要看搜索进入占比、帖子存活时间、评论深度、回访、贡献者留存和内容审核成本。

Meta 2026 年第一季度披露，旗下 App 日活跃人数为 35.6 亿，广告展示同比增长 19%，平均广告价格增长 12%。这是 Facebook、Instagram、Messenger、WhatsApp 等产品合并口径，不能拆成 Facebook 或 Instagram 的网页日 UV。

Reddit 2026 年第二季度披露 DAUq 1.303 亿、WAUq 5.146 亿，季度收入 8.05 亿美元，同比增长 61%。Reddit 将 ARPU 定义为季度收入除以平均 DAUq。它是前十中少数同时公开日活、周活和收入的公司，但 DAUq 覆盖平台整体，也包含 App。

### 4. AI 答案与任务入口：ChatGPT

ChatGPT 的单次会话可能生成答案、代码、图片、文件或代理操作。Pages / Visit 只有 4.29，无法反映一页对话里发生了多少轮请求、多少 token 和多少工具调用。

核心漏斗是：

`访问 / 提问 → 获得可用结果 → 追问或工具调用 → 注册 → 付费订阅 / 企业席位 / API 消费`

应该跟踪周活与日活、每用户会话数、每会话消息数、任务完成率、重试率、工具调用成功率、免费到付费转化、订阅留存、企业席位扩张、每百万 token 收入与推理成本。对内容网站而言，还要跟踪被引用次数、引用后点击、品牌搜索提升和 AI referral 的落地页转化。

OpenAI 2026 年公开披露 ChatGPT 周活超过 9 亿、消费者订阅超过 5,000 万、付费企业用户超过 900 万。用消费者订阅人数除以周活，只能得到约 5.6% 的粗略比例；两者时间窗、账号范围和产品口径不同，不能当成正式付费转化率。

### 5. 即时通信与商业对话：WhatsApp

WhatsApp 网页访问大部分发生在 web.whatsapp.com。消息产品的价值藏在会话、联系人和业务流程里，页面切换次数很难描述真实使用深度。

核心漏斗是：

`广告 / 二维码 / 联系入口 → 开始对话 → 有效咨询 → 报价或商品 → 支付 → 复购 / 服务完成`

适合跟踪新会话数、首次响应时间、有效咨询率、机器人解决率、转人工率、对话到订单转化、每次有效会话成本、退款、复购和客服节省。Meta 的商业化还包括 click-to-message 广告、WhatsApp Business Platform 与商业消息；这类收入不应归入 whatsapp.com 的网页 PV 收益。

## 五、应该收集哪些数据

一套可用于跨平台比较的数据字典，至少包含七层。

| 数据层 | 必备字段 | 回答的问题 |
|---|---|---|
| 流量规模 | 日期、域名、网页 / App、访问、PV、播放、消息 | 发生了多少次使用 |
| 去重覆盖 | 日 UV、周 UV、月 UV、登录用户、跨设备去重规则 | 实际触达多少身份 |
| 参与深度 | 时长、页 / 次、消息 / 会话、观看留存、回访频次 | 用户使用得多深 |
| 意图信号 | 查询词、内容主题、收藏、商品点击、咨询原因 | 用户想完成什么 |
| 转化事件 | 注册、关注、留资、加购、支付、订阅、企业席位 | 哪一步产生业务结果 |
| 收入与成本 | 广告收入、订阅、GMV、抽佣、推理、分成、获客与履约成本 | 流量是否创造利润 |
| 质量与风险 | 机器人、无效点击、退款、投诉、审核、隐私同意 | 数字能否持续使用 |

同一张报表还需要保留来源字段：平台后台、服务器日志、分析 SDK、财报披露或第三方估算。第三方估算不应覆盖真实后台值；公司合并口径也不能替代单产品口径。

## 六、转化该怎样计算

### 广告型平台

`广告收入 = 可变现展示量 ÷ 1,000 × eCPM`

`每访问广告收入 = 广告收入 ÷ Visits`

还要拆出广告负载、填充率、可见率和无效流量。页面多只能增加潜在广告位，广告库存是否可售由用户体验、地区、内容安全和需求共同决定。

### 搜索与线索

`线索贡献 = 查询量 × 结果点击率 × 落地到达率 × 留资率 × 有效率 × 成交率 × 单客贡献`

查询意图和关键词类别会让结果相差几个数量级。品牌词、导航词、知识问答和高客单商业词应分开计算。

### 订阅与 AI

`订阅收入 = 可付费活跃用户 × 付费转化率 × ARPU`

`订阅贡献 = 订阅收入 − 推理 / 内容 / 支付 / 客服等可变成本`

AI 产品还要观察每个任务的 token、工具和算力成本。高使用量可能同时推高收入与服务成本。

### 社交电商

`平台交易收入 = 商品访问 × 下单转化率 × 客单价 × 平台抽佣率`

`商家贡献利润 = 支付 GMV × 毛利率 − 退款 − 佣金 − 履约 − 售后 − 投放`

收藏、评论和分享属于中间信号。没有支付、留存或增量实验时，互动不能直接写成销售贡献。

### 商业对话

`会话贡献 = 新会话 × 有效咨询率 × 成交率 × 单客贡献 − 会话与人工成本`

客服场景还可以计算解决率、平均处理时间、一次解决率和节省的人工工时。

## 七、所有权与流量集中

| 最终控制方 | 前十网站 | 主要变现 |
|---|---|---|
| Alphabet | Google、YouTube | 搜索与视频广告、订阅、云及生态导流 |
| Meta | Facebook、Instagram、WhatsApp | 信息流广告、商业消息、交易与企业工具 |
| OpenAI | ChatGPT | 消费订阅、企业席位、API 与平台服务 |
| X Corp. | X | 广告、订阅、数据与生态服务 |
| Reddit | Reddit | 广告、数据许可及其他服务 |
| Microsoft | Bing | 搜索广告、Edge / Windows 分发、Copilot 入口 |
| ByteDance | TikTok | 广告、电商、直播及交易服务 |

前四名由两家公司控制，说明默认入口和账号体系仍然有极强的规模效应。第 5—10 名则出现了新的分工：ChatGPT 承接答案和任务，Reddit 提供社区语料与经验，X 承接实时事件，Bing 把搜索与 Copilot 结合，TikTok 把推荐、搜索和交易结合，WhatsApp 把公开流量转入私密对话。

## 八、外部研判

### PV 的解释力正在下降

无限滚动、单页应用、视频自动播放和 AI 对话都让“一个页面”失去统一含义。YouTube 的一次页面加载可能包含几十分钟视频，ChatGPT 的一页可能完成十轮任务，WhatsApp 的一个页面可能承载全天沟通。跨产品比较时，活跃用户、有效时长、任务完成和商业事件更有解释力。

### 搜索、社交、社区和 AI 正在互相进入对方的场景

TikTok、Instagram、Reddit 承接越来越多搜索需求；Google 和 Bing 在结果页生成答案；ChatGPT 输出链接、购物和工具结果；WhatsApp 把广告点击变成对话。分类仍有用，边界已经变得模糊。

### AI 已经成为全球级入口，转化披露仍少

ChatGPT 进入网站流量前五，说明用户已经把生成式 AI 当成高频目的地。OpenAI 披露周活、订阅和企业用户，尚未公开网页日 UV、免费到付费 cohort、每次任务收入或完整单位经济性。外部只能确认规模，无法精确判断单个网页访问的价值。

### 内容供给方要同时看“被访问”和“被使用”

Reddit、Wikipedia、新闻网站和专业内容站向搜索与 AI 提供语料。答案在平台内完成后，来源站点可能获得引用，却未必获得点击。品牌提及、引用覆盖、站外搜索、直接访问、注册和最终成交应放在同一归因框架中观察。

## 九、未能验证

- 未找到十个网站 2026 年 7 月同口径、可公开下载的日 UV 数据。付费 API 可以返回 unique visitors，公开页面不足以完成复核。
- 未找到 Similarweb 与 Semrush 对跨设备去重、子域名合并和机器人过滤的完整可复现算法。
- X 与 TikTok 没有提供可与上市公司财报同等级审计的 2026 年全球网页日活、广告收入和转化数据。
- Meta 只披露 Family of Apps 合并日活，无法拆分 Facebook、Instagram 和 WhatsApp，也无法只取网页。
- OpenAI 的周活、消费者订阅和企业付费用户属于不同产品与时间窗口，无法据此得到正式付费转化率。
- Pages / Visit 对视频自动播放、无限滚动、聊天线程和单页应用的可比性有限，日均 PV 仅作量级估算。
- 公开榜单不含原生 App，无法代表每个互联网服务的完整流量和使用时长。
