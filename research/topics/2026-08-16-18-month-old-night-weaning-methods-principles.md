> 适用范围：已经满 18 个月、总体健康、生长曲线稳定、白天能够正常吃饭和喝奶的孩子。早产、低体重、生长迟缓、慢性病或特殊喂养需求的孩子，应先让儿科医生评估。戒夜奶不等于断母乳，也不要求孩子整夜完全不醒。

## 一、先给结论

1. **健康的一岁半孩子通常可以戒夜奶。** 这个年龄的主要营养应由白天的三餐、加餐、母乳或其他奶类共同提供。夜间仍可以醒，但可以逐渐学会在没有奶的情况下再次入睡。
2. **最稳妥的方法是渐进减少，加上固定替代安抚。** 母乳每两晚减少 2—5 分钟；瓶喂每两晚减少 20—30 毫升，降到 60 毫升以内后停止。每次减少后都用拥抱、拍抚、声音或陪伴完成重新入睡。
3. **先拆开“吃奶—睡着”的联结。** 把最后一次奶提前到睡前流程前半段，喝完奶后刷牙，再进行洗漱、故事、关灯和安抚。孩子清醒或困倦时进入睡眠位置，比含着乳头或奶瓶入睡更有利于减少夜醒后的重复索取。
4. **白天补足营养，但不要用过量奶填满胃。** 国家卫健委资料建议 1—2 岁幼儿每天安排三次正餐、两次加餐，奶量大约 400—600 毫升；母乳亲喂无法精确计量，可以结合正餐摄入、生长曲线和排尿判断。
5. **夜间奶瓶应优先退出。** 乳牙萌出后，含奶睡觉会延长牙齿接触可发酵碳水的时间。国家卫健委建议 1 岁后尽量减少奶瓶，1 岁半至 2 岁停止使用奶瓶。
6. **方法是否成功，看的是“夜醒后不靠奶复睡”。** 一岁半孩子仍可能因睡眠周期、分离焦虑、出牙或环境变化醒来。把“零夜醒”当目标，容易让家长不断升级干预。

## 二、先判断：孩子夜里醒来属于哪一种

连续记录 3 个晚上，比直接选一种“睡眠训练法”更有用。记录入睡时间、每次夜醒时间、吃奶时长或毫升数、是否有持续吞咽、用其他方式能否安抚、白天三餐与奶量、午睡和身体不适。

| 夜醒类型 | 常见表现 | 优先处理 |
|---|---|---|
| 白天摄入不足 | 晚餐吃得少，夜里一次能持续吃很久并有明显吞咽，早晨仍很饿 | 先调整白天正餐、加餐和奶量，再减夜奶 |
| 入睡联结 | 每次醒来都要含乳或含奶瓶，吃奶很短，吸几口就睡 | 把奶移出入睡最后一步，练习其他复睡方式 |
| 规律性索取 | 每晚几乎在同一时间醒，家长一有动静就立即喂 | 延迟回应、固定无奶时段或逐步推迟喂奶时间 |
| 分离焦虑 | 白天也更黏照护者，换环境、入托或家庭变化后加重 | 保留回应与身体接触，用陪伴递减法 |
| 疼痛或疾病 | 突然频繁夜醒，伴发热、鼻塞、抓耳、咳嗽、湿疹、呕吐或明显哭痛 | 暂停计划，先处理身体问题 |
| 作息不匹配 | 上床后很久不睡、白天午睡过晚或总睡眠过多 | 调整午睡和上床时间，可尝试“就寝时间渐移” |

短暂吸几口并迅速睡着，通常更接近安抚和睡眠联结；长时间有力吸吮不能单独证明营养不足。判断饥饿还要结合白天摄入、生长、排尿和医生评估。

## 三、开始前的准备

### 1. 确认身体和营养条件

适合开始的信号包括：近期没有生病，体重和身高沿自己的生长曲线发展，白天能够完成规律进餐，精神和排尿正常，照护者能够连续执行至少一周。

[国家卫健委托育机构婴幼儿喂养与营养指南](https://www.nhc.gov.cn/rkjcyjtfzs/c100147/202201/a7d3fc17153f410ea97270814a3e662f.shtml)建议，12—24 月龄幼儿逐步适应家庭日常饮食；1—2 岁可以在母乳喂养同时引入鲜奶、酸奶、奶酪等乳制品，奶及奶制品参考量约 500 毫升。[国家卫健委 2025 年发布会](https://www.nhc.gov.cn/xcs/c100122/202508/8458a47948274283ab01c6cc672d8015.shtml)给出的 1—2 岁每日奶量范围为 400—600 毫升，并建议三次正餐和两次加餐。

这些数值是群体参考，不是要求每个孩子每天喝到同一个数字。母乳、牛奶、酸奶和奶酪要合并考虑，正餐质量和孩子的生长趋势更重要。

### 2. 统一照护者的规则

开始前约定四件事：

- 哪个时间段不再喂奶；
- 哪位照护者负责第一次夜醒；
- 使用哪些安抚动作和固定短句；
- 哭到什么程度会抱起安抚，出现哪些身体信号会停止计划。

照护者每晚采用完全不同的边界，孩子很难预测下一步，也更容易持续尝试原来的吃奶方式。

### 3. 把睡前奶提前

可以把流程改成：

`晚餐 / 加餐 → 奶 → 刷牙 → 洗漱换睡衣 → 讲故事或拥抱 → 关灯 → 入睡`

奶和入睡之间留出一段清醒活动，哪怕只有 10—20 分钟，也在改变原有联结。刷牙放在所有含热量食物和饮料之后。刷牙后如果口渴，只提供少量白水，优先使用水杯。

## 四、五种可执行的方法

### 方法一：按量或时长渐减

这是适用面最广、冲突相对较低的方法。

**母乳亲喂：**

1. 先测两晚平常一次夜奶大约吃多久；
2. 每两晚缩短 2—5 分钟；
3. 缩短后立即换成拥抱、拍抚、哼唱或固定短句；
4. 降到 5 分钟以内时，停止这一顿并直接安抚；
5. 多次夜奶时，一次只处理一顿，通常先处理最短或最早的一顿。

**瓶喂：**

1. 每两晚减少 20—30 毫升；
2. 降到 60 毫升以内后停止；
3. 不增加奶粉浓度，也不把配方奶不断加水稀释；
4. 不用果汁、甜奶、蜂蜜水或米粉奶替代；
5. 白天同步把奶瓶过渡为敞口杯或无阀训练杯。

澳大利亚政府支持的 [Raising Children Network 夜间断奶指南](https://raisingchildren.net.au/toddlers/sleep/better-sleep-settling/night-weaning)采用了相同的递减幅度，并指出健康的母乳喂养孩子满 12 个月后可以考虑夜间断奶。18 个月孩子已经超过这一年龄线，个体生长和摄入情况仍应优先。

**底层原理：**逐步降低夜奶带来的热量、吸吮和亲密接触强度，同时保留安全感。孩子经历的预测误差较小，哺乳者出现胀奶的概率也比突然完全停止更低。

### 方法二：建立“无奶时间窗”

适合夜奶次数多、每次时间不长的孩子。

先设一个家庭能够执行的窗口，例如晚上 11 点到凌晨 3 点不喂奶。窗口内所有夜醒都用同一套安抚；两三晚稳定后，把结束时间每两晚向后推 30—60 分钟，直至覆盖整个夜间。

也可以保留一顿固定夜奶，其他夜醒不喂。固定夜奶逐步推迟到清晨，再与起床后的第一顿合并。

**底层原理：**时间边界比“今天看孩子哭得凶不凶”更可预测。孩子逐渐学到夜醒与吃奶之间不再是即时、必然的关系。

### 方法三：由不喂奶的照护者接手

母乳亲喂家庭可以让另一位熟悉的照护者负责前半夜或最常见的一次夜醒。对有些孩子而言，闻到乳汁或靠近平常喂奶者，会更容易启动已经形成的吃奶预期。

接手者使用固定顺序：观察几秒、轻声回应、手放在身上、拍抚、必要时抱起，平静后再放回睡眠位置。夜里保持光线暗、交流短，不开灯玩耍。

**底层原理：**环境线索发生变化后，旧的“看到妈妈—立即吃奶”链条较难自动启动；孩子有机会在另一位安全照护者帮助下建立新的复睡路径。

### 方法四：陪伴递减，也叫“露营法”

适合分离焦虑强、家长不愿采用长时间离开的家庭。

1. 前几晚坐在孩子睡眠位置旁，使用轻拍或触摸；
2. 孩子适应后停止触摸，只保留声音和在场；
3. 每隔两三晚把椅子向门口移动一小段；
4. 夜醒时回到当前阶段，保持同样做法；
5. 整个过程可能需要 1—3 周。

[Raising Children Network 的陪伴递减方案](https://raisingchildren.net.au/toddlers/sleep/better-sleep-settling/camping-out)强调逐步减少喂、拍、抱和陪睡强度，同时在孩子明显难过时仍然回应。

**底层原理：**先保留照护者在场这一安全线索，再通过塑造逐步降低帮助强度。它通常更慢，家庭较容易保持一致。

### 方法五：渐进式查看或就寝时间渐移

**渐进式查看**是把孩子清醒地放到安全睡眠位置，离开后按预先设定的短间隔回来查看、安抚，再次离开。查看要简短、平静，不在每次回来时恢复喂奶。家长可以采用固定间隔，也可以逐次延长。

**就寝时间渐移**适合躺下后长期睡不着的孩子。先把上床时间临时调到孩子通常真正睡着的时间附近；连续几晚能够较快入睡后，每隔数晚提前 10—15 分钟。

美国睡眠医学会的[儿童睡前问题与夜醒行为干预参数](https://aasm.org/resources/practiceparameters/pp_nightwakingschildren.pdf)把渐进式查看、积极睡前流程和就寝时间渐移列为有效的行为方法。一项纳入 43 名 6—16 月龄婴儿的[随机对照试验](https://digital.library.adelaide.edu.au/dspace/handle/2440/106024)发现，渐进式查看和就寝时间渐移改善了入睡时间或夜醒，12 个月随访未发现依恋差异。样本很小，年龄也没有覆盖一岁半，不能据此宣称任何方法对所有孩子都无风险或必然有效。

**底层原理：**渐进式查看减少哭闹后获得原有喂奶结果的频率；就寝时间渐移利用睡眠压力，让床和快速入睡重新形成稳定联系。

## 五、一个可调整的 7—14 晚方案

| 阶段 | 家庭动作 | 观察指标 |
|---|---|---|
| 准备 3 天 | 记录夜醒和奶量；补齐白天三餐两点；把睡前奶移到刷牙前 | 夜奶次数、时长或毫升、白天进食、午睡 |
| 第 1—2 晚 | 保留最重要的一顿，其余夜醒由固定照护者按同一顺序安抚 | 是否真的持续吞咽、其他安抚能否奏效 |
| 第 3—4 晚 | 母乳每顿减 2—5 分钟，或瓶喂减 20—30 毫升 | 哭闹持续时间、家长能否保持稳定 |
| 第 5—6 晚 | 停掉已经很短或少于 60 毫升的一顿；保留陪伴 | 夜醒后复睡时间、白天是否更饿 |
| 第 7 晚起 | 夜间只用安抚和少量杯装白水；奶留到约定的早晨时间 | 连续 3 晚趋势，不看单晚成败 |
| 尚未稳定 | 每个阶段多停留 2—3 晚，或者改用更慢的陪伴递减 | 家庭压力、孩子身体状态、执行一致性 |

一次有三四顿夜奶的孩子，不必在第一晚全部取消。可以每 3—5 晚处理一顿，整个过程延长到两三周。生病、旅行、刚入托或主要照护者变化时，先暂停推进；恢复后回到上一个已经稳定的阶段。

## 六、底层原理：孩子为何会反复找奶

### 1. 夜醒是正常现象，复睡方式才是训练对象

睡眠由多个周期组成，周期转换时出现短暂觉醒很常见。成人通常翻身后继续睡，幼儿可能会寻找入睡时存在的条件。如果入睡最后一刻含着乳头、奶瓶或被持续摇抱，夜醒后也更可能要求恢复同样条件。

戒夜奶改变的是“夜醒—吃奶—入睡”这条链，不是消灭所有夜醒。

### 2. 即时喂奶形成了很强的强化

奶同时带来味觉、吸吮、体温、拥抱和家长关注，回报速度极快。只要孩子哭到某个强度后偶尔还能得到奶，原来的索取行为就可能持续更久。这在学习理论中属于间歇强化。

所以，一致性并不意味着不回应孩子。家庭可以稳定地回应、拥抱和安抚，同时稳定地不恢复已经取消的夜奶。

### 3. 新习惯需要替代路径

只拿走奶而没有增加触摸、声音、陪伴或可预测流程，孩子失去的是整套调节方式。有效方案通常都包含替代：固定短句、拍抚、抱起再放下、照护者在场、安抚巾或其他符合安全要求的睡眠线索。

替代方式也会逐步减弱。目标是让帮助从喂奶降到拥抱，从拥抱降到触摸，从触摸降到声音或短暂在场。

### 4. 昼夜节律和睡眠压力决定“什么时候容易睡”

固定起床时间、白天接触自然光、适量活动、不过晚的午睡和稳定睡前流程，可以让身体更容易在相近时间进入睡眠。孩子尚未困倦时过早上床，容易出现长时间抗拒；已经过度疲劳时，情绪调节也会更困难。

国家卫健委[托育机构保育指导大纲](https://zc.gjzwfw.gov.cn/art/2022/11/29/art_14_60874.html)建议 13—24 月龄固定睡眠和唤醒时间，坚持睡前活动，逐渐培养独自入睡的习惯。

### 5. 白天和夜间会发生热量补偿

减少夜奶后，孩子白天短期变饿、早餐吃得更多很常见。反方向也成立：夜里摄入大量奶液，可能降低早餐和正餐食欲，使夜间饥饿继续存在。

调整重点是把营养逐步搬到白天，提供含铁动物性食物、蛋、谷薯、蔬果和适量乳制品。不要靠睡前强塞食物或在奶瓶中加米粉来换睡眠。美国儿科学会指出，[在奶瓶中加入米粉不能帮助孩子睡整夜](https://www.healthychildren.org/English/healthy-living/growing-healthy/Pages/baby-food-and-feeding.aspx)，还会带来不需要的额外热量。

### 6. 夜间口腔环境放大了频繁吃奶的风险

夜间唾液分泌减少，奶液中的可发酵碳水在牙面停留更久。风险与牙齿是否萌出、频率、持续时间、刷牙和氟化物暴露共同相关。

[国家卫健委《中国居民口腔健康指南》](https://www.nhc.gov.cn/wjw/jkshfs/200909/058b3e9ade454a3f9f8bfe807ae78aaa.shtml)建议乳牙萌出后避免含甜奶或甜饮料的奶瓶入睡，1 岁后减少奶瓶，1 岁半至 2 岁停止使用。英国 NHS 也建议[第一颗乳牙萌出后开始刷牙，并避免 1 岁后继续鼓励使用奶瓶](https://www.nhs.uk/start-for-life/how-to-take-care-of-your-baby-or-toddlers-teeth/)。

[美国儿童牙科学会 2025 年政策](https://www.aapd.org/globalassets/media/policies_guidelines/p_eccconsequences.pdf)将 1 岁后的按需或夜间奶瓶、频繁夜间母乳列为应避免的龋齿风险因素，同时强调低龄儿童龋是口腔菌群、牙釉质、饮食频率、清洁习惯和社会环境共同作用的多因素疾病。夜奶会增加风险，不代表单凭一次或几次夜奶就能预测孩子是否患龋。

世界卫生组织仍建议[母乳喂养持续到 2 岁或更久](https://www.who.int/health-topics/breastfeeding)。继续白天母乳与减少乳牙萌出后的频繁夜间喂养可以同时进行，两项目标没有冲突。

## 七、哭了应该怎么办

改变熟悉流程时出现抗议很常见。哭声需要被判断和回应，但哭本身不能告诉家长孩子是饥饿、疼痛、愤怒还是希望恢复旧习惯。

可以按强度分层：

- 哼唧或短暂翻动：先观察几十秒，看能否自行回落；
- 持续哭：用声音、触摸和拍抚回应；
- 明显失控：抱起安抚，平静后再放下；
- 哭声异常、伴疼痛或呼吸问题：停止训练并检查身体。

家长不需要在“立即喂奶”和“完全不管”之间二选一。回应孩子，同时维持当晚已经确定的无奶边界，是多数渐进方法的共同部分。

如果家长开始愤怒、失控或极度困倦，应把孩子放在安全位置，自己离开片刻冷静，或者让另一位照护者接手。不要摇晃孩子。

## 八、常见无效或高风险做法

| 做法 | 问题 |
|---|---|
| 奶瓶里加米粉、麦片 | 没有可靠证据能延长整夜睡眠，增加额外热量和呛噎风险 |
| 把配方奶冲浓 | 改变水和营养素比例，可能增加肾脏和脱水风险 |
| 不断把配方奶稀释 | 营养和电解质比例失去标准，也把奶瓶联结继续保留下来 |
| 用果汁、蜂蜜水或甜奶替代 | 继续提供夜间糖分，增加龋齿风险 |
| 让孩子含着奶瓶睡 | 延长牙齿接触奶液的时间，也不利于退出奶瓶 |
| 白天限制饮食，指望晚上更累 | 会增加真实饥饿和情绪压力 |
| 只戒夜奶，不改变奶睡 | 入睡联结仍在，夜醒后更容易持续索取 |
| 每晚更换规则 | 偶尔恢复夜奶会让孩子更长时间尝试原来的方式 |
| 自行使用褪黑素或镇静类药物 | 无法解决喂养和睡眠联结，幼儿使用应由医生评估 |

## 九、这些情况先不要自行推进

出现以下情况，应暂停戒夜奶并咨询儿科、儿童保健、口腔科或有资质的哺乳顾问：

- 体重下降、生长曲线明显放缓或医生认为需要夜间补充营养；
- 早产、低出生体重、代谢性疾病、糖尿病、严重食物过敏或其他特殊喂养计划；
- 持续呕吐、腹泻、发热、明显疼痛、吞咽困难或进食呛咳；
- 夜间打鼾伴憋气、呼吸暂停、胸腹反常起伏或长期张口呼吸；
- 异常口渴、排尿明显增多、精神差或脱水迹象；
- 夜醒突然显著增加，并伴抓耳、严重鼻塞、湿疹瘙痒或其他疾病表现；
- 连续执行两周仍毫无改善，或者孩子和照护者的情绪、睡眠已经明显受损；
- 哺乳者出现持续胀痛、乳房红肿、发热或疑似乳腺炎。

渐减母乳期间如果胀奶，可以少量挤出到舒适为止，避免每次完全排空后继续刺激相同产量。出现硬结、红肿、发热或全身不适时及时就医。

## 十、怎样判断已经成功

可以用连续一周的趋势判断：

- 夜间奶液次数和总时长持续下降，最后停止；
- 孩子夜醒后能够通过一种以上方式重新入睡；
- 白天正餐、加餐和奶类摄入稳定；
- 精神、排尿和生长没有异常；
- 入睡和复睡所需的家长帮助逐渐减少；
- 家庭总体睡眠和压力有所改善。

孩子偶尔在生病、出牙、旅行或分离焦虑期重新要求吃奶，不代表此前的努力失效。先提供更多安抚，身体恢复后再回到原有边界即可。

## 十一、未能验证

- 没有一项高质量研究能够证明某一种戒夜奶方法对所有 18 月龄孩子最有效。
- 现有行为睡眠试验的年龄、样本量和干预方式差异较大，很多研究依赖家长报告；关于长期依恋和情绪发展的证据仍有限。
- “几天一定戒掉”“哭几晚就会成功”“母乳孩子必然更难戒”等说法缺少适用于所有家庭的证据。
- 奶量、睡眠时长和夜醒次数存在显著个体差异，公开指南只能提供范围，不能替代对生长曲线、饮食记录和疾病信号的个体评估。
