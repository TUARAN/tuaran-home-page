WorkBuddy 仍在快速改界面。操作路径、模型名单和积分规则以客户端最新版本与[官方文档](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Task-Bar)为准。重要文件先备份，再让它改。

你已经会用 ChatGPT：问一句，拿一段文字，剩下的表格、PPT、文件夹还得自己动手。WorkBuddy 的差别在权限。它能在你指定的文件夹里读文件、改文件、生成新文件。一句话交代清楚，它会自己拆步骤、自己调用技能、把成品放到工作目录里。

社区有时把它叫「虾」，来自开源项目 OpenClaw 的龙虾梗。桌面软件的正式名字是 WorkBuddy，和编程助手 CodeBuddy 共用账号体系。

## 一、先给结论

**第一周只做一件事：在电脑上，用一个隔离文件夹，把一件真实办公活干完。**

五条够用：

1. **只从官网下载。** 入口是 [codebuddy.cn/work](https://www.codebuddy.cn/work/) 或 [workbuddy.cn](https://www.workbuddy.cn/)。Windows 10+ 选 x64（兼容 ARM64）；Mac 选 ARM64（M 系列）或 x64（Intel）。公开页面写 macOS 12.0+。官网另有 iOS、Android、鸿蒙电脑版和鸿蒙手机版入口，小白第一周仍以桌面端为准：本机文件权限、产物预览和技能安装都在电脑上最完整。手机先当遥控器，不当主工作台。
2. **每个任务一个文件夹。** 发票进「发票整理」，周报进「周报」。不要把整个桌面或整个用户目录交给它。
3. **权限按三档放开。** Ask 只看不改；Plan 先出计划你点头；Craft 直接动手。新手第一次用 Ask，确认它读对了再切 Craft。
4. **指令写成「做什么 + 有什么 + 做成什么样」。** 素材在哪、输出格式、读者是谁，写进同一条消息。
5. **远程、自定义连接器、专家团可以后装。** 人还在电脑前时，主界面「新建任务」比助理页面好用。QQ 机器人、企微 URL 回调、自建 MCP 适合有技术背景再配。

30 分钟路径：下载 → 微信登录 → 新建隔离文件夹 → Ask 读一份文件 → Craft 产出一份可打开的 Word / Excel / PPT → 在右侧「产物」里验收。

## 二、装上并能登录

### 1. Windows

打开官网，选 WorkBuddy，下载安装包。双击 `WorkBuddySetup.exe`，同意协议，按向导点完即可。腾讯云开发者社区 2026 年 3 月的安装说明写安装包大约 150–180 MB，以实际下载为准。

启动后点登录。常见路径是网页授权 + 微信扫码。勾选服务条款和隐私协议后再扫。登录成功会回到客户端。

头像菜单里可以切语言、切浅色 / 深色主题，也可以点「检查更新」。已是最新版会直接提示；有新版本会走下载安装。检查更新报错时，卸载后回官网重装通常比在旧包上死磕更快。

### 2. Mac

官网按芯片分流：M 系列选 **Mac ARM64**，Intel 选 **Mac X64**。下完打开 dmg，把图标拖进 `Applications`。装完后推出安装盘。

用程序坞或 `Command + 空格` 搜 WorkBuddy 启动。登录同样走网页 + 微信扫码。电脑已登录微信时，有时会出现快捷登录。

macOS 常见两道坎：

| 现象 | 公开口径里的处理 |
|---|---|
| 提示安装包已损坏 | 社区与产品侧说明里，多次指向重启后再装。原因被解释为从 dmg 拖到 Applications 时，Finder 按文件复制，过程中可能出现短暂不一致，触发签名校验失败。官网直接下载或应用内更新较少碰到。 |
| 无法写入程序用户数据 | 先检查用户目录权限。有技术背景可在终端执行：`sudo mkdir -p ~/.WorkBuddy && sudo chown -R $(whoami) ~/.WorkBuddy && sudo chmod 775 ~/.WorkBuddy`，然后重启软件。 |

覆盖安装一般不会清掉本地数据。用「清理类卸载工具」则可能连配置一起删，卸载前先看它勾了什么。

### 3. 登录后先看三处

1. **积分余额。** 头像 → 积分看板。WorkBuddy 与 CodeBuddy 共用账户，额度在[套餐页](https://www.codebuddy.cn/profile/plan)采购。免费档有月积分上限，复杂长任务会烧得很快。
2. **工作目录入口。** 在新建任务的输入区附近，有选择文件夹的按钮。路径不用手敲：Windows 类似 `C:\Users\你的用户名\Desktop\发票整理`，Mac 类似 `/Users/你的用户名/Desktop/发票整理`。点选即可。
3. **安全边界。** 只授权当前任务需要的文件夹。批量删除、覆盖原文件、连邮箱发信，都先小范围试一次。试用阶段把身份证、银行卡、未公开合同排除在工作目录外。模型会把文件内容送去云端推理，工作目录里有什么，就等于这次任务可能上传什么。

配置和会话默认存在本机，不随账号同步到另一台电脑。两台电脑各装一份，远程助理通常连的是最近一次登录的那台；公开 FAQ 对「指定哪台机器」仍写得含糊，当未能完全验证项。

## 三、第一次任务：30 分钟内交一份成品

打开主界面，点 **新建任务**。左侧是功能区，右侧是对话。未指定文件夹时，系统会给这个任务建一个隔离工作目录，常被叫作 Claw 目录。图省事可以用它；图可控，自己建文件夹。

建议你现在就建一个叫 `workbuddy-试跑` 的文件夹，把一份不敏感的会议记录、发票照片或 Excel 丢进去，把它设为工作目录。

### 1. 先 Ask，确认它看懂了

把模式切到 **问一问（Ask）**。Ask 可以读文件、回答问题，不改你的磁盘。发一条：

```text
请只阅读当前工作目录，列出所有文件名、大致内容和你认为可以帮我做的 3 件事。
不要新建、修改或删除任何文件。
```

看它列得对不对。文件名读错、把发票认成合同、把草稿当成终稿，都在这一步拦住。Ask 适合合同条款检索、表格口径确认、先问做法再动手。

### 2. 再 Craft，把活干完

切到 **做一做（Craft）**。Craft 是默认执行模式：整理文件夹、生成文档、做 PPT、改表格，它会直接写文件。权限最大，效率也最高。指定好工作目录、做好备份再用。

把刚才那份素材换成一条完整指令。模板是：

```text
工作目录：当前文件夹。
要做的事：【整理报销 / 写纪要 / 做周报】。
已有材料：【文件名或类型】。
交付物：【Excel / Word / PPT】，保存到当前文件夹。
格式要求：【字段、排序、读者】。
限制：不要改工作目录以外的文件；不要删除原文件；原件不够清晰时在结果里标注「待核对」。
```

回车发送。不必盯着进度条。可以再开第二个任务处理另一件事。侧边栏像聊天列表，点进去看每条任务的过程和结果。

### 3. 在右侧验收，不要只看聊天

对话右上角可以打开结果面板，四个标签分工不同：

| 标签 | 看什么 |
|---|---|
| 产物 | 这次新生成的 PPT、PDF、Word 等，默认可预览 |
| 全部文件 | 当前工作目录的树状结构 |
| 变更 | 改前改后对照，删的标红、加的标绿 |
| 预览 | 网页类产物可在内置页里打开 |

点产物即可预览。点文件夹图标能在资源管理器或 Finder 里定位文件。Craft 跑完后，先看「变更」再打开成品。改过头、格式打乱、把不该动的表头改了，都会出现在这里。

不满意就继续说人话，不必重写整段提示词。例如：「预算表那一段拆成三项：场地、餐饮、礼品」「语气改成给分管领导看的书面语，保留数字」。它会在原文件上改。改崩了就回备份，不要指望它永远改对。

### 4. 用一份周报把流程跑通

假设今天下午你要交周报。文件夹里放三样东西：本周工作备忘（txt 或 Word）、一张数据表、上次周报（如果有）。

**第一步，Ask。**

```text
请阅读当前目录。
1. 列出每份文件的类型、时间和它可能对应的周报章节。
2. 指出互相矛盾或缺失的信息，例如有事项没有结果、有数字没有来源。
3. 按「本周完成 / 进行中 / 风险 / 下周计划」给出目录建议。
不要改任何文件。
```

**第二步，Plan。** 如果目录看起来合理，切到 Plan，让它写出准备动哪些文件、新文件叫什么、会不会覆盖上周周报。你只确认一件事：原件保留，新周报另存。

**第三步，Craft。**

```text
请根据当前目录写一份本周周报 Word，另存为「周报-2026-W34.docx」，不要覆盖旧周报。
读者：直接上级。篇幅：800–1200 字。
结构：
- 三句结论（先写判断，再跟数字）
- 本周完成（条列，每条带结果）
- 风险与卡点（谁阻塞、等到什么时候）
- 下周计划（可验收的结果，不要写「持续推进」）
数据只使用表格里出现过的数字。备忘里含糊的句子标「待确认」。
```

**第四步，验收。** 打开「变更」看它有没有改旧周报；打开「产物」预览新 Word。常见返工指令：

- 「结论里的百分比和 Excel 对一下，对不上的删掉。」
- 「进行中的事项不要写成已完成。」
- 「下周计划每条加上负责人，没有负责人就写我。」

这一套跑通，你已经会了 80% 的日常用法：隔离目录、先看后改、要格式、要读者、用变更面板验收。发票、PPT、合同检索，只是把「周报」换成别的交付物。

## 四、三种模式：放权多少，你自己定

官方任务栏文档把三种模式写成权限档，不是三种人设。

| 模式 | 它会做什么 | 适合什么 |
|---|---|---|
| 问一问 Ask | 读文件、回答、给建议，不改文件 | 第一次接触一份材料；确认有没有某条款；先问做法 |
| 想一想 Plan | 先写执行计划：分几步、动哪些文件，你确认后再干 | 批量改名、合并多表、重构一堆文档 |
| 做一做 Craft | 直接执行并写文件 | 目标清楚、可逆、你已经备份 |

选择顺序可以记成三问：只要信息、不要改动？用 Ask。步骤多、难撤销？用 Plan。目标清楚、原件已备份？用 Craft。

同一条任务里可以中途切换。常见走法是 Ask 摸底 → Plan 看图纸 → Craft 开工。刚装上就开 Craft 扫整个桌面，风险在误删和误覆盖，不在「AI 不够聪明」。

## 五、模型怎么选，积分怎么省

客户端内置多个模型，名单会变。2026 年 8 月公开介绍和社区长文里常见的选项包括 MiniMax M2.5、智谱 GLM-5、Kimi K2.5、DeepSeek V3.2 等。**以下拉列表和积分倍率为准**，不要把过期截图当说明书。

按任务类型选，比按「最强」选更省钱：

| 你手头的活 | 优先考虑的能力 | 实务上怎么选 |
|---|---|---|
| Excel、汇总、PPT 骨架 | 办公文件处理、速度快 | 办公向、倍率较低的模型 |
| 多步调研、长报告 | 长流程、少中途跑偏 | 推理较强的综合模型 |
| 发票照片、白板、网页截图 | 视觉 / OCR | 带「视觉」标签的模型 |
| 改写、翻译、普通问答 | 够用就行 | 便宜的通用模型 |

小程序云上模式会把倍率和能力标签写在选模型面板里，例如带视觉的更贵、纯文本批量处理更便宜。数字会活动调价。原则稳定：简单任务用便宜模型；要看图再换视觉模型；架构级长任务再上高倍率。

积分不够有两条路：在 CodeBuddy 套餐页加购；或在设置里填自有模型 API Key。后者适合已经有供应商账号的人。报 `invoke model error` / 连不上 API 时，公开建议是重试或换模型，资源紧张时硬刷同一模型意义不大。

## 六、可直接粘贴的办公指令

把【】换成你的真实文件名和数字。素材先放进当前工作目录。

### 1. 发票批量整理成报销表

照片也能跑。把发票拍清楚、摆正，丢进同一文件夹，模型选带视觉能力的。一张拍糊了，结果里应出现「待核对」，不要编一个看起来完整的金额。

```text
请检查当前文件夹里的发票图片和 PDF，生成报销简述。
每条包含：日期、商家名称、消费金额、消费类别（餐饮 / 交通 / 住宿 / 其他）、备注。
按日期升序排列，格式示例：2026.08.01  某某餐厅聚餐  299 元。
分别按支付明细和发票金额汇总。金额对不上或看不清的，单独标注「异常 / 待核对」。
不要改原图。除对话里的摘要外，再交付一份 Excel。
```

### 2. 乱七八糟的笔记变成纪要

```text
以下是【周会语音转写 / 工作备忘 / 调研草稿】，请整理成【会议纪要】。
读者是【未参会的同事】。
结构：决议事项、待办（负责人 + 截止日期）、未决问题、下次会前需要准备的材料。
用分条，关键数字放进一张表。不确定的句子标成「待确认」，不要编。
原始内容：
【粘贴】
```

### 3. 一句话出 Word 框架

```text
请生成一份公司年会活动策划 Word，规模约 100 人。
包含：活动目标、带时间节点的流程、节目类型建议、预算构成、注意事项。
语言简洁，给领导确认方向用，不要写成宣传稿。
保存到当前工作目录，文件名带日期。
```

生成后再改，直接说哪一段不行：「预算拆到场地、餐饮、礼品、应急金四行，每行给低/中/高三档」。

### 4. 按已有数据和模板做 PPT

```text
请读取当前目录里的【销售数据.xlsx】和【模板.pptx】（如有）。
做一份 8–12 页汇报 PPT，给【业务负责人】周会用。
必须有：封面、本期结论（3 条）、分渠道对比、风险与下一步。
结论页先写判断再写数字。不要装饰性图表。交付可打开的 pptx。
```

需要更像「文档岗」时，可在专家中心召唤文档生成类专家，再发同一条指令。专家是角色和思路，技能才是真正写 pptx 的手。两者可以叠：先召唤专家定结构，再确认已启用 pptx 技能出文件。只有专家、没有对应技能时，常见结果是一份看起来完整、本地却打不开的「伪成品」。验收标准永远是资源管理器里那份文件。

### 5. 表格变分析报告

```text
请读取工作区中所有 xlsx / csv。
生成一份可视化分析 PDF。
重点：【2 月】各渠道投放、转化率、ROI，并与【1 月】对比。
要有多张图和一段文字结论。不要发明原始数据里没有的数字。
```

还没有现成表、需要先上网找公开数据时，先装联网搜索类技能，并写明主题、时间范围、来源偏好和交付格式（HTML / Markdown / 看板页）。模型知识会过时，带「最近」「最新」的问题必须允许它搜索。

### 6. 写给上级的邮件，基于已有材料

```text
请根据当前目录里的【项目进展.docx】起草一封邮件，发给【直接上级】。
目的：说明【上线是否按期】，并请求【周四前确认范围】。
要求：
- 主题一行能看懂结论
- 正文不超过 250 字
- 第一句写结论，第二段写证据（只引用文档里的数字和日期）
- 最后给出两个选项：A 按期缩小范围，B 延期一周保范围
不要发出邮件。只在当前目录生成「邮件草稿.txt」。
```

没接邮箱连接器时，让它只产草稿。接了 QQ 邮箱之后，再单独说「把草稿发到某某地址」，并先拿自己的邮箱做测试。

### 7. 合同 / 制度里找条款

```text
请只阅读【合同.pdf】，回答：
1. 有没有违约金条款？原文怎么写？在第几页？
2. 付款节点有几个，分别触发什么条件？
3. 解约需要提前多久通知？
4. 有没有「自动续约」或「默示同意」？
找不到就写「全文未出现」，不要用常识补。
输出一份一页 Word，每条附原句。
使用 Ask 模式。
```

法律意见仍由人签。这一条的价值是定位原文，减少在几十页里手工翻。

### 8. 一页竞品对照

```text
请基于当前目录材料和必要的联网搜索，做一份一页竞品对照。
对象：【产品 A】和【产品 B】。
维度：定价公开信息、主打功能、最近 90 天产品动态、明显短板。
每条判断后面跟来源链接或文件名。没有公开来源的格子留空，写「未找到」。
交付：一张 Excel + 一段 200 字给老板看的口头稿。
```

### 9. 外文音视频变中文笔记

```text
请把当前文件夹中的英文音频和视频转成中文笔记。
每份材料输出：时间线摘要、关键术语对照、可执行待办。
原文件不要删。看不清口音或专有名词时保留英文并标注不确定。
```

这一条依赖本地转写技能或系统已装的音频工具。没装对应技能时，让它先说明缺什么，再决定装不装。

### 10. 含糊指令和清楚指令

同一件事，信息差会直接变成返工。

| 含糊 | 清楚 |
|---|---|
| 帮我看看这个表 | 请阅读「投放.xlsx」，用 Ask 回答：2 月哪个渠道 ROI 最低？计算口径用表内已有列，不要另造公式。 |
| 做个 PPT | 8–10 页，给周会，听众是业务负责人；第 2 页必须是三条结论；数据只用「投放.xlsx」。 |
| 整理桌面 | 只处理当前工作目录。按「日期-类型」建子文件夹。不删除原文件。重名时在文件名末尾加序号。 |
| 写得专业一点 | 读者换成分管副总；去掉口语；每个判断后面跟一个数字或日期；总字数压到 800。 |
| 帮我研究一下 AI | 搜集 2026 年 7–8 月国内大模型产品的公开价格页，做三列对照：产品、标价、计量单位。没有标价就留空。 |

自己写指令时，用四行检查：工作目录对不对、原件能不能动、交付文件叫什么、失败时怎么标注。四行都写了，Craft 才能安全开。

## 七、技能：先给它配工具箱

WorkBuddy 装好就能写文档、答问题。技能（Skills）是可执行的工作流和脚本：做 PPT、处理 Excel、读 PDF、联网搜。官方技能市场分成「已安装」和「推荐」。[官方说明](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)写得很清楚：第三方技能可能把输入发到外部服务，安装前看权限和来源。

三种安装方式：

1. 技能页卡片上点添加。
2. 下载 zip，解压后用「上传技能」选文件夹。
3. 「查找技能」用自然语言搜；「创建技能」用自然语言生成一份给自己用的技能。

对话框里也可以勾选本次启用的技能。只开当前任务需要的，少占上下文，也少误调用。暂时不用就关，不必卸载；要彻底去掉再用卸载，支持批量。

技能、专家、专家团别混：

| | 技能 | 专家 | 专家团 |
|---|---|---|---|
| 解决什么 | AI 能不能做出某种文件或动作 | 用某个岗位的思路看问题 | 多角色拆解、并行、再汇总 |
| 什么时候用 | 要 pptx / xlsx / 浏览器 | 单点专业判断 | 从需求到开发到验收这种长链路 |
| 新手优先级 | 高 | 中 | 低 |

整理桌面、改一份表、写一页纪要，普通对话加对应技能就够。分析销售数据并给运营建议，再召唤数据分析类专家。软件从需求写到测试，才值得开专家团。专家中心公开宣传有数十个专家团、两百多位专家，品类会变，以客户端为准。

小白第一批建议只装「今天下午就能用」的：

- **xlsx / docx / pptx / pdf**：办公文件四件套，本地处理，少接新的付费 API。
- **web-search 或官方联网技能**：查最近 30 天的资料。
- **skill-scanner**：装第三方技能前先扫可疑脚本和硬编码密钥。
- **find-skills**：你只知道需求、不知道技能名叫什么时用。

社区还有 agent-browser（真去点网页）、local-whisper（本地语音转写）、yt-dlp-downloader（B 站 / YouTube 下载再摘要）、obsidian、self-improvement、frontend-design。有真实痛点再装。不要第一天把清单全倒进去。

装第三方技能前，可以把以下这段发给它（链接换成你准备装的仓库）：

```text
先检查当前工作区已安装哪些 Skills。先安装并使用 skill-scanner，对准备新装的技能做基础安全扫描。
发现明显风险、硬编码私人配置、可疑脚本或高危行为就停下来告诉我，不要继续装。
扫描通过后，只安装尚未安装的技能，并读取每个 SKILL.md 再装依赖。
若需要付费 API、API Key、模型下载或额外手工配置，先明确告诉我。
完成后给清单：已有、新装、额外依赖、还需要我动手的部分。
```

官方兼容 OpenClaw / SkillHub 生态。中文用户常用 SkillHub 或技能页里的社区入口：复制「通过对话安装」指令，发给 WorkBuddy 即可。非官方技能按别人的代码对待。

办公四件套装上之后，对话里可以直接点名格式：

```text
请使用 xlsx 技能，把当前目录三张表按「客户名」对齐合并，输出「客户总表.xlsx」。
保留来源表名列。对不上的行放到「未匹配」工作表。不要改原表。
```

```text
请使用 pdf 技能，抽取「合同.pdf」里所有表格，转成「合同表格.xlsx」。
抽不出的页码列在「失败页.txt」。
```

浏览器类技能解决的是另一类问题：页面必须滚动、点击、展开才能看到正文。公众号文章、后台报表、活动页常属于这一类。纯搜索技能拿到的是摘要或接口结果，点不开的页面仍需要浏览器技能。装之前同样先扫描。

## 八、资料库、连接器、灵感：需要时再开

### 1. 资料库

资料库把腾讯文档、ima、乐享接到工作台里：搜索 → 添加到任务 → AI 加工 → 产物上传回云端。少一次下载再上传。

授权在左侧「资料库」里做，扫码同意即可。换绑或关闭走右上角解绑。找文件有两条路：在任务里用自然语言描述（「上个月那份季度汇报」）；或在资料库页用标题、所有者关键词搜。勾选后点「添加到任务」。本地 Word / Excel / PPT / PDF 也可以先传到腾讯文档再勾选。

干完后到右侧产物点「上传到云端」，选目标资料库。腾讯文档的「我的文档」里应能看到。

完整绕一圈可以这样验收：在腾讯文档里放一份脱敏周报 → 资料库里搜到并添加到任务 → Ask 抽出三条结论 → Craft 生成一页 PPT → 产物上传回腾讯文档。四步都通，说明云端资料已经进工作台，不必再下载上传。搜不到文件时，先确认授权账号是不是你平时用的那个号；企业文档还受可见范围限制，AI 看不到你本来就没有权限的内容。

### 2. 连接器

连接器是账号钥匙：QQ 邮箱、腾讯文档、乐享、TAPD、微云等。连上之后可以说「今天有哪些重要邮件」「把这份报告存到腾讯文档」。每条连接都要你主动授权，可关可断。

配置分两级：用户级写在 `~/.workbuddy/mcp.json`，所有项目能用；项目级写在该文件夹的 `.workbuddy/mcp.json`。企业微信群通知这类「所有活干完都要喊一声」适合用户级。

自定义 MCP 适合对接内部系统。从企业微信群机器人 Webhook 入手相对简单，但仍要改 JSON、装运行时。暂时用不上就跳过。司外可参考[腾讯云 MCP 市场](https://cloud.tencent.com/developer/mcp)。

### 3. 灵感 / 探索

探索是预装场景库。提示词、技能、专家已经配好，选一个「做同款」就能跑。适合不知道怎么开口的人。浏览精选 → 看预览和工具集 → 直接生成或改几个词再生成 → 在产物里验收。它回答的是「别人用这些能力实际做出过什么」，和技能页、专家页互补。

第一次点探索，别从空白对话框纠结措辞。挑一个接近你本职的案例，例如周报、活动海报、数据看板。进详情后先看它调用了哪些技能和专家，再点「做同款」。直接生成适合你完全没有素材的试跑；有自己的数据时，把案例提示词里的公司名、时间、数字换成你的，再生成。成品仍要在右侧产物里用本机软件打开。探索降低的是启动成本，不替代验收。

## 九、自动化：只为重复劳动开闹钟

每天早报、每周五周报、下班前汇总，适合自动化。偶发、每次口径都变的任务，继续手动开对话。

左侧进自动化。定时任务看已安排的，运行记录看历史。添加时填：

- 任务名称，例如「每日行业新闻」。
- 提示词，和平时对话框里写的一样。
- 工作空间，成果会落到这个文件夹。
- 定时规则，每天或间隔。
- 模型和技能。
- 是否推到小程序。打开后文件会同步到云端，手机上看得到。

例：每天 8:00，工作目录选「行业新闻」，提示词写「调研今天 AI 行业动态，整理成简报，含标题、摘要、来源链接」。电脑要开机、联网、WorkBuddy 在跑；锁屏通常不影响，休眠会断。

预设模板可一键导入「每日 AI 新闻」「周报」之类，改公司名和工作目录就能用。

进阶是干完发邮件。先在 QQ 邮箱网页开通 SMTP，生成**授权码**（不是 QQ 密码），再在对话里让它配置：

```text
请配置 QQ 邮箱 SMTP。邮箱：xxx@qq.com。授权码：【授权码】。
配好后先发一封测试信到这个地址，主题写 WorkBuddy SMTP 测试。
```

测通后再说「把刚才这条简报设为每个工作日 8:30 自动执行，完成后发到同一邮箱」。节假日停发、只要财经不要科技、加微博热榜，都用自然语言改一条即可。

企业微信机器人暂不支持自动化主动推送，公开 FAQ 写后续会做。需要即时触达时，优先邮件或小程序推送。

手动先跑通，再交给闹钟。把以下指令贴进普通任务，成功后再说「设为每个工作日 8:30 自动跑」：

```text
请生成今日简报，保存为「简报-当天日期.md」，不要覆盖昨天的文件。
内容：
1. 【你的城市】天气：气温、降雨、穿衣。
2. 科技资讯 3 条，每条含标题、三句摘要、来源链接。
3. 根据这 3 条，给公众号一个今日选题和 80 字开头。
4. 你认为今天可以替我完成的 2 件事（必须是当前工作目录里已有材料能支持的）。
全程标注信息时间。搜不到就写「未找到」，不要编新闻。
```

跑一次大约几分钟。你要盯的是：链接能不能打开、天气城市对不对、有没有把旧文件覆盖掉。这三项过了，再自动化。

## 十、远程先别作为入门主线

助理页面（常标成 Claw）服务「人在外面、活在电脑上」。微信、企微、QQ、元宝、飞书、钉钉、小程序都可以给电脑下指令。你回到电脑，打开助理页看完整思考、操作和产物。点助理旁的文件夹图标可看它的固定工作目录。

和普通任务的差别：

- 工作目录默认锁在 Claw 专属文件夹，不能像普通任务那样随便换。
- 不能并行开多个助理会话，远程指令都进这一条历史。
- 不能像普通任务那样清空上下文重来。

人在电脑前，用「新建任务」。远程值得配的时候，优先走官方「扫码绑定」：微信客服号、元宝扫码、企微小程序/长连接、QQ 扫码。WebSocket 填 AppID、URL 回调填 Token / Encoding-AESKey / Webhook，步骤长，适合公司管理员。

微信小程序搜「腾讯 WorkBuddy」。登录微信号需要和电脑端一致，否则连不上本机。第一次建议这样走：

1. 电脑端保持登录、联网、不休眠。
2. 小程序勾选协议，授权手机号登录。
3. 顶部把环境切到「电脑」，发一条无害指令：「列出桌面是否存在名为 workbuddy-试跑 的文件夹，只回答有或没有，不要改文件。」
4. 回到电脑助理页，确认同一条消息出现、有执行记录。
5. 再试一条带产物的：「把试跑文件夹里的纪要压成 5 条待办，另存为 待办.txt。」

云上模式不必开电脑。适合拍黑板、拍发票、在高铁上写大纲。附件入口包括摄像头、相册、微信文件、手机文件、腾讯文档。多张图建议先用系统相机拍完，再一次性从相册选，上限以小程序当前提示为准。云上可选模型、快捷标签；电脑模式主要把指令送到本机 Agent，细节仍在电脑端看。

两种环境：

| 环境 | 解决什么 | 适合 |
|---|---|---|
| 云上 | 不依赖电脑文件，云端沙箱即开即用 | 通勤、差旅、周末 |
| 电脑 | 远程驱动桌面端读写本机文件 | 人走了，文件还在公司电脑 |

云上有快捷标签：幻灯片、视频、深度研究、文档处理。电脑模式能碰本机文件，思考过程和工具调用细节主要在电脑端助理页里看。电脑必须保持 WorkBuddy 在线且不休眠。

项目页面向多人协同：建项目、邀请链接、任务流转（待开始 / 进行中 / 已暂停 / 已完成）、待办、资产、数据源。个人入门用不到。一个人把活干完之前，邀请链接只会多出一份对不上的聊天记录。需要和同事共一份资产、要任务状态和截止日期时再开。开了之后，对话进「任务」，文件进「资产」，计划和待办分开看，避免和普通新建任务的工作目录混在一起。

「我的文件」在更多菜单里，按对话产物、类型、云端网盘归类，可保存、分享、收藏。跨端同步看云端网盘，不看本地会话。

## 十一、十条省事的用法

1. **从本机痛点开始。** 报销、纪要、周报，比一上来接企微更值。
2. **做什么 + 有什么 + 做成什么样。** 少让它猜。不确定要素时先问：「我要做周报，你还缺哪些信息？」
3. **一次一件事。** 「把 50 页全翻成战略报告并重做全部图表」容易整篇都不合格。先目录，再一章，再图表。
4. **多轮改，不一轮定生死。** 「缩短一半」「第三段逻辑重写」「这个例子换掉」都是合法指令。
5. **换一种说法。** 加上读者、场景、字数、格式，结果往往稳很多。
6. **给样本。** 「按附件这份纪要的标题层级和语气来」比写十行形容词有效。
7. **脏了就新开任务。** 对话太长会前说后忘。关键约束复制到新窗口，不要在跑偏的上下文里加戏。
8. **先备份。** 改 Word / Excel 前复制一份 `_备份` 或带日期的副本。成熟用法是留后路，不是假设它零失误。
9. **重复的才自动化。** 规则清楚、无需每次现场判断的，再设定时。
10. **机械活外包，决策留下。** 格式、抽取、归类交给它；口径、对外承诺、金额异常由你签。

执行中途可以点停止。停了之后补充一句约束再继续，比让它在错误方向上跑完更省积分。右侧过程里出现「准备删除」「清空文件夹」「发给所有联系人」时，立刻停，改成 Plan 或 Ask，把动作范围写死再开。

多任务并行时，每个任务一个文件夹。财务表和宣传文案不要塞进同一个工作目录。Agent 会在目录里找「看起来相关」的文件，混放等于扩大误用范围。

## 十二、常见问题（截至 2026-08）

公开 FAQ 仍在补，以下只收小白会碰到的。

**登录按钮没反应。** 先设好默认浏览器，用 Chrome 无痕再试。

**跨设备不同步。** 配置和会话在本地。移动端可发文字、图片、文件；产物过去主要在电脑端看，小程序在补齐推送。

**不能装进自己的服务器当容器服务。** 公开口径是仅限本地安装。

**语音输入。** 客户端曾写暂不支持，可用系统语音输入顶上。小程序侧有语音按钮，以当前版本为准。

**技能在对话框里勾不到。** 先到技能页打开对应技能。不少技能无需手动 @，对话中会自动选用。

**导出日志。** 顶栏帮助 → 打开日志文件夹，按日期找。

**工作空间不能改名。** 任务名可以改。任务默认使用用户级 Claw 目录并自动隔离；工作空间用来钉死某个项目文件夹。

**Figma 官方 MCP 连不上。** 官方有限制。可改试腾讯设计向产品，或等官方通道。

**Credits。** 头像进看板。个人版 / 企业版与 CodeBuddy 计费共用账户。提高额度：买套餐，或接自有 API。

**性能。** 本地主要吃内存和带宽，模型计算在云端。多任务并行时，本地文件操作会抢资源。

**安全。** 产品说明里有模式权限、安全中心、沙箱、高风险动作拦截、第三方技能扫描。对话传输走 TLS。企业侧提到腾讯 OneID / SSO。仍须把工作目录收窄，敏感文件不要放进试跑文件夹。

**移动端报 AGENTINVOKABLE CUSTOM MODEL NOT FOUND。** 公开建议重试或换模型。

指定工作空间：新建任务后，在输入框附近的文件夹下拉里选。选错了就新开任务，不要指望中途偷偷换盘还能保持上下文干净。

主题与语言：左下角头像里切换浅色 / 深色，以及中英文。和模型选择无关。

## 十三、第一周可以怎么排

按工作日拆，每天只加一个新能力。

**第 1 天：装上，交一份不会外传的成品。** 建 `workbuddy-试跑`，放一份脱敏纪要。Ask 列出文件，Craft 产出 Word。只在产物里打开，不把整个磁盘授权给它。

**第 2 天：学会验收。** 同一份材料让它改一版语气和结构。对照「变更」看它动了哪些段。故意给一句错误指令（例如「删掉所有附件」），确认自己能及时停止并靠备份回退。

**第 3 天：装办公四件套。** 各做一次最小任务：一张三行 Excel、一页 Word、三页 PPT、一份 PDF 抽表。成功标准是本机软件能打开；聊天窗口里的预览不算交付。

**第 4 天：接一种真实材料。** 发票夹、周报素材或合同 PDF，用第六章对应指令跑一遍。把返工次数记下来。同一类活返工超过三次，把成功那一版提示词存成 txt，下次直接改日期。

**第 5 天：决定要不要闹钟和远程。** 只有已经手动跑通、且每天都要做的，才设自动化。只有经常离开工位、电脑还开着的，才配微信小程序电脑模式。云上模式适合不碰本机文件的差旅任务。

一周结束时，你应该有：一个固定工作目录习惯、三到五条自己改过的提示词、对 Ask / Plan / Craft 的手感、对积分消耗的直觉。专家团、项目协同、自定义 MCP 可以放到第二周，等有具体协作对象再开。

积分上，入门阶段把贵模型留给「看图」和「长报告」，日常改写用便宜模型。一条任务反复失败时，先缩短范围，再换更强模型。范围太大时，强模型也会在错误目标上烧额度。

任务失败时先看三类原因，再决定换模型还是改指令：

1. **材料不够。** 它开始编数字、编来源、编「业内通常」。停，让它列出缺哪些文件，你补进目录后再继续。
2. **范围太大。** 过程已经跑了十几步，产物却是一堆半成品。停，改成「只做目录」或「只做第一章」。
3. **技能没开。** 聊天里给了一份 Markdown，却声称那是 PPT。去技能页确认 pptx / xlsx 已启用，再要求「交付可打开的 pptx」。

同一任务里途中换模型可以，但要把已确认的约束再贴一次：工作目录、禁止删除、交付文件名。新模型看不到你以为「它应该还记得」的全部细节。

备份不必上版本管理系统。Windows 里对文件夹右键复制、粘贴，把副本改名为 `发票整理_备份-20260820`。Mac 在 Finder 里按住 Option 拖动文件夹，效果相同。Agent 动手前做一次，改完用「变更」对照，不对就整夹换回。比事后从回收站里捞更稳。

执行过程值得看一眼工具调用：它打开了哪个文件、写了哪条命令、有没有往目录外走。看不懂命令没关系，看路径。路径一旦离开你指定的工作目录，停。Ask 摸底、Plan 收窄、Craft 再干。

对外发送类动作单独对待。生成 Word 可以默认 Craft；点「发送邮件」「发到群里」「上传到全员可见的文档」前，先问它准备发到谁、正文是什么、附件是哪份。确认草稿后再授权发送。连接器给的是钥匙，发送动作仍是你的责任。
