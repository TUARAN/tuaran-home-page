嘉靖在《大明王朝1566》里说话常先丢一句诗、一段经、一个古人。网上金句帖把原创台词和用典混在一起。能对上出处的引用，可以拆开看。

## 一、先给结论

1. **嘉靖最常引用的，是老子、唐诗和本朝太祖。** 墙上写着「吾有三德」，嘴里念李翱的「云在青天水在瓶」，高兴时搬汉高祖，翻脸时搬朱元璋。
2. **「高祖」在剧里至少指向两个人。** 汉高祖刘邦出现在《大风歌》那一场；朱元璋的正式称号是太祖高皇帝，酒宴警告、剥皮揎草、孟子出庙，都打在他名下。
3. **海瑞的引用方向相反。** 嘉靖用经文把责任推开，海瑞用《尚书》《孟子》和汉文帝、唐太宗把责任推回去。最后那场对质，嘉靖还把《治安疏》里点过的先帝一串念出来。
4. **其他人各有自己的书袋。** 严嵩引《尚书》《诗经》，徐阶拿孔子应付，胡宗宪翻《左传》和王阳明，李妃用《易经》劝裕王别动，高翰文满口嵇康。吕芳那套「思危、思退、思变」是官场口诀，不是经书。
5. **流传最广的句子，很多不是引用。** 「任何人答应你的事都不算数」「笨人直人」「衣冠禽兽」是编剧写的台词。把它们和「金杯共汝饮」放在同一张金句图里，出处就糊了。

## 二、事实层

### 2.1 作品口径

| 项 | 公开事实 |
|---|---|
| 电视剧 | 《大明王朝1566》，刘和平编剧，张黎导演，46 集，2007 年 1 月 8 日湖南卫视首播 |
| 文学底本 | 刘和平同名小说，与剧集台词高度接近 |
| 时间背景 | 嘉靖三十九年冬至四十五年，约 1560–1566 |
| 主角 | 嘉靖帝朱厚熜、海瑞；严嵩、徐阶、胡宗宪、吕芳等环绕 |
| 本次范围 | 只整理「点名经书、诗文、先帝、古人」的引用；原创金句另标 |

对照文本取自公开流传的刘和平小说。电视剧个别口播可能与小说有出入，未逐集核对官方字幕。

### 2.2 嘉靖点过名的经书、诗文、古人

| 场合 | 剧中说法 | 可核对的出处 | 当场拿来做什么 |
|---|---|---|---|
| 开场入殿 | 「练得身形似鹤形……云在青天水在瓶。」自称唐朝李翱《问道诗》 | 李翱《赠药山高僧惟俨》其一。网上有时误写成「李敖」 | 先把朝臣按「云 / 水」分位置，再问周云逸有没有后台 |
| 玉熙宫中堂 | 「吾有三德曰慈曰俭曰不敢为天下先」 | 《道德经》第六十七章作「我有三宝」：慈、俭、不敢为天下先。剧中改「三宝」为「三德」 | 挂在墙上。裕王听见「不敢为天下先」，立刻把「有建树」的话吞回去 |
| 浙江灾情 | 「《道德经》第五十八章有云：其政闷闷，其民淳淳……」 | 《道德经》第五十八章 | 宽也错、严也错，责任先落到「迷」上，再召胡宗宪、杨金水、谭纶 |
| 罪己诏 / 贺表风波 | 「万方有罪，罪在朕躬一人而已」 | 《尚书·汤诰》「其尔万方有罪，在予一人」；《论语·尧曰》也有相近句 | 表面揽罪，实际把无雪、欠俸、贺表缺席都收进自己的解释权 |
| 台州捷报 | 「汉高祖不读书，诗却比那些读书人作得好。最好的是哪一句？」 | 刘邦《大风歌》：「安得猛士兮守四方」 | 徐阶对上这句后，嘉靖立刻问：胡宗宪算不算猛士，赵贞吉算不算猛士 |
| 东南二贞 | 徐阶对「贞」字，嘉靖听完 | 徐阶引孔子「凤兮凤兮」（《论语·微子》楚狂接舆歌） | 嘉靖要的是「不二」；徐阶用「终是一凤」把胡宗宪和赵贞吉都保住 |
| 严嵩、徐阶劝酒 | 「金杯共汝饮，白刃不相饶！」自称太祖高皇帝宴饮功臣 | 《明史·茹太素传》：洪武十八年朱元璋赐酒，曰「金杯同汝饮，白刃不相饶」。对象是户部尚书茹太素，不是功臣群宴 | 告诉吕芳：两个大学士端杯时已经听懂杀机 |
| 惩贪 | 诵「硕鼠硕鼠，无食我黍」 | 《诗经·魏风·硕鼠》 | 承认贪官杀不尽，同时把刀交给徐阶 |
| 病中见世子 | 「《礼记》上有一句话……君子抱什么不抱什么」 | 《礼记·曲礼上》：「君子抱孙不抱子」。原意是祭祀时孙可为祖父之尸，子不可为父之尸 | 世子答对，被允许坐到身边 |
| 见海瑞前自语 | 「三花聚顶本是幻，脚下腾云亦非真」 | 内丹套话，不是某一章经文的固定原句 | 自己拆穿修仙场面 |
| 江山之辩 | 刘禹锡「山桃红花满上头……」；又念「天下兴亡多少事，悠悠。不尽长江滚滚流」 | 刘禹锡《竹枝词》；辛弃疾《南乡子·登京口北固亭有怀》原作「千古兴亡多少事」 | 先把海瑞的「山 / 江」比喻拆掉，再转进黄河长江之论 |
| 黄河长江 | 「古谚云『圣人出，黄河清』。可黄河什么时候清过？」 | 纬书、史书常见「圣人出而黄河清」一类话；胡宗宪先前也对海瑞用过 | 清流浊流都要用，泛滥了再治。严嵩是黄河，杨廷和、夏言、杨继盛、沈炼被说成长江泛滥 |
| 点海瑞奏疏 | 「妄谈尧舜禹汤，妄谈汉文帝、汉宣帝、汉光武，还妄谈唐太宗、唐宪宗、宋仁宗、元世祖」 | 与海瑞《治安疏》点名的先帝清单一致 | 逼问：这些「山」现在还在不在 |
| 其他短引 | 「朱熹说过，万事都有个理」；「衣不如新，人不如故」 | 朱熹说理气，是理学常谈；「衣莫若新，人莫若故」一类俗语可上溯到《晏子春秋》 | 前者给朱七留差；后者留旧人 |

嘉靖自己的发明，不算引用，但常被金句帖混进来：

| 台词 | 作用 |
|---|---|
| 「你们这些人有些是云，有些是水……都是忠臣，没有奸臣。」 | 给李翱诗做当场解释 |
| 「朝廷也就是几座宫殿几座衙门罢了，饭还是分锅吃的。」 | 分锅，就是分派 |
| 「没有谁是真正的贤臣，贤时用之，不贤黜之。」 | 回答裕王「谁是贤臣」 |
| 「这个世上，真靠得住的就两种人，一种是笨人，一种是直人。」 | 对黄锦说黄锦，也捎带海瑞这种直人 |
| 「君既不是山，臣民便不是江。」 | 把海瑞的比喻整句翻过来 |

小说叙述里还有一句常被当成嘉靖台词：「万允万当，不如一默。任何一句话，你不说出来便是那句话的主人，你说了出来，便是那句话的奴隶。」这是作者旁白，嘉靖没有当面对谁念过。

### 2.3 海瑞点过名的经书和先帝

| 场合 | 剧中说法 | 可核对的出处 |
|---|---|---|
| 给母亲背书 | 《孝经·广扬名》：「君子之事亲孝，故忠可移于君」 | 《孝经》第十四章 |
| 对王用汲 | 「子曰：交友无不如己者」 | 《论语·学而》作「无友不如己者」。剧中多了一个「交」 |
| 浙江对谭纶 | 「孟子云『君为轻，社稷次之，民为重』」 | 《孟子·尽心下》原文是「民为贵，社稷次之，君为轻」。语序被拧过 |
| 诏狱长段 | 《尚书》「时日曷丧？吾与汝俱亡」；孔子「仁者爱人」；孟子「民为重……」；汉文帝文景之治；唐太宗贞观；太祖高皇帝出身贫寒，又把孟子牌位搬出孔庙 | 「时日曷丧」见《尚书·汤誓》。洪武五年朱元璋一度罢孟子配享，旋即恢复，方向属实 |
| 回奏 | 「孟子曰：『民为重，社稷次之，君为轻。』老子曰：『圣人无恒心，以百姓之心为心。』」 | 《道德经》第四十九章通行本作「圣人无常心」 |
| 对质汉文帝 | 承认汉文帝「不尊孔孟崇尚黄老」，仍认他为贤君；指责当今「不如汉文帝远甚」 | 与《治安疏》以汉文帝开篇的结构一致 |
| 嘉靖代为点名的奏疏人物 | 尧、舜、禹、汤、汉文帝、汉宣帝、汉光武帝、唐太宗、唐宪宗、宋仁宗、元世祖；另有「狂生贾谊」、海南乡贤丘浚 | 海瑞《治安疏》原文确有这串比较。丘浚著《大学衍义补》，海瑞狱中还在翻 |

《治安疏》里海瑞拿来压嘉靖的先帝，可以列成一张短表：

| 名字 | 疏中怎么用 | 剧中有没有再出现 |
|---|---|---|
| 汉文帝 | 开篇对照：天资本该高过文帝，节用爱人却不如 | 有。诏狱、神龟、对质都打在他身上 |
| 尧舜禹汤文武 | 「可为尧、舜，可为禹、汤、文、武」 | 嘉靖当面对质时点名 |
| 汉宣帝 | 励精 | 嘉靖点名 |
| 汉光武帝 | 大度 | 嘉靖点名 |
| 唐太宗 | 英武无敌 | 嘉靖点名；海瑞诏狱里也提贞观 |
| 唐宪宗 | 志平僭乱 | 嘉靖点名 |
| 宋仁宗 | 仁恕 | 嘉靖点名 |
| 元世祖 | 嘉靖初年「毁不与祀」 | 嘉靖点名 |
| 贾谊 | 海瑞引贾谊责文帝，被嘉靖骂「狂生」 | 有 |
| 吕祖谦 | 《治安疏》称文帝能尽人之才力 | 剧中对质戏未再展开 |

神龟那一折，张居正、高翰文、朱翊钧把「汉文帝后元」刻辞当成祥瑞往宫里送。嘉靖听孙子说「天下人都说皇爷爷就像汉文帝」，耳边响的仍是海瑞那句「不如汉文帝远甚」。

### 2.4 其他人引用了谁

按人物排，只收点了书名或古人名的句子。

| 说话人 | 剧中说法 | 出处或归属 | 当场用途 |
|---|---|---|---|
| 严嵩 | 「《尚书》有云：三年丰，三年歉……天象在尧舜时就是这样。」 | 《尚书》无这一句成文。近于农家备荒常谈，被安在《尚书》和尧舜头上 | 把无雪、亏空说成周期，责任在「存粮备荒」 |
| 严嵩 | 「《诗经》云『哀哀父母，生我劬劳』」 | 《诗经·小雅·蓼莪》 | 跟徐阶谈父子，为严世蕃开脱 |
| 严嵩 | 离京时要随从找胡宗宪手抄的《左传》 | 书名 | 老人收拾行李，仍带这套书 |
| 张居正 | 「凡事预则立，不预则废」 | 《礼记·中庸》 | 年度财政会上先说；严嵩随后接过这句话 |
| 张居正 | 给裕王讲朱子理气 | 《朱子语类》 | 讲书，也在讲眼下的「气」 |
| 张居正 | 成祖派郑和七下西洋；成祖派人找张三丰血经 | 永乐史事 + 剧中情节 | 前者谈开海，后者把《道德经》《南华经》血经送进宫 |
| 徐阶 | 「孔子曰『凤兮凤兮』，终是一凤」 | 《论语·微子》 | 保东南「二贞」 |
| 徐阶 | 「圣德巍巍，直追尧舜」 | 套话 | 压赵贞吉去管海瑞 |
| 胡宗宪 | 「《左传》上说『君以此兴，必以此亡』」 | 剧中称《左传》。常见近句是「君以此始，亦必以终」一类，原文归属未在这里坐实 | 自认跟严嵩绑在一起 |
| 胡宗宪 | 「孔子说的『知不可为而为之』」；责备部下空谈「半部《论语》可治天下」 | 《论语·宪问》作「知其不可而为之」。「半部论语」是后世加在赵普头上的话 | 训周江勇 |
| 胡宗宪 | 「君不密则失臣，臣不密则失身」 | 《周易·系辞上》 | 不愿按密旨两头瞒 |
| 胡宗宪 | 王阳明看河图洛书；「古语云：圣人出，黄河清」 | 王学掌故 + 古谚 | 劝海瑞别谈沧浪归隐 |
| 海瑞 / 海母 | 「沧浪之水清兮可以濯我缨」 | 《孟子·离娄上》引《孺子歌》，亦见《楚辞·渔父》 | 海父当年不肯应举；海瑞后来对胡宗宪再提 |
| 李妃 | 「《易经》上说『潜龙勿用』」 | 《周易》乾卦初九 | 劝裕王在杨金水押京前关门别动 |
| 嘉靖私下 | 「乾上乾下」 | 他自己给海瑞和自己配的乾卦，不是经文原句 | 等一个能跟自己交卦的人 |
| 赵贞吉 | 「老子有句名言……『天网恢恢，疏而不失』」 | 《道德经》第七十三章 | 审郑泌昌 |
| 王用汲 | 「孟子云：禹思天下有溺者，犹己溺之也」 | 《孟子·离娄下》 | 拦高翰文签字 |
| 高翰文 | 纠《广陵散》音准；临别说「《广陵散》从此绝矣」 | 嵇康临刑典故 | 沈一石一案的文化诱饵 |
| 沈一石 / 芸娘 | 「侯非侯，王非王，千乘万骑归邙山……一曲《广陵散》」 | 剧中自撰歌词，附着在嵇康故事上 | 给自己定调 |
| 高翰文 | 「文章憎命达，魑魅喜人过」；「此心匪石不可转也」 | 杜甫《天末怀李白》；《诗经·邶风·柏舟》「我心匪石，不可转也」 | 拒绝再被套 |
| 裕王 | 「圣人云，天下无不是的父母」；又引太祖教百官断讼：父子诉讼曲在子 | 俗语 + 剧中所称太祖教导 | 压官员别为修宫闹事 |
| 赵贞吉宣旨 | 「我大明开国之初，有贪赃六十两白银者，太祖高皇帝即将之剥皮揎草」 | 明人笔记、野史常见「贪六十两剥皮」的说法，制度史有争议 | 吓郑泌昌、何茂才 |
| 赦免高翰文的旨 | 「秉承太祖高皇帝『无心为过，虽过不罚』祖训」 | 《皇明祖训》未见此句。更接近《聊斋志异·考城隍》「无心为恶，虽恶不罚」，且《聊斋》成书在明亡之后 | 把高翰文送回翰林院读《永乐大典》 |
| 吕芳 | 「做官要三思……思危、思退、思变」 | 官场口诀，不是经书 | 教冯保怎么活 |
| 郑泌昌 | 「文官袍服上绣的是禽，武官袍服上绣的是兽……哪一个不是衣冠禽兽」 | 原创台词 | 把贪腐说成制度 |
| 徐阶 | 「大风吹倒梧桐树，自有旁人论短长」 | 俗语、小说常用套句 | 金句帖常收，小说里也有相近用法 |

太祖、成祖在剧中还反复作为「祖制」出现，不一定每次都引原话：皇庄不得侵占民田、锦衣卫选人规矩始自成祖、两淮盐税在太祖成祖时更旺、吕芳被发去给太祖守陵。这些是制度记忆，另算一列。

### 2.5 「高祖」到底指谁

| 称呼 | 剧中指向 | 出现方式 |
|---|---|---|
| 汉高祖 | 刘邦 | 嘉靖主动考徐阶《大风歌》 |
| 太祖高皇帝 / 太祖爷 / 太祖皇帝 | 朱元璋 | 酒宴两句、剥皮揎草、孟子出庙、祖训、守陵 |
| 成祖 / 太宗文皇帝 | 朱棣 | 郑和、锦衣卫、血经、镇抚司归属 |
| 老祖宗 | 宫里太监对吕芳、陈洪的称呼，也是嘉靖骂人时的词 | 嘉靖吼过：「我大明朝只有太祖成祖才是老祖宗」 |

日常口语里的「高祖」，在这部戏里更容易先碰到朱元璋的谥号「高皇帝」，而不是刘邦。刘邦只在捷报那一场被点名。

## 三、结构分析

引用在这部戏里是工作语言。谁先抢到解释权，谁就暂时安全。

嘉靖的书袋有三层。最外层是道教场面：《道德经》挂墙上，血经、道袍、铜磬都在场。中间一层是诗：李翱定场，刘禹锡、辛弃疾收场。最里一层是本朝祖宗。汉高祖的诗用来问「谁是猛士」；太祖的酒用来告诉严嵩、徐阶，今晚这杯喝完可能还有刀。祖宗比老子硬，因为臣下没法说太祖的话作废。

海瑞不跟他抢道教词汇，直接换书。《尚书》的民变、《孟子》的民贵、汉文帝的节用，都是科举出身的人背得出来的。嘉靖要是承认这些句子，就得回答自己为什么二十多年不上朝。对质时嘉靖没有否认海瑞读过这些名字，他问的是：这些山还在不在。海瑞答「在史册里，在人心里」。两边用的都是古人，结论拧着。

其余人各拿能活命的那一本。严嵩把灾荒写成尧舜时就有的周期；徐阶用孔子把两个「贞」字圆成一只凤；胡宗宪用《左传》和王阳明给自己的夹缝找说法；李妃只用乾卦初九，劝丈夫先别动。高翰文的嵇康是文化人的致命处，沈一石拿来套他，最后也套住自己。吕芳不引经，他传口诀。口诀比经书好使，因为太监没有科举身份，不能靠孔孟发言。

网上最常转发的句子，大量是这一层之外的原创台词。郑泌昌的衣冠禽兽、吕芳的三思、嘉靖的笨人直人，传播力往往高于「硕鼠」和《大风歌》。金句帖按「扎心」排序，不按出处排序，于是「引用了谁」这件事在二次传播里消失了。

## 四、外部研判

这些观察只对刘和平这部作品有效，不能直接当成嘉靖四十五年的史料。

1. **继续补这张对照表是有用的。** 看剧时能分清哪句是《孟子》，哪句是编剧。不必再写成权谋鸡汤或成功学摘抄。
2. **历史原句和剧中用法要分开。** 「金杯同汝饮」在《明史》里是朱元璋对茹太素说的；剧中改成宴饮功臣，好让严嵩、徐阶同时听见。『君子抱孙不抱子』在《礼记》里讲祭祀用尸；剧中拿来让病中的皇帝把孙子放到身边。方向还在，场合换了。
3. **《治安疏》是整部戏里最接近原文的一叠名字。** 尧舜、汉文帝到宋仁宗、元世祖，海瑞疏里有，嘉靖嘴里也有。戏剧加码的是神龟、笔架、黄河长江，这些是刘和平的结构，不是疏文。
4. **不跟进把这部戏当成嘉靖思想史教材。** 真实的朱厚熜写青词、议大礼、长期住西苑，都有史料。剧中「太极政治」「云在青天水在瓶」是人物设计。两者可以对照，不能互相替代。
