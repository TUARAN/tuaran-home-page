> 适用范围：讨论的是健康成人在公开、被评价、结果不完全可控时的急性应激与表达表现。材料来自实验室压力范式、前额叶与工作记忆研究和挑战—威胁评估模型，用来解释述职、答辩、面试、例会发言、路演等场面。不构成医疗建议，也不能替代焦虑障碍、惊恐发作或其他精神卫生问题的临床评估。若紧张已造成持续回避、睡眠崩溃、惊恐样发作或明显功能损害，应寻求专业诊治。

## 一、先给结论

**交感唤起挤占前额叶和工作记忆，表达先垮。**

1. **最容易抬高皮质醇的，是“被别人评判能力、自己又控不住结果”的任务。** Dickerson 与 Kemeny 对 208 项实验室研究的元分析表明，带社会评价的任务皮质醇效应约 \(d = 0.67\)，不带评价的约 \(d = 0.21\)；评价与不可控同时出现时最大，约 \(d = 0.92\)–\(0.93\)，恢复也更慢。
2. **特里尔社会应激测验（TSST）几乎就是公开讲话加心算、加冷脸观众。** 原协议包含约 10 分钟预期和 10 分钟当众演讲与心算；唾液皮质醇常升到基线的 2–4 倍，心率同步上升。述职、答辩、面试的心理结构与它同类：公开、向上或打分、过程中可能被打断。
3. **急性压力会迅速削弱前额叶的工作记忆能力。** Arnsten 综述指出，即使中等、不可控的急性压力，也可通过过高的单胺和糖皮质激素信号，减弱前额叶网络连接、压低神经元发放。Qin 等人用 fMRI 看到，急性心理应激会降低背外侧前额叶（DLPFC）与工作记忆相关的活动，并把资源从执行网络挪走。
4. **焦虑还会占用中央执行器。** 注意控制理论认为，担忧把注意从目标导向系统推向刺激驱动系统，损害抑制和切换效率；成绩有时还能靠加力撑住，但组句、提取数字、临场转弯这些高带宽操作会先变慢、变碎。
5. **声音发抖、对着幻灯片念不通、脑子空白，是同一条链路落到发声和语言输出上。** 表达依赖平稳呼吸、喉部精细控制和刚好够用的工作记忆。这三样都对压力敏感，所以内容还在长期记忆里，嘴上先垮。
6. **「想赢只会兴奋，怕输才会害怕」只说对评估标签。** 挑战—威胁模型里，同一套心跳加快可以对应挑战或威胁：觉得资源盖得住需求时偏兴奋，觉得需求压过资源时偏害怕。想赢本身不会关掉威胁评估。

## 二、事实层：实验室里什么压力会动皮质醇

心理压力并不“一律”抬高皮质醇。Dickerson 与 Kemeny（2004）把能可靠激活下丘脑—垂体—肾上腺轴（HPA）的条件收窄成两类叠加：

| 条件 | 操作化含义 | 皮质醇 |
|---|---|---|
| 社会评价威胁 | 表现可能被他人负面评判 | 单独约 \(d = 0.67\) |
| 不可控 | 努力与结果不严格对应，失败路径明显 | 单独约 \(d = 0.52\) |
| 两者同时 | 当众表现 + 时间压力 + 评价者 | 约 \(d = 0.92\)–\(0.93\)，恢复更慢 |
| 无评价的困难任务、看血腥影片等 | 可以难受，但不必然动 HPA | 效应接近 0 或很小 |

社会自我保全模型把这类刺激写成：可能失去社会尊重、接纳、地位或价值。Gruenewald、Dickerson 等人的实验对照也显示，做同一套困难任务，有评价观众时自我评价更差、自我意识情绪更高、HPA 激活更强；拿掉观众，皮质醇可以不升。

TSST（Kirschbaum、Pirke、Hellhammer，1993）把上述条件做成标准流程：预期等待、当众即兴演讲、突然心算、观众少给反馈。它后来成为人类急性心理应激最常用的实验室工具之一，正因为它稳定地结合了评价与不可控。Allen 等人 2017 年的方法学综述仍把它的核心要素概括为：公开讲话带来的生态压力，加上评价和不可预测。

职场和考场里，同类结构反复出现：

| 场面 | 评价者 | 不可控点 | 自我相关目标 |
|---|---|---|---|
| 述职 / 晋级汇报 | 掌握考核与资源的上级 | 提问口径、时间、表情 | 这段工作是否够格 |
| 答辩 | 委员会 | 追问方向 | 资格是否成立 |
| 面试 | 用人方 | 对方标准不透明 | 能否进入下一轮 |
| 例会被点名 | 同事与上级 | 何时被叫、要多短 | 当场是否显得清楚 |
| 路演 | 投资人或客户 | 打断、比稿 | 项目是否被信任 |

公开资料能确认的是机制同类，不能确认某一次述职的皮质醇数值等于 TSST。

## 三、结构分析：从威胁评估到表达失败

### 1. 两条生理通道同时开工

被判成“有风险的表现任务”后，至少两条轴会动：

- **交感—肾上腺髓质（SAM）**：几秒内释放肾上腺素、去甲肾上腺素。心跳加快、呼吸变浅变快、肌肉张力上升、唾液减少。这就是口干、手抖、肩颈发紧、气接不上的底盘。
- **HPA**：稍慢释放皮质醇。评价加不可控时，这条轴特别容易被拉起来，而且退回去更慢。所以前一晚预演灾难、进门前最慌，符合预期焦虑已经开始动员，不一定要等开口。

Arnsten（2009）把前额叶写成对压力最敏感的高级认知区：保命时让出控制、把反应交给更古老的回路，有生存价值；需要组织语言、抑制跑题、在工作记忆里暂存数字时，同一套切换会变成故障。过高的 cAMP–HCN 信号减弱前额叶网络连接，过高的磷脂酰肌醇—蛋白激酶 C 信号压低前额叶发放。轻度可控压力有时还能 sharpen 表现；不可控、过强时，工作记忆能力会快速掉下去。

Qin 等人（2009）在健康女性被试上诱导急性心理应激，同时做数字 N-back：DLPFC 与工作记忆相关的活动显著下降，默认网络的去激活也变弱。作者把机制指向过高的儿茶酚胺，并可能叠加皮质醇。样本、应激诱导方式与述职现场并不等同，能确认的是方向：急性心理应激可以立刻改写前额叶工作记忆网络的活动。

### 2. “挤占”对应两件已经分开验证的事

标题里的“挤占”是组织用语，对应两条并行过程，不宜理解成颅内某个叶被物理推开。

| 过程 | 主要证据 | 落到讲话上 |
|---|---|---|
| 化学信号削弱前额叶网络 | Arnsten 综述；Qin 等 DLPFC 活动下降 | 提取专名、数字、转折变慢，出现空白 |
| 担忧占用中央执行器 | Eysenck 等注意控制理论（2007）；其前身是加工效率理论（1992） | 一边扫描“他们满不满意”，一边组句，带宽不够 |
| 补偿性加力 | 同一理论：有效性（对不对）有时还能撑，效率（费不费劲、稳不稳）先掉 | 看起来还在讲，句子已经碎、重复、抢气 |

Eysenck、Derakshan、Santos 与 Calvo 强调：焦虑损害目标导向注意，增强刺激驱动注意，并提高对威胁线索的捕捉。受影响最大的执行功能是**抑制**和**切换**。Shi、Sharpe 与 Abbott（2019）对注意控制的元分析总体支持：焦虑与抑制、切换的缺损有关，更新（updating）较弱；高认知负荷时效应更大。当众讲话正是高负荷：要听自己、看听众、盯时间、选词、控气。

压力下“发挥失常”还有另一条文献。Beilock 与 Carr（2001）讨论高压力如何让熟练表现变脆：一是分心（工作记忆被担忧占走），二是过度显式监控（把本应自动的动作拆开盯）。念幻灯片逐字读，会把讲话从“提取要点”推进成“显式解码 + 监控对错”，两条脆弱点叠在一起。

### 3. 为什么垮的是表达，不是“这件事你不会”

长期记忆里的经历、判断、数字，存储位置和当场调用不是同一套系统。当场调用要：

1. 在工作记忆里暂时握住当前要点和下一个要点；
2. 抑制跑题和自我监控噪音；
3. 按时间切换到下一句；
4. 用平稳的呼气流驱动声带。

前三项主要靠前额叶执行功能；第四项靠呼吸—喉部的精细运动，而交感唤起会把呼吸变浅、肌张力抬高。所以会出现一种很具体的分裂：**坐下能把事讲清楚，站起来对着评价者就不会了。** 会的那部分还在；调用和发送的通道正在给保命系统让路。

Yerkes 与 Dodson 很早就指出，唤起与表现呈倒 U 形，任务越复杂，过线越早。当众组句属于复杂任务。适度警觉有用；评价威胁把唤起推过线后，掉下去的正是复杂输出。

## 四、现场症状怎样挂上这条链路

| 现场现象 | 更靠近哪一段机制 | 可观察的信号 |
|---|---|---|
| 进场前比开讲后更慌 | 预期期已启动评价威胁；未知尚未变成已知 | 失眠、胃紧、进门心跳 |
| 脑子空白、数字突然没了 | 前额叶工作记忆网络被下调；提取失败 | 卡在专名、百分比、人名 |
| 句子碎、重复、转不过弯 | 执行器被担忧占用，抑制和切换变差 | 同一句改两遍仍不完整 |
| 口干、手抖、肩僵 | SAM：唾液下降、外周张力上升 | 端杯子、握遥控会稍稳一点 |
| 声音发紧、发颤、气不够 | 呼吸变浅 + 喉内肌张力；气流不稳传到声带 | 越想把那句硬念完，抖越明显 |
| 对着幻灯片念不利索 | 把高负荷解码叠在已经变窄的工作记忆上；再加显式监控 | 读破句、读错行、越念越快 |
| 讲着讲着反而稳了 | 不可控下降、控制感回升，威胁评级回落 | 第一句落地后语速恢复 |

Giddens 等人（2013）回顾压力的嗓音指标：基频、抖动、强度和震颤等会随应激变化，机制涉及呼吸支持和喉部张力，个体差异大。不能把每一次声抖都写成“皮质醇升高”；能写的是，发声系统对交感和呼吸节律敏感，所以它经常成为这条链路的第一公开症状。

## 五、按机制拆开的接法

目标有三件，对应三处瓶颈：把 SAM 的峰值拉下来一点、把工作记忆里的项目减到能握住、把输出从“完美念稿”改成“把结论送出去”。

### 1. 先动呼吸，再跟情绪辩论

慢呼吸（通常低于每分钟 10 次，许多研究落在每分钟 6 次附近）与更高的心率变异性、呼吸性窦性心律不齐有关，并常伴随主观唤起下降。Zaccaro 等人（2018）系统综述了 15 项健康被试研究；Russo、Santarelli 与 O’Rourke（2017）把自主神经较优化的呼吸区间写在每分钟 6–10 次、以膈肌为主。拉长呼气是现场可做的操作：吸 4 秒、呼 6 秒，重复数轮，频率大约落在这一带。

它做不到的事情也要说清：没有证据表明这几轮呼吸能把一次述职的皮质醇曲线改写成“无评价任务”。它能做的是给喉和胸腔一个更稳的气流，并占用一点本来会拿去灾难预演的注意。

### 2. 把工作记忆负载降到三格

前额叶在压力下能同时握住的项目变少。上场只保留三句，每句一格：

1. 做成了什么（最好带一个可核验事实）；
2. 卡点怎么处理；
3. 下一步要什么、边界在哪。

各准备 30 秒版和 2 分钟版。时间被切掉时输出短版；被追问时再展开。纸上只写标题、一个数字或例子、一个已承认的不足加对应动作。这是给提取失败预留的外部工作记忆，不是讲稿。

开场直接给结论，例如：这段核心做成了 A；卡点在 B，已经用 C 处理；下一步是 D，需要确认 E。听众先有地图，提问会从“你到底在讲什么”变成“这个数字怎么来的”，后一种对工作记忆更友好。

### 3. 声音发抖、念稿不通时，停，不要把那句硬念完

硬念会把失败的显式监控再喂回威胁评估：越念越碎，越碎越像在输。

可执行的下一秒：

- 呼完这一口气，音量放低，语速放慢；
- 看一个具体的人，用自己的话只讲当前页的结论；
- 幻灯片当提词器，不当朗读材料；
- 卡住就丢掉这个分句，报数字或例子，翻下一页；
- 最多说一次“我重新说一下”，不要连续道歉。

成功标准是要义送出。把破句念顺，会继续占用已经不够的执行器。

### 4. 临场前两小时停止改稿

新故事和新页会制造新的不可控，威胁评估会重新抬头。只过开头 20 秒、关键数字、可能被问的五题。答不上的题预备一句：现在能确认的是……；缺的材料会后补。

## 六、兴奋和害怕：同一套唤起，两种评估

Blascovich、Tomaka、Seery 等人的挑战—威胁生物心理社会模型处理的是：在自我相关、必须出力的任务里，主观上资源与需求怎么比。

| | 挑战 | 威胁 |
|---|---|---|
| 评估 | 资源 ≥ 需求 | 需求 > 资源 |
| 任务投入 | 都有：心跳更快、收缩更有力 | 同左 |
| 心血管模式（该模型的指标） | 心输出量上升、外周阻力下降 | 心输出量少增或不增，阻力升或持平 |
| 主观标签 | 常被说成兴奋、专注 | 常被说成害怕、发懵 |
| 资源例子 | 练过开口、有三条线、知道会问什么 | 标准模糊、可能被打断、身份被绑进对错 |

「想赢只会兴奋，怕输才会害怕」把标签说成互斥开关。实验室和赛场里更常见的是连续谱：越在意结果，需求侧的“输会怎样”越大；若同时觉得准备够用，仍可偏挑战。述职的不对称在于评价权在对方、标准常不公开，需求容易被估高，资源容易被估低，所以同样想赢，唤起更容易被标成怕。

把场面从“别被判输”收到“把三件事讲清楚”，是在改需求评估和可控感，不是在给自己下达“只许想赢”的命令。

## 七、外部研判

一种与公开证据相容的观察是：职场把普通进展同步，做成一次带档案意味的定性。实验室要靠观众、计时和不可预测提问才能做出的评价威胁，组织流程会定期生产。所以“平时能讲、述职不会讲”不必写成性格缺陷，写成任务结构变化更省事。

第二种观察：文化里对自夸的抑制，会把“报结果”额外标成社交风险。这可能抬高需求评估，但目前缺少与 TSST 直接对照的、可引用的中国职场皮质醇数据，只能当假说。

第三种观察：把紧张解释成“心态不够赢”，会逼人继续和情绪辩论，而情绪辩论本身占用执行器。更省带宽的干预是改负载、改呼吸、改输出标准。
