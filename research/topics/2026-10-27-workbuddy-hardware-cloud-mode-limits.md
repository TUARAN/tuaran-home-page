> 适用范围：只讨论 WorkBuddy 硬件接入里的云端任务。应用发布中的云开发、企业知识库上传限额、客户端本地文件预览大小，不计入沙箱配额。白皮书里的 Assistants 与 `execution_target` 是合作说明，和现行 Open API v2 的任务接口不是同一套字段。

硬件把一条指令交给 WorkBuddy 云端时，任务在腾讯云隔离沙箱里执行，电脑不必开着。本机文件、企业内网、工作空间选择、完全访问和自定义模型都不在这条路径上。

协议链路和产品分类见 [ACP 与 MCP 硬件接入审计](/articles/research/topics/workbuddy-acp-vs-mcp-hardware-bridge)。联调入口见 [硬件接入助手](/tools/workbuddy-acp-bridge)。

## 一、先给结论

1. **云端任务的执行面是沙箱，入口是 `POST /openapi/v2/tasks`。** 返回 `task_id`、ACP `link` 和 token 之后，用 GET SSE 收消息、POST JSON-RPC 发 `initialize`、`session/load`、`session/prompt`。
2. **云端路径明确做不到五件事：** 读未上传的本机文件、访问企业内网和本机已装软件、为这次任务选择工作空间、打开「允许完全访问」、使用客户端自定义模型。
3. **用户侧已经公开的配额在账号和资料，不在沙箱规格。** 积分按月发放且不结转；资料库按会员分 5 / 10 / 20 / 50 GB；项目资产默认 5 GB，可扩容，存在腾讯网盘；定时任务条数按会员分档。
4. **调用方必须处理的硬边界是鉴权寿命、分页和限流。** 任务列表每页最多 100 条，产物分页 `limit` 最大 500。Open API 超频返回 `429`，按 1 秒、2 秒、4 秒退避。ACP token 过期后用任务详情换新凭据。
5. **沙箱 CPU、内存、单会话磁盘、单文件大小、任务最长时长、并发沙箱数、QPS 数值、音视频带宽和传感器上报频率，公开文档没有给出。** 这些行不能写成无限，也不能写成已经禁止。

四档用词固定：硬限制是文档写出、调用方不能改写的上限或禁止；可配置是会员、后台、连接器或安全策略能改；暂不支持是文档明确写不能做；未公开是问过这项，但没有配额数字。

| --- | --- | --- | --- |
| 用户 | 资料库容量 | 体验 / 标准 / 高级 / 旗舰为 5 / 10 / 20 / 50 GB，随订阅变化 | 可配置 |
| 用户 | 项目资产 | 默认 5 GB，可扩容，依托腾讯网盘。这是项目资料，公开文档没有把它写成沙箱磁盘配额 | 可配置 |
| 云端 | 任务产物 | 保存在云端。产物列表可分页拉取。单会话容量、单文件大小、上传和下载流量上限没有数字 | 未公开 |
| 开发 | 产物分页 | `limit` 取值 1–500；省略或 0 表示一次返回全部 | 硬限制 |

| 用户 / 硬件 | 本机文件 | 云端沙箱不能读取本机路径和未上传文件 | 暂不支持 |

### 硬件接入

| 侧 | 项 | 边界 | 档 |
| --- | --- | --- | --- |
| 硬件 | 可接入形态 | 文档举例包括眼镜、头显、耳机、手表手环、录音笔、麦克风、桌宠、工卡、便携终端、车机。这是合作分类，不是协议枚举。模式③写明只和头部伙伴合作，要过审核 | 可配置（审核准入） |
| 开发 | 纯软件申报硬件 | 开放平台按真实设备审核。没有实机、型号和设备链路时，不能按硬件应用通过 | 暂不支持 |
| 硬件 | 采样、帧率、带宽 | 白皮书写硬件负责拾音、成像和位置，云端负责理解。采样率、帧率、音视频码率和传感器上报频率都没有上限数字 | 未公开 |
| 开发 | 创建任务的入参 | 公开请求体只有 `prompt` 和可选 `name`。ACP 示例是文本 ContentBlock。图片、音频、视频流如何进入云端任务，没有上传接口说明 | 未公开 |
| 硬件 / 开发 | 票据存放 | `access_token`、`refresh_token`、`client_secret` 放在合作方后端。硬件和前端不持有 | 硬限制 |
| 用户 | 用户票据寿命 | 第三方应用页写 access_token 24 小时、refresh_token 60 天。Open API 示例里的 `expires_in` 是 3600 秒。两处不一致，调用方应读取每次换票响应里的 `expires_in`。用户撤销授权后旧票据立即作废 | 硬限制 |
| 云端 | ACP 沙箱票据 | 只用于 ACP 鉴权。文档写通常约 3 天，也可能很短。401 后调用 `GET /openapi/v2/tasks/{task_id}` 换新 token。列表接口不返回 token | 硬限制（会过期）；时长不固定 |
| 硬件 | 保活与重连 | SSE 与 POST 靠 `Acp-Connection-Id` 关联。心跳间隔、最大重连次数和断线后续跑窗口没有写。创建后若暂时没有 `link` 或 token，状态会停在 `CREATING`，需要轮询 | 未公开 |
| 硬件 | 本机执行 | 本地助理只覆盖已经安装并在线的 Mac 与 Windows 客户端。手机等移动端不能走本机执行 | 暂不支持 |
| 用户 | 权限确认 | 需要用户参与时，服务端发送 `session/request_permission`，客户端要在超时前应答。超时秒数没有写。无人应答时任务可以停在 `pending` | 硬限制（必须应答）；超时值未公开 |

### 权限与合规

| 侧 | 项 | 边界 | 档 |
| --- | --- | --- | --- |
| 云端 | 沙箱隔离 | 云端任务在腾讯云隔离沙箱执行。企业智能体 Runtime 是独立的 Linux 文件系统和终端。用户不能把它改成完全访问 | 硬限制 |
| 用户 | 本机安全中心 | 文件、命令、域名可以分别设为允许、询问或拒绝。敏感信息拦截默认开启。一次删除达到默认 50 个时需要审批。审计日志可以导出和清空。这套策略写在本机客户端。云端任务文档没有说可以同样配置出站白名单 | 可配置（本机）；云端出站名单未公开 |
| 云端 | 内网 | 云端任务不能访问企业内网和本机资源。企业 IP 白名单限制的是谁能登录客户端 | 暂不支持（云端访问内网） |
| 云端 | 数据位置 | 云端任务的数据在云端。产物接口示例主机是 `*.ap-guangzhou.agentos-run.net`，只说明示例落在这个域名，不是合同里的驻留承诺。专享版把后台、数据库和向量库放在独立 VPC，那是另一套企业部署 | 未公开（驻留条款） |
| 用户 | 本地处理声明 | 「数据在本地执行、服务端只处理片段」写的是本地任务和本地文件。云端模式把任务数据放在云端，不能用这句话覆盖云端任务 | 不适用于云端模式 |
| 云端 | 审计留存 | 定时任务会记录创建、启停、触发、结果和耗时。企业控制台有 AI 安全审计和会话回放。留存天数没有写。客户端审计日志可以由用户自己清空 | 未公开 |
| 云端 | 敏感操作 | 工具授权和提问走 `session/request_permission`。敏感保护、安全网关和传输加密的开关细节写在本机安全中心 | 硬限制（云端交互须确认）；本机策略可配置 |
| 开发 | 凭证注入 | 企业智能体的凭据加密存储，运行时由代理注入请求头，不写进沙箱文件 | 硬限制 |

| 开发 | 私有域名和内网 MCP | 云端沙箱不能访问企业内网。连接器文档里的内网地址指用户本机上的连接器 | 暂不支持（云端访问内网） |
| 开发 | 分享进 WorkBuddy | 整段消息的原始 JSON 上限 16 KiB。PC 端不支持把图片、音频、文件以 Base64 嵌进分享消息。这是分享通道，不是云端任务上传 | 硬限制 |
| 开发 | 分享审核 | 提交后 7 个工作日内审核。客户端需 5.8.0 及以上。应用要使用企业实名的代码签名证书 | 硬限制 |
| 开发 | API 频率 | 只有 429 和退避，没有分接口的 QPS 表 | 未公开 |

### 异常

| 现象 | 行为 | 档 |
| --- | --- | --- |
| 沙箱还没就绪 | 状态为 `CREATING`，轮询任务详情直到补齐 `link` 和 token | 硬限制 |
| ACP 或产物接口 401 | 用任务详情换新 ticket 后重试 | 硬限制 |
| Open API 超频 | 返回 429，按指数退避重试 | 硬限制 |
| 设备授权轮询过快 | 返回 `slow_down`，间隔加 5 秒 | 硬限制 |
| 下游异常 | 本地助理下游非 401、403、404 时返回 502。服务未配置或暂不可用时返回 503。文档要求带 `request_id` 重试，没有写熔断窗口和排队深度 | 未公开 |
| 等待用户确认 | 状态可以停在 `pending`。云端定时任务不能选择权限，也不能推送到企业微信 | 硬限制 |
| 积分或工具轮次用尽 | 对话按积分计费。轮次用尽时以 `max_turn_requests` 结束。没有「排队到下一分钟」或「自动换成小模型」的说明 | 未公开 |
| 企业智能体空闲 | 10 分钟无访问后休眠，再次访问唤醒。失败态表示沙箱创建或启动异常 | 硬限制（企业智能体） |
| 应用云开发资源点用尽 | 云服务暂停。体验、标准和高级版保留数据 30 天，旗舰版 60 天，到期后删除云数据。这是应用云开发，不是 Agent 沙箱 | 不要套用 |

## 三、结构分析

四侧看的是同一条链路的不同切面。

用户在客户端里把任务拨到云端之后，WorkBuddy 不再使用这台电脑的文件夹、已安装软件和内网。个人 Skill 也换成云端那一份。项目 Skill、已连接的公共授权和云端资料库仍然可以进任务。积分记在任务所有者账上，只有任务所有者能切换这次任务的模型，而云端任务本身又不能换成自定义模型，所以模型选择停在账号可用的内置模型上。

开发侧的云端调用分成两跳。第一跳是 Open API：`user.task.invokable` 创建任务，`user.task.readable` 读列表和详情。第二跳是 ACP：`link` 上的 SSE 负责收，POST 负责发，两边用 `Acp-Connection-Id` 绑在一起。`session/load` 的示例工作目录是 `/workspace`。产物既可以从 SSE 的 `_codebuddy.ai/artifact` 增量收到，也可以用沙箱上的 `GET /api/session/artifacts` 拉全量。沙箱主机由 `link` 去掉末尾 `/acp` 得到，鉴权票和 ACP 共用一份。

硬件侧不该成为票据的存放点。开放平台和白皮书都要求个人票据留在合作方后端，设备负责唤醒、采集和回显。本地助理是另一组接口，只在 Mac 或 Windows 客户端在线时成立。移动端要做复杂任务，走的是云端任务。传感器采样和音视频帧率留在设备到厂商后端这一段，公开的云端任务接口没有接收这些流的配额。

云端运行侧把「允许完全访问」拿掉了。本机安全中心里的路径规则、命令前缀和域名白名单，管的是客户端沙箱。云端任务的隔离由平台沙箱执行，用户不能在任务里把它关掉。远程 MCP 必须是公网 HTTPS。只保存在本机的 Token 模式凭证，云端沙箱拿不到。

企业智能体 Runtime、企业托管智能体产品介绍、应用云开发，是三套相邻产品。企业智能体写了 10 分钟休眠，也写了独立 Linux 沙箱。应用云开发写了单文件 20 MB 和资源点。企业托管智能体的产品介绍还出现过「1 个 Session 对 1 个沙箱」「休眠唤醒很快」「单集群百万 Session」这类运行口径。硬件 Open API 没有引用这些数字，不能把它们填进硬件云端任务的配额表。

## 四、外部研判

云端模式适合设备不在用户电脑旁边、又要把长任务交出去的场景：眼镜上发起，沙箱里做完，结果回到镜片或 App。这条路径换来的是电脑可以关机，拿不走的是本机磁盘和内网。

集成时可以把已经写死的行为当成契约：分页上限、429 退避、ACP 401 换票、`pending` 时把确认交回给人、远程 MCP 只用 HTTPS。磁盘、算力、时长、QPS 和媒体带宽在报错或官方配额页出现之前，不应当成可承诺的容量写进硬件规格。

会改变上表结论的缺项有三件：

- 开放平台如果公布沙箱磁盘、CPU、内存、最长时长或 QPS，对应的「未公开」行要改成硬限制或可配置。
