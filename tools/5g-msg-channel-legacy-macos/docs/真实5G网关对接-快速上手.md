## 第 0 步：先准备这 5 样

| # | 项目 | 示例 / 写法 | 去哪找 |
|---|---|---|---|
| ① | 项目根目录 | `<你的项目根目录>` | 把 `5g-msg-channel` 文件夹解压在哪个盘就填哪个，例如 `D:\apps\5g-msg-channel` |
| ② | 网关 WS 地址 | `wss://5gvas01.cmicmaap.com/gtw-ai/openclaw/ws/msg` | 平台方/负责人给 |
| ③ | API Key | `ak_xxxxxxxx` | 平台方/负责人给 |
| ④ | node 怎么写 | **推荐**写：`node`（走系统 PATH，最省事） | 终端里输 `node -v` 有版本号就直接用 `node` |
|  |  | 不行就写**绝对路径**：`C:\Users\jx\.workbuddy\binaries\node\versions\22.22.2-2\node.exe` | WorkBuddy 内置 node 版本号从 `C:\Users\<你>\.workbuddy\binaries\node\versions\current` 里看 |

```bash
cd <你的项目根目录> && npm run install:all
```

## 第 1 步：改 mcp.json（最稳方案）

打开 `C:\Users\<你的用户名>\.workbuddy\mcp.json`，整份替换为下面内容，**尖括号 `<>` 里的全部改成你自己的**：

```json
{
  "mcpServers": {
    "5g-msg-channel": {
      "command": "node",
      "args": ["<你的项目根目录，反斜杠两个>\\connector\\src\\index.cjs"],
      "env": {
        "MAAP_WS_URL":    "wss://5gvas01.cmicmaap.com/gtw-ai/openclaw/ws/msg",
        "MAAP_API_KEY":   "ak_<平台给你的钥匙>",
        "ALLOWED_SENDERS":"<你的手机号，多个用逗号分隔>",
        "ENFORCE_WHITELIST": "true",
        "ACP_CWD":        "C:\\Users\\<你的用户名>\\WorkBuddy\\<你的项目文件夹>"
      },
      "disabled": false
    }
  }
}
```

> 💡 **`"command"` 怎么写：**
> - **推荐**：直接写 `"node"`，系统 PATH 里能找到 node 就用这个（最简单）。
> - **不行再写绝对路径**，两种常见情况示例（注意 JSON 里单个 `\` 必须写成 `\\`）：
>   - WorkBuddy 自带 node：
>     `"C:\\Users\\jx\\.workbuddy\\binaries\\node\\versions\\22.22.2-2\\node.exe"`
>     （把 `jx` 换成你的用户名、`22.22.2-2` 换成 `current` 文件里的版本号）
>   - 自己装的 node（安装包默认路径）：
>     `"C:\\Program Files\\nodejs\\node.exe"`
>
> 终端里 `node -v` 能显示版本号，就代表 **`"command": "node"` 可以直接用**。

## 第 2 步：重启 + 信任（必做，90% 的人漏这步）

1. **重启 WorkBuddy**
2. 左侧边栏 → **连接器 / MCP** → 找到 `5g-msg-channel` → 点右侧 **「信任 / Trust」**

---

## 第 3 步：验证（复制这句话去对话里发）

```
用 send_5g 给 <你的手机号> 发：你好，5G消息测试
```

| 结果 | 说明 |
|---|---|
| ✅ 手机收到短信 | 成功！ |
| ❌ "没有这个工具 / 找不到 send_5g" | 没点 **信任**，回第 2 步 |
| ❌ "5G WS 未连接 / auth_failed" | `MAAP_WS_URL` 或 `MAAP_API_KEY` 填错，回第 0 步核对 |
| ❌ 别人发短信 AI 没反应 | 号码没在 `ALLOWED_SENDERS` 白名单里 |

---

## 排障速查（3 个命令够用了）

在对话里发：

```
用 bridge_status 查一下链路状态
```

看两个关键字段：`"wsConnected": true`（网关已连上）、`"processed"`（已处理消息数）。

日志文件路径：`<你的项目根目录>\connector\logs\channel-当天日期.log`
