# 广东省中医院复诊提醒（本地版）

此版本提供北京时间校准、每日 20:59:50 预热提醒、21:00 提醒、8 天后日期计算，以及不含个人信息的本地结果日志。它**不会操作微信、轮询号源或自动下单**。医院实际院区、排班、预约周期和放号规则以官方服务号当日显示为准。

## 使用

1. 安装 Python 3.9 或更新版本（需包含 Tkinter）。
2. 在 Windows 双击 `start.bat`；在 macOS 双击 `start.command`。首次运行请保持联网以进行 NTP 校时。
3. 提前在微信「广东省中医院服务号」绑定就诊人，进入刘晓雁医生的预约页，并核对院区、科室和日期。
4. 保持电脑不休眠且程序窗口打开。提醒后在官方页面手动完成预约与支付；随后点“登记成功”或“登记未挂到”。

程序不会读取或保存身份证、手机号、微信会话、截图。结果仅写在本目录的 `appointment-results.jsonl`，可直接删除。校时仅向公开 NTP 服务发送标准时间查询，不上传就诊信息。如果 NTP 不可用，界面会明确显示使用系统时钟。程序没有毫秒级放号或预约成功保证。
