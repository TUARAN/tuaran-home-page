# 掘金高频互动助手

当前本地测试版为 v0.2.0，暂无公开下载版。`manifest.json` 是当前可安装源码的版本号；公开 ZIP 和下载页只表示已发布版本。开发中的多次修改可以合在一个交付节点验证，交付过的版本内容冻结；之后改行为，即使未打包也要升版。兼容修复升 PATCH，新增兼容功能升 MINOR，破坏已有设置或使用方式升 MAJOR；版本号只用 Chrome 接受的三段数字。只改文档不升版，打包本身也不触发升版。

每个交付版本在下方记录日期、状态、改动及用户影响。公开 ZIP 上传并确认可下载后，才把同一条记录标为「已发布」，补上发布日期、下载文件名、SHA-256 和对应提交；公开页面只列已发布版。修订已发布 ZIP 必须另升版。打包发布前核对测试结果、面板与 `manifest.json` 的版本，以及 ZIP 文件名和 ZIP 内版本。

Chrome Manifest V3 扩展，在已登录的掘金页面运行。三个任务分别是每日签到、定时发沸点和定时写文章。默认使用「每日上限 · 草稿」模式：按北京时间每天最多发布 3 条沸点、保存 3 篇文章草稿。设置中可切换「高频 · 自动发布」模式：沸点和文章按频率持续发布，不设每日 3 条上限。站长后台「自动化 → 社区动作 → 浏览器插件」展示源码目录、回执密钥和运行结果。

## 安装与启动

1. 打开 `chrome://extensions/`，开启开发者模式，选择「加载已解压的扩展程序」，选中 `tools/juejin-interaction-extension`。修改源码后，在扩展管理页点「重新加载」，再刷新掘金页面。
2. 打开 `https://juejin.cn/`，登录掘金。首页右下角会显示插件面板。在面板保存 DeepSeek API Key；如果需要后台回执，再粘贴社区动作回执密钥。
3. 面板顶部可一键启动或暂停三项任务。页签分别查看签到、沸点和文章的设置与状态，切换页签不会跳转网页，也不会影响其他任务。单项工作区可启动或暂停任务，并查看下一次执行时间；启动任务时才打开对应任务页。运行模式、密钥和待确认任务清理在右上角设置里；面板可折叠或放大。

启用后的第一条会立即运行。之后按所选挡位等待：慢 50～70 分钟、中 25～35 分钟、快 12～18 分钟、超快 6～10 分钟。默认模式达到每日上限后次日再继续；高频模式按挡位持续执行。签到在两种模式下都按北京时间每天一次。运行中不能改频率，暂停后可调整；已排定的等待时间保持不变。

扩展仅在当前活动标签页属于 `https://juejin.cn/` 时执行到期任务，并打开对应掘金任务页；切到其他网站时不会自动开页或执行。本机 Chrome、网络和掘金登录态需保持可用。关闭任务开关即可停止后续执行。

内容素材取自 Hacker News 的 AI 相关条目，由 DeepSeek Flash 根据标题和来源链接生成中文内容。沸点正文按段落排版且不带链接；模型返回链接时会拒绝发布。文章保留文末来源链接。扩展只把资讯标题和链接发送给 DeepSeek，不上传掘金 Cookie。已经用于成功发布或保存草稿的资讯不会重复使用。

默认模式下，文章只写入编辑器，由掘金自动保存至草稿箱；扩展不会点击「发布」。页面明确显示已保存后才计入当天草稿数，并打开草稿箱，让下一次任务使用新的编辑器。高频模式下，文章经过分类、标签和摘要弹层自动发布；跳转到标题匹配的文章详情页后记录成功。沸点以页面明确显示「发布成功」且编辑器清空，或跳转到匹配内容详情页作为确认信号。完成状态无法确认时会停在待确认状态，避免重复生成；切换模式只影响下一次任务，待确认内容仍需人工核对。

回执只包含任务、结果、目标编号和错误码，不包含正文、Cookie 或模型密钥。未填写回执密钥时任务照常运行，回执会暂存本机。

部署后台回执前还需应用 `migrations/0110_juejin_community_actions.sql`。开发测试阶段直接加载源码目录，不需要打包 ZIP。
