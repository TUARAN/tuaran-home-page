# protal待办处理助手

本目录是一个本地 Chrome / Edge Manifest V3 扩展。它只在用户点击扩展图标后注入当前页面，不申请全站读取权限。

每条待办执行以下闭环：

1. 在 `.todo-table` 中点击第一条尚未处理的 `.title.oneLine`。
2. 等待详情页出现 `label="一键提交"`、`event="onekeySubmit"` 的按钮并点击。
3. 等待“一键提交”弹窗出现 `.onekey-submit-button`，校验可见文案严格等于“提交”后点击。
4. 等待最终提交按钮与详情页一键提交按钮消失，并确认待办列表重新可见。
5. 记录该行指纹，继续下一条。

任何步骤超时都会停止，不会猜测或改点其他按钮。

## 安装

1. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择目录：

```text
tools/oa-batch-submit-extension
```

## 使用

1. 登录 OA，进入截图所示的待办列表。
2. 点击浏览器工具栏中的扩展图标，页面右下角会显示控制面板。
3. 第一次先保持默认参数，点击“单步一条”。
4. 核对一条待办确实完成并回到列表后，再点击“连续开始”。
5. 点击“停止”后，插件不会再发起新的点击；当前等待会尽快退出。

刷新页面后脚本不会自动运行。如需继续，再点击一次扩展图标并手动开始。

## 安全边界

- 插件不读取或保存正文、附件和联系人信息。
- 设置只保存在浏览器本地；日志只存在当前页面内，刷新即清空。
- 默认单次最多处理 20 条，可设置 1–200 条。
- 标签页切到后台时暂停，回到前台后继续。
- 只匹配给定 DOM 契约；页面结构变化会超时停止。
- 当前版本面向“详情与提交弹窗都在同一标签页”的流程。如果标题会打开新的浏览器窗口或跨域标签页，插件会安全超时，需要依据实际窗口行为再接入多标签页协调。

## DOM 契约

关键选择器集中在 `automation-core.js` 的 `SELECTORS` 中。OA 改版时优先在这里调整，并继续保留“稳定属性 + 精确可见文案”的双重校验。
