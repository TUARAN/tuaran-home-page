# 鹿鹿精灵（长颈鹿桌宠预览版）

独立的 Electron 长颈鹿桌宠：悬浮陪伴、拖动、置顶、摸摸鹿鹿、文字输入和本机离线演示。它不需要 WorkBuddy 凭据就能展示；接入已授权的本机桥接器后，用户点击发送才会调用 WorkBuddy 的本地助理。

## 运行

要求 Node.js 22+。仓库根目录已安装 Electron 时可直接运行：

```sh
cd tools/workbuddy-desktop-pet
../../node_modules/.bin/electron main.cjs
```

独立安装时在本目录 `npm install`、`npm start`。`npm test` 验证本机请求与数据边界。桌宠默认连接 `http://127.0.0.1:8080`；现有桥接器见 `../workbuddy-acp-bridge/README.md`，先在其目录启动 `npm start` 或 `npm run desktop`。桥接器真实模式需由审核通过的应用完成用户授权。演示模式的桌宾讯息是本地固定回复，不会冒充 WorkBuddy 真实执行。

## 产品边界和下一步

- 这是软件桌宠，不是硬件设备。截图里的“硬件接入”表单要求核实真实硬件，不能把它填成硬件产品；先向平台确认常规第三方应用的入口、可用性和审核方式。
- 本版使用本机现有桥接器进行联调，只在用户发送时传文字；桌宠进程不持有 Client Secret、OAuth token，也不在界面中展示它们。桥接器 `8080` 端口不能同时被其他应用占用。
- 桥接器的本地 `/v1/ui/messages` 是本机联调入口，并非面向互联网的公开 API。正式对外分发前，需要独立的服务端 OAuth 凭据与令牌管理、安装包签名和更严格的本地请求认证；不要把 Client Secret 打包进桌宠。
- 桌宠当前支持手动文本交互。日程提醒、语音、支付、自动任务、跨设备同步都尚未实现；对外介绍不能列为现有能力。

## 变现与里程碑

1. **可审核演示**：完善安装包、公开产品页、隐私说明与操作视频，依据真实功能申请最小 Scope。
2. **验证留存**：招募小范围体验者，记录实际启动、次日使用、用户主动发送与任务完成情况；仅在用户知情后收集产品统计。
3. **付费增值**：先销售桌宠形象、主题与本地提醒等自身功能。WorkBuddy 积分、任务额度和官方权限不作为可转售商品；接入积分兑换需另行获得对应授权和平台规则确认。
