# 2aran X Article Auto Publisher

每天北京时间 14:00 从 `2aran.com` 领取一篇站内已发布文章，保留正文中的安全链接、基础排版和图片，然后利用浏览器现有登录状态操作 X Articles 编辑器发布。

## 安装

1. 在 Cloudflare Pages 的公开站环境变量中设置 `X_ARTICLE_EXTENSION_SECRET`。
2. 打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，加载本目录。
3. 点击扩展图标，填写与服务器相同的领取密钥，保存。
4. 保持 Chrome 运行并登录 `x.com`，账号需要具备 X Articles 发布权限。

设置页只有“保存并立即检查”一个按钮。密钥保存在 `chrome.storage.local` 的独立备份字段中；在同一个已安装扩展上升级版本或点击“重新加载”会继续沿用，不需要再次输入。卸载扩展会清除 Chrome 为该扩展保存的数据。

## 自动化规则

- 北京时间 14:00 设置独立的每日闹钟；每 15 分钟再检查一次，用于领取或页面失败后的补偿重试。
- 当天领取同一个任务，失败重试不会随机换文章。
- 领取失败、站内文章暂时打不开、X 编辑器尚未加载时会继续重试。
- 点击 X 的发布按钮后如果无法确认结果，会停止当天自动重发，避免重复文章。
- 保留正文已有的 HTTP/HTTPS 链接，不额外添加站内原文地址；脚本链接等非网页协议会被删除。
- 保留二至四级标题、粗体、斜体、删除线、引用、代码、列表和段落；表格转换成等宽文本，避免 X 编辑器把列结构打散。
- 最多携带正文中的 20 张 JPEG、PNG 或 WebP 图片，单张不超过 8 MiB。图片下载或 X 上传未完成时不会点击发布，而是稍后重试。
- 写入失败会复用标题相同的现有草稿并整体重写，不会在每次重试时继续创建新草稿。
- 插件需要读取 HTTPS 图片，因此安装时会显示较宽的网站读取权限；该权限只用于下载本次站内文章引用的图片并交给 X 上传。

## 页面兼容

插件依赖 X 页面编辑器。`x-content.js` 使用英文和中文语义定位标题与发布按钮，`main-world.js` 通过 X 当前的 Draft.js 编辑器写入结构化正文并调用页面自身的图片上传处理器。X 改版后若状态显示 `X_ARTICLE_EDITOR_NOT_FOUND`、`X_DRAFT_EDITOR_NOT_REACHABLE` 或 `X_IMAGE_UPLOAD_HANDLER_NOT_FOUND`，需要按新页面结构更新兼容层。
