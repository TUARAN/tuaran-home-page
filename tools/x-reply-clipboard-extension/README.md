# X 时间线回复助手

站内入口：<https://2aran.com/resources/x-reply-clipboard-extension>。工具集的「推特工具」和下载中心都会链到这一页。

本地 Chrome Manifest V3 扩展。在已登录的 X 时间线上，从上往下打开每条帖子的评论弹窗，从固定话术里随机抽一条写进去，再点 Reply。

插件单独内置 55 条话术，以普通中文短句为主，只保留少量图标话术。每次处理完会换下一条，下一条不会和刚用过的那句相同。不读取系统剪贴板。macOS 应用「X粘贴板评论助手」仍单独维护自己的话术副本。

插件会先核对评论框里的文字与抽中的话术完全一致，等 Reply 真正可点后自动发送。发送成功才进入下一条；结果不明确时保留当前帖子和话术重试。`Save` 只保存草稿，不是发送按钮，插件不会用它代替 Reply。已成功但弹窗残留时，插件会刷新清理并自动续跑。

开始运行时如果页面已有评论弹窗，插件会核对其中的文字。内容能匹配 55 条固定话术中的任意一条时，会切换到对应话术并接着点击 Reply；比较时忽略 X 编辑器压缩的空格、换行、零宽字符和 Emoji 变体。内容不属于固定话术时才暂停，避免覆盖手写草稿。插件从账号切换按钮或个人资料入口读取当前登录账号，并按帖子永久链接识别作者；自己的帖子、自己刚发出的回复以及无法确认作者的帖子都不会进入回复队列。

写入时以评论框里肉眼可见的文本为准。浏览器输入已经显示完整话术后，不再调用 Draft 内部状态补写，避免同一句被写两遍；发现弹窗里已有重复或残留内容时，会自动全选替换为当前这一条话术，然后点击 Reply，不会停在“内容不一致”。

扩展更新后必须刷新已经打开的 X 标签页。v0.2.13 使用新的页面通信通道，并会替换同版本遗留的写入监听器，避免旧版与新版同时写入。若弹窗里已经出现“稳稳”这种同一句连续两遍的内容，插件会自动压回一句再发送。

v0.2.14 不再依赖浏览器的 `selectAll` 命令，而是精确选中整个 X 编辑器后替换内容。若旧版已经留下“稳st your reply”这种话术与英文占位文字混合的内容，新版会识别、清理并继续发送。

v0.2.15 允许接管启动前已经打开的空评论弹窗。编辑器为空或只显示 `Post your reply` 等占位文字时，插件会直接填入当前话术并发送；已有无法识别的真实文字时仍会暂停保护。

v0.2.16 在页面写入层同样把 `Post your reply` 等占位文字视为空。第一次浏览器写入没有生效时，会重新聚焦、重新选中整个编辑器并再写一次；仍然失败才尝试 Draft 状态回退。

v0.2.17 按 X 真实弹窗 DOM 精确定位 `contenteditable="true"` 的回复编辑器。旧选择器会先命中 `tweetTextarea_0_label` 外层，导致话术写到错误节点并反复提示“话术没有写进评论框”。

v0.2.18 修复第一条成功后弹窗尚未消失就暂停的问题。插件会等待弹窗自行关闭；已确认发送但弹窗仍残留时，通过刷新清理并自动续跑。已回复的帖子 ID 会跨刷新保存，不会再次回复。每轮 35 条，共 5 轮 175 条后停止。

v1.0.0 重做页面面板：独立显示本轮、轮次、本次执行三组数据，加入当前轮和整体进度条、运行状态、当前话术与重试计数。界面使用“自动发送”描述真实行为，不再显示“等待发送确认”。

每轮成功 35 条后刷新页面，再从顶部继续；完成 5 轮（共 175 条）后自动停止。刷新后会保留本轮进度、已完成轮次和下一条话术。关闭这个标签页会停。

## 安装

1. 打开 Chrome：`chrome://extensions/`
2. 开启「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本目录：

```text
tools/x-reply-clipboard-extension
```

已经装过旧版时，在扩展管理页点这个扩展的刷新按钮。

## 使用

1. 在 Chrome 里登录 X。
2. 打开首页、个人主页或搜索结果。
3. 点击左下角「开始回复」。
4. 需要停止时，点「停止」。

扩展只在当前这个 X 标签页里操作。切到别的标签页会暂停，回到该页后继续。
