# X高频互动助手

站内入口：<https://2aran.com/resources/x-reply-clipboard-extension>。工具集的「推特工具」和下载中心都会链到这一页。

本地 Chrome Manifest V3 扩展。面板顶部按以下顺序提供四个 Tab，新安装默认选择时间线：

- **时间线回复**：在已登录的 X 时间线上，从上往下打开他人帖子的评论弹窗并回复。
- **通知回复**：只处理通知页最近 2 小时内别人对当前账号的回复，先点赞，再打开评论弹窗继续回复。单纯的点赞通知不会进入队列；成功处理的通知 ID 会保存在 Chrome 本地，之后不会重复点赞或回复。
- **互关浇友**：整合原「X 互关清理助手」，提供清理未回关、回关粉丝和关注候选三项任务。
- **推文浇给**：DeepSeek 从当前 X 首页已经加载的趋势与时间线文字中提炼话题，生成带段间空行的纯文字推文；第一条立即发送，之后每条随机间隔 25～35 分钟。

两个回复助手都可使用固定话术随机回复，也可使用 DeepSeek AI 根据当前内容生成更适配的回复。

时间线每次先按当前频率挡位生成一份随机计划。运行设置里可以在慢、中、快、超快之间滑动，默认是「中」：3～5 轮，每轮 25～35 条；每条成功后随机等待 5～15 秒，整次完成后随机休息 2～3 小时再生成下一份计划。通知回复使用同一套挡位决定每条间隔和扫描后的休息，并继续使用持久历史去重。已经开始的计划和正在进行的等待不会因为改挡位而改写。插件不对时间线和通知回复设置每日总量。页面暂时不可用时每 1 分钟自动重连。标题栏显示整个插件从任一任务启动后累计的稳定运行时长，各任务单独显示自己的运行时间；只有最后一个任务停止或对应任务页签关闭时，整体计时才结束。

插件单独内置 100 条完整话术，以认可、感谢、支持、观察和学习为主。约四成句子带一个与语气匹配的 Emoji，其余保留纯文字，不再使用纯图标或单字回复。每次处理完会换下一条，下一条不会和刚用过的那句相同。不读取系统剪贴板。

插件会先核对评论框里的文字与抽中的话术完全一致，等 Reply 真正可点后自动发送。发送成功才进入下一条；结果不明确时保留当前帖子和话术重试。`Save` 只保存草稿，不是发送按钮，插件不会用它代替 Reply。已成功但弹窗残留时，插件会刷新清理并自动续跑。

v3.6.5 给推文浇给加上慢、中、快、超快滑块。默认「中」仍是发送成功后随机等待 25～35 分钟；慢是 50～70 分钟，快是 12～18 分钟，超快是 6～10 分钟。挡位单独保存在扩展本地存储，不改时间线和通知回复的挡位。已经开始的等待保持原截止时间。

v3.6.4 把面板从左下角浮层改成嵌在 X 右侧栏搜索框下面，跟着页面滚动，不再挡住时间线。X 还没画出右侧栏时面板先不显示，栏出现或被替换后会重新挂上。

v3.6.3 把回复频率调度改成可滑动的四挡：慢、中、快、超快。默认「中」保持 v3.6.2 的间隔、轮次和休息区间；更快的挡位缩短每条等待、提高每轮条数并缩短执行后休息。挡位保存在扩展本地存储，时间线和通知回复共用。已保存的本次计划继续跑完，新挡位从下一次抽取开始生效。

v3.6.2 移除时间线和通知回复共享的每日 100 条插件额度。升级后不会再出现“今日插件回复额度已用完”，旧版本保存的额度和次日恢复倒计时不会继续生效。随机间隔、随机轮次、执行后休息、通知去重和 X 风控提示停机机制保持不变。

开始运行时如果页面已有评论弹窗，插件会核对其中的文字。内容能匹配当前 100 条话术或旧版话术中的任意一条时，会切换到对应话术或安全替换后接着点击 Reply；比较时忽略 X 编辑器压缩的空格、换行、零宽字符和 Emoji 变体。内容不属于固定话术时才暂停，避免覆盖手写草稿。插件从账号切换按钮或个人资料入口读取当前登录账号，并按帖子永久链接识别作者；自己的帖子、自己刚发出的回复以及无法确认作者的帖子都不会进入回复队列。

写入时以评论框里肉眼可见的文本为准。浏览器输入已经显示完整话术后，不再调用 Draft 内部状态补写，避免同一句被写两遍；发现弹窗里已有重复或残留内容时，会自动全选替换为当前这一条话术，然后点击 Reply，不会停在“内容不一致”。

扩展更新后必须刷新已经打开的 X 标签页。v0.2.13 使用新的页面通信通道，并会替换同版本遗留的写入监听器，避免旧版与新版同时写入。若弹窗里已经出现“稳稳”这种同一句连续两遍的内容，插件会自动压回一句再发送。

v0.2.15 允许接管启动前已经打开的空评论弹窗。编辑器为空或只显示 `Post your reply` 等占位文字时，插件会直接填入当前话术并发送；已有无法识别的真实文字时仍会暂停保护。

## 安装

1. 打开 Chrome：`chrome://extensions/`
2. 开启「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本目录：

```text
tools/x-reply-clipboard-extension
```

已经装过旧版时，在扩展管理页点这个扩展的刷新按钮。

## 使用

1. 在 Chrome 里登录 X。
2. 面板在右侧搜索框下方。默认打开时间线；顶部依次可切换时间线、通知回复、互关浇友或推文浇给。
3. 互关任务按提示打开 Following / Followers 列表；回复任务点击对应的开始按钮。
4. 选择“模板随机”可直接开始；选择“AI 模式”时，只需填写并保存 DeepSeek API Key。
5. 如需调整回复速度，打开「运行设置」，把频率滑块停在慢、中、快或超快。推文浇给在自己的页面里单独滑动发推间隔。
6. 需要停止时，点「停止」。

「推文浇给」只发送纯文字。它与 AI 回复共用已保存的 DeepSeek API Key，读取当前页面可见话题作为灵感，不读取网站后台任务。启动后立即发布第一条，之后按发推页的频率挡位随机等待；默认「中」是 25～35 分钟。发帖框已有手写内容时会暂停，不会覆盖。

「关注候选」专门用于其他作者的 Followers 页面，不会跳转到当前账号自己的粉丝页。「回关粉丝」和「关注候选」共享同一组关注限制：每 2 秒操作 1 个，两个功能合计每完成 15 个暂停 30 分钟，每日合计最多 400 个。今日数量、本批进度和暂停时间保存在 Chrome 扩展本地存储中，并按本地日期重置。

扩展只操作启动任务的 X 标签页。时间线、通知回复、互关浇友和推文浇给会分别绑定专用页签；从顶部导航切换功能时，其他任务仍会继续。Chrome 可能降低后台页签的 DOM 渲染频率，因此实际动作间隔可能比设置值更长；不要关闭、丢弃或手动刷新正在执行任务的 X 标签页。

面板中的每条间隔从发送成功后开始，按当前挡位随机抽取并计算，不包含 AI 生成、弹窗出现、编辑器写入和发送确认所需的时间。默认「中」是 5～15 秒。出现重试时，总耗时会继续增加；v3.2.0 已缩短单步超时并减少后台计时消息，避免 v3.1.6 在前台也被离屏轮询拖慢。
