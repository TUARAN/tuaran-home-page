# X 时间线回复助手

站内入口：<https://2aran.com/resources/x-reply-clipboard-extension>。工具集的「推特工具」和下载中心都会链到这一页。

本地 Chrome Manifest V3 扩展。在已登录的 X 时间线上，从上往下打开每条帖子的评论弹窗，再点 Reply。默认从固定话术池随机抽取；也可使用 DeepSeek AI，根据原帖文字生成更适配的回复。

插件单独内置 100 条完整话术，以认可、感谢、支持、观察和学习为主。约四成句子带一个与语气匹配的 Emoji，其余保留纯文字，不再使用纯图标或单字回复。每次处理完会换下一条，下一条不会和刚用过的那句相同。不读取系统剪贴板。macOS 应用「X粘贴板评论助手」仍单独维护自己的话术副本。

插件会先核对评论框里的文字与抽中的话术完全一致，等 Reply 真正可点后自动发送。发送成功才进入下一条；结果不明确时保留当前帖子和话术重试。`Save` 只保存草稿，不是发送按钮，插件不会用它代替 Reply。已成功但弹窗残留时，插件会刷新清理并自动续跑。

开始运行时如果页面已有评论弹窗，插件会核对其中的文字。内容能匹配当前 100 条话术或旧版话术中的任意一条时，会切换到对应话术或安全替换后接着点击 Reply；比较时忽略 X 编辑器压缩的空格、换行、零宽字符和 Emoji 变体。内容不属于固定话术时才暂停，避免覆盖手写草稿。插件从账号切换按钮或个人资料入口读取当前登录账号，并按帖子永久链接识别作者；自己的帖子、自己刚发出的回复以及无法确认作者的帖子都不会进入回复队列。

写入时以评论框里肉眼可见的文本为准。浏览器输入已经显示完整话术后，不再调用 Draft 内部状态补写，避免同一句被写两遍；发现弹窗里已有重复或残留内容时，会自动全选替换为当前这一条话术，然后点击 Reply，不会停在“内容不一致”。

扩展更新后必须刷新已经打开的 X 标签页。v0.2.13 使用新的页面通信通道，并会替换同版本遗留的写入监听器，避免旧版与新版同时写入。若弹窗里已经出现“稳稳”这种同一句连续两遍的内容，插件会自动压回一句再发送。

v0.2.14 不再依赖浏览器的 `selectAll` 命令，而是精确选中整个 X 编辑器后替换内容。若旧版已经留下“稳st your reply”这种话术与英文占位文字混合的内容，新版会识别、清理并继续发送。

v0.2.15 允许接管启动前已经打开的空评论弹窗。编辑器为空或只显示 `Post your reply` 等占位文字时，插件会直接填入当前话术并发送；已有无法识别的真实文字时仍会暂停保护。

v0.2.16 在页面写入层同样把 `Post your reply` 等占位文字视为空。第一次浏览器写入没有生效时，会重新聚焦、重新选中整个编辑器并再写一次；仍然失败才尝试 Draft 状态回退。

v0.2.17 按 X 真实弹窗 DOM 精确定位 `contenteditable="true"` 的回复编辑器。旧选择器会先命中 `tweetTextarea_0_label` 外层，导致话术写到错误节点并反复提示“话术没有写进评论框”。

v0.2.18 修复第一条成功后弹窗尚未消失就暂停的问题。插件会等待弹窗自行关闭；已确认发送但弹窗仍残留时，通过刷新清理并自动续跑。已回复的帖子 ID 会跨刷新保存，不会再次回复。每轮 35 条，共 5 轮 175 条后停止。

v1.0.0 重做页面面板：独立显示本轮、轮次、本次执行三组数据，加入当前轮和整体进度条、运行状态、当前话术与重试计数。界面使用“自动发送”描述真实行为，不再显示“等待发送确认”。

v1.1.0 在面板内加入默认展开的 55 条话术池。当前将要发送的话术会升到话术池首位、高亮并播放扫光动画；下次随机切换后，旧项回到原顺序，新项升到首位，形成走马灯效果。话术池可折叠，浏览和折叠不会改变发送顺序。

v1.2.0 新增运行时间统计。从点击开始时计时，每秒更新；每轮刷新页面后继续累计，手动停止或完成 175 条后保留最终用时。

v1.3.0 把进度面板拆成“本次执行”和“当前轮”两个层级：一次执行固定 5 轮、共 175 条，每轮 35 条。开始前可设置每条回复之间的间隔（默认 5 秒）和每轮之间的间隔（默认 60 秒）；等待期间显示倒计时，设置会随当前标签页保存。第 35 条后只计算轮间隔，不再叠加回复间隔。

v1.4.0 将话术池从 55 条扩充到 100 条。所有短词、单字与纯图标回复都改写成更自然的完整句子，并在约四成话术中加入符合语气的 Emoji；同时保留旧话术识别能力，避免升级时已有评论弹窗被误判为手写内容。

v1.5.0 重构面板信息层级：顶部用三个步骤解释“回复一条、完成一轮、完成一次执行”，主体按 ①本次执行、②当前轮、③回复方式、④回复速度、⑤当前回复分区。标题栏新增折叠与放大按钮；折叠后保留轮次和本轮进度，放大后并排展示执行数据并扩大话术池，显示模式会随当前标签页保存。

v2.0.0 新增两种回复方式。默认“模板随机”继续使用 100 条完整话术；“AI 模式”读取当前帖子的 `data-testid="tweetText"` 文字，交给 DeepSeek Flash 生成 15～50 个中文字符的自然回复。DeepSeek API Key 由用户在面板里填写、保存并测试连接，只保存在 Chrome 扩展本地存储。AI 模式会把当前原帖文字发送给 DeepSeek，不会发送 X 登录 Cookie。AI 请求关闭思考模式并设置 10 秒超时，避免等待过久。默认频率改为每条回复后等待 2 秒、每轮完成后等待 5 秒。

每轮成功 35 条后刷新页面，再从顶部继续；完成 5 轮（共 175 条）后自动停止。刷新后会保留本轮进度、已完成轮次和下一条话术。关闭这个标签页会停。

## 安装

1. 打开 Chrome：`chrome://extensions/`
2. 开启「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本目录：

```text
tools/x-reply-clipboard-extension
```

已经装过旧版时，在扩展管理页点这个扩展的刷新按钮。

## 使用

1. 在 Chrome 里登录 X。
2. 打开首页、个人主页或搜索结果。
3. 点击左下角「开始回复」。
4. 选择“模板随机”可直接开始；选择“AI 模式”时，先填写 DeepSeek API Key，保存并点击“测试连接”。
5. 如需调整速度，在开始前修改“每条回复间隔”和“每轮之间间隔”。
6. 需要停止时，点「停止」。

扩展只在当前这个 X 标签页里操作。切到别的标签页会暂停，回到该页后继续。
