# X 时间线回复助手

站内入口：<https://2aran.com/resources/x-reply-clipboard-extension>。工具集的「推特工具」和下载中心都会链到这一页。

本地 Chrome Manifest V3 扩展。在已登录的 X 时间线上，从上往下打开每条帖子的评论弹窗，从固定话术里随机抽一条写进去，再点 Reply。

话术和 macOS 应用「X粘贴板评论助手」是同一组，共 55 条。每次处理完会换下一条，下一条不会和刚用过的那句相同。不读取系统剪贴板。

插件会等待 Reply 真正可点；如果编辑器只显示文字、Reply 仍是灰色，会重新同步一次 X 的编辑器状态再发送。两次发送仍未成功时，插件关闭评论弹窗并点击 `Save`，把已经写好的内容保存在 X 草稿中，不再点 `Discard` 丢掉内容。只有确认评论弹窗已因发送而关闭的回复才计入 35 条。

满 35 条后刷新页面，再从顶部继续，直到点击停止。刷新后会接着累计，并记住下一条话术。关闭这个标签页会停。

## 安装

1. 打开 Chrome：`chrome://extensions/`
2. 开启「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本目录：

```text
tools/x-reply-clipboard-extension
```

已经装过旧版时，在扩展管理页点这个扩展的刷新按钮。

## 使用

1. 在 Chrome 里登录 X。
2. 打开首页、个人主页或搜索结果。
3. 点击左下角「开始回复」。
4. 需要停止时，点「停止」。

扩展只在当前这个 X 标签页里操作。切到别的标签页会暂停，回到该页后继续。
