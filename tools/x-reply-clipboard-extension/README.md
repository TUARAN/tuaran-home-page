# X 时间线回复助手

站内入口：<https://2aran.com/resources/x-reply-clipboard-extension>。工具集的「推特工具」和下载中心都会链到这一页。

本地 Chrome Manifest V3 扩展。在已登录的 X 时间线上，从上往下打开每条帖子的评论弹窗，从固定话术里随机抽一条写进去，再点 Reply。

话术和 macOS 应用「X粘贴板评论助手」是同一组，共 55 条。每次处理完会换下一条，下一条不会和刚用过的那句相同。不读取系统剪贴板。

插件会先核对评论框里的文字与抽中的话术完全一致，再等待 Reply 真正可点。点击 Reply 后等待最多 5 秒确认发送结果。插件不会主动关闭评论弹窗，也不会点击 `Save` 或 `Discard`；这两个按钮只处理草稿，不负责发送回复。没有确认成功时，插件保留当前弹窗、当前帖子和当前话术，不会标记处理完成，也不会滚到下一条。若已经出现本次发送成功提示，但 X 没有自行关闭仍有内容的评论框，插件会把该条计为成功后暂停，避免再次回复。

开始运行时如果页面已有评论弹窗，插件会核对其中的文字。内容与当前话术完全一致时会接着点击 Reply；内容不同则暂停，避免覆盖手写草稿。插件从账号切换按钮或个人资料入口读取当前登录账号，并按帖子永久链接识别作者；自己的帖子、自己刚发出的回复以及无法确认作者的帖子都不会进入回复队列。

写入时以评论框里肉眼可见的文本为准。浏览器输入已经显示完整话术后，不再调用 Draft 内部状态补写，避免同一句被写两遍；发现弹窗里已有重复或残留内容时，会自动全选替换为当前这一条话术，然后点击 Reply，不会停在“内容不一致”。

满 35 条后刷新页面，再从顶部继续，直到点击停止。刷新后会接着累计，并记住下一条话术。关闭这个标签页会停。

## 安装

1. 打开 Chrome：`chrome://extensions/`
2. 开启「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本目录：

```text
tools/x-reply-clipboard-extension
```

已经装过旧版时，在扩展管理页点这个扩展的刷新按钮。

## 使用

1. 在 Chrome 里登录 X。
2. 打开首页、个人主页或搜索结果。
3. 点击左下角「开始回复」。
4. 需要停止时，点「停止」。

扩展只在当前这个 X 标签页里操作。切到别的标签页会暂停，回到该页后继续。
