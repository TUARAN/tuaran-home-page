# X高频互动助手

站内入口：<https://2aran.com/resources/x-reply-clipboard-extension>。工具集的「推特工具」和下载中心都会链到这一页。

版本规则与发版记录格式见 [VERSIONING.md](VERSIONING.md)。本地未打包版本 v3.12.0；公开下载仍为 v3.9.0，以上线页面为准。

本地 Chrome Manifest V3 扩展。面板顶部按以下顺序提供四个 Tab，新安装默认选择时间线：

- **时间线回复**：在已登录的 X 时间线上，从上往下打开他人帖子的评论弹窗并回复。
- **通知回复**：只处理通知页最近 2 小时内别人对当前账号的回复，先点赞，再打开评论弹窗继续回复。单纯的点赞通知不会进入队列；成功处理的通知 ID 会保存在 Chrome 本地，之后不会重复点赞或回复。
- **关注管理**：提供清理未回关、回关粉丝和关注候选三项任务。
- **定时发帖**：只从热点取材，先读取知乎热榜，再读今日头条；素材不足时才读取 2aran 舆情分析的近期热点。参考王长富短帖的节奏写原创短帖，不抓取或改写他的帖子。开头抓具体的人或事，结尾留一点余味；参考近期文案避免同一句式连发。用过的素材 ID 和已发主题保存在 Chrome 本地；待发列表和发布历史保留来源、原始链接及站内选题页。主题重复、语气过火或不合格的素材会跳过。旧版王长富待发草稿不会继续发送。第一条立即发送，之后每条随机间隔 25～35 分钟。

任务会在 X 首页等待发帖框和 Post 按钮真正出现，再发送待发列表的第一条；页面尚在加载时会继续检查，不计为发送失败。

X 提示「You already said that」时，定时发帖会清空这条草稿，跳过当前待发内容并立即尝试下一条。

两个回复助手都使用 DeepSeek 阅读当前帖子后生成回复。

标题栏右上角的四格图标打开「X 工具箱」。在单条推文详情页可将当前推文排版为 PDF，再在打印窗口选择保存；工具箱内可关闭或重新启用导出。原独立的互关清理插件功能已并入「关注管理」；X 长文自动发布保留为独立扩展，单独管理站点密钥和定时任务。

时间线每次先按当前频率挡位生成一份随机计划。轮次进度里可以在慢、中、快、超快之间滑动，默认是「中」：3～5 轮，每轮 25～35 条；每条成功后随机等待 5～15 秒，整次完成后随机休息 2～3 小时再生成下一份计划。通知回复使用同一套挡位决定每条间隔和扫描后的休息，并继续使用持久历史去重。已经开始的计划和正在进行的等待不会因为改挡位而改写。插件不对时间线和通知回复设置每日总量。页面暂时不可用时从 2 秒开始逐步重试，最长间隔 30 秒；网络恢复事件会立即唤醒重试。标题栏显示整个插件从任一任务启动后累计的稳定运行时长，各任务单独显示自己的运行时间；只有最后一个任务停止或对应任务页签关闭时，整体计时才结束。

## 安装

1. 打开 Chrome：`chrome://extensions/`
2. 开启「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本目录：

```text
tools/x-reply-clipboard-extension
```

已经装过旧版时，在扩展管理页点这个扩展的刷新按钮。

## 使用

1. 在 Chrome 里登录 X。
2. 面板默认浮在页面右下角。标题栏齿轮里可以打开「嵌入到页面」，再挂到右侧搜索框下方。默认打开时间线回复；顶部依次可切换时间线回复、通知回复、关注管理或定时发帖。
3. 互关任务按提示打开 Following / Followers 列表；回复任务点击对应的开始按钮。
4. 首次运行先填写 DeepSeek API Key；配置后主面板收起密钥栏，可在右上角设置修改。
5. 工作区的滑块选择慢、中、快或超快。每一挡的具体数字、回复提示词、发推提示词和 DeepSeek API Key 都在右上角设置里修改，改动自动保存。
6. 需要停止时，点「停止」。
7. 要在后台看到回执，打开 `/admin/community-actions`，把回执密钥贴到设置里的「社区回执」。不填则不上传。

「定时发帖」只发送纯文字。先取知乎热榜，再取今日头条；两者素材不足时才读 2aran 舆情分析。生成后放进待发列表，列表没发完不会重新抓取。正文排成短行，每行之间空一行；面板显示下一次发布倒计时，默认「中」是 25～35 分钟。发帖框已有其他内容时等待人工处理。

「关注候选」每次从 @crazypig9y、@jianlvup、@jianlvya、@kyotom08、@Chill_Alpha 里随机打开一个 Followers 页面。「清理未回关」「回关粉丝」和「关注候选」共用同一组额度：每 2 秒操作 1 个，三项合计每完成 15 个暂停 30 分钟，每日合计最多 400 个。今日数量、本批进度和暂停时间保存在 Chrome 扩展本地存储中，并按本地日期重置。

扩展只操作启动任务的 X 标签页。时间线回复、通知回复和定时发帖各自使用一个窗口。关注管理的清理未回关、回关粉丝和关注候选再各自使用一个窗口。从顶部点开关注管理会打开这三个窗口；点其中一项只打开或切到对应窗口。原来的窗口仍停在它的当前页上，任务继续跑。不要把两个任务放进同一个窗口的不同页签，Chrome 会冻住被盖住的后台页签。也不要关闭、丢弃或手动刷新正在执行任务的窗口。

面板中的每条间隔从发送成功后开始，按当前挡位随机抽取并计算，不包含 AI 生成、弹窗出现、编辑器写入和发送确认所需的时间。默认「中」是 5～15 秒。出现重试时，总耗时会继续增加；v3.2.0 已缩短单步超时并减少后台计时消息，避免 v3.1.6 在前台也被离屏轮询拖慢。
