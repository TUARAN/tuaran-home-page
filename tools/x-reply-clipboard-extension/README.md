# X高频互动助手

站内入口：<https://2aran.com/resources/x-reply-clipboard-extension>。工具集的「推特工具」和下载中心都会链到这一页。

文档中心：<https://2aran.com/resources/x-reply-clipboard-extension/docs>。面板中的规则入口会打开对应章节。

版本规则与发版记录格式见 [VERSIONING.md](VERSIONING.md)。当前本地源码为 v4.0.30；站内下载包为 v3.32.46，下载要求联系站长获取密码。

任务机制、运行状态和异常恢复以站点「文档中心」为统一入口；本 README 保留安装说明、开发记录和完整版本历史。

站长在 `/admin/community-actions?tab=extension` 的「X 高频互动助手」卡片生成新下载密码。新密码立即生效，旧密码失效；后台只保存校验值，明文仅在生成时显示一次。本次站点管理功能不改变扩展版本号。

本地 Chrome Manifest V3 扩展。面板顶部提供四个分组，新安装默认选择评论管理的评论帖子：

v4 全流程由后台统一排班：同一 Chrome 配置文件的一个 X 账号最多保留一个执行页签，八项任务到期后轮流占用。总开关下方的排班台按「上一任务 / 当前任务 / 下一任务」展示轮班历史、当前执行与预计可运行时间；点击任务只看详情，另设「打开当前执行页签」。面板“排班设置”可调整任务参与、优先级、时段和单次占用时间。

- **评论管理**：评论帖子与评论通知分别按排班设置的速度档位生成本次轮次与每轮次数；完成全部轮次后让位。评论通知扫描未处理的回复，不再限定最近 2 小时；@grok 通知跳过。疑似自动化限制时按 10、20、30 分钟递增倒计时，并先让其他任务运行。
- **点赞管理**：点赞帖子和点赞评论分别按速度档位生成本次轮次与每轮次数，确认成功才计数；完成本次计划或遇频率限制时让位。已确认的点赞历史独立保存。
- **关注管理**：回关粉丝默认在北京时间 22:00–次日 06:00 处理，每确认 15 个冷却 30 分钟，夜间到期后继续；清理未回关约每 7 天排一轮，两项单次占用共享页签最长约 10 分钟；关注候选暂时折叠并停用，不会随全流程启动。
- **定时发帖**：先读知乎和今日头条；模型都未写出正文时补充 AI HOT；最后轮换常用社会观察。每轮准备一条并保存待发列表。新帖子按条随机选择格式：20% 概率附带原创背景文字卡片，40% 为原篇幅纯文字，40% 为精简纯文字。精简稿目标约 35～60 字、3～4 个短行，每行之间留一个空行。抽取结果随待发稿保存，重试不变。默认提示词要求先交代具体事件，再情绪化只站一边表态：讨厌、反对、无语要明说，禁止正反拆开；不得虚构长期持有者、回本等素材没有的经历，也不补空泛赞叹。旧抽象插画仍停用；如果发帖框已有图片，会等待人工确认或移除，防止误发。模型服务异常时检查本地社会观察兜底。发推不抓取或改写王长富的帖子。第一条立即发送，之后按所选频率等待，并按北京时间波浪加密（早 7–10、午 12:30–13:30、晚 18–22 更密，其他时段更疏）；X 提示重复时跳过该条。

v3.1.6 重新排列顶部功能导航：时间线置于第一位并作为默认项，其后依次为通知回复和互关浇友。移除 DeepSeek 测试连接按钮及相关状态，只需保存 API Key 即可直接运行。三类任务的等待由扩展离屏计时 Worker 负责，即使 X 标签页处于后台，也能继续唤醒任务；页面计时仅作为旧版 Chrome 的兼容回退。

v3.1.5 取消“切到其他浏览器页签就暂停”的限制。时间线回复、通知回复和互关任务在 X 页签处于后台时仍会继续；回复间隔、批次暂停和超时全部按真实时间截止计算，不会因为后台定时器降频而从切回页面后重新等待。

v3.1.4 将通知回复从时间线轮次中拆开。通知模式只扫描最近 2 小时内的回复通知，处理完或遇到时间边界后停止，不再执行 35 条一轮、5 轮 175 条的刷新流程。成功点赞并回复的通知 ID 持久保存在 Chrome 本地，刷新页面、重新打开浏览器或再次运行时都会跳过。

v3.1.3 统一「回关粉丝」与「关注候选」的关注频率和额度：两个功能共同按每 2 秒一个、每 15 个暂停 30 分钟运行，并共享每日 400 个的总额度、本批进度和暂停截止时间。切换功能或刷新页面不会重新计数或绕过暂停。

v3.1.2 重建面板的信息层级：顶部加入明确的「功能导航」，开始或执行按钮移动到当前工作区的首要位置；回复方式和频率限制合并进默认折叠的「运行设置」。时间线回复在新安装时默认使用 AI 模式，用户手动保存的模板选择仍会保留。

v3.1.1 将互关区的三项功能改为独立子 Tab。点击「清理未回关」会打开自己的 Following 页面，点击「回关粉丝」会打开自己的 Followers 页面；「关注候选」不会自动跳转，需要先手动打开其他作者的 Followers 页面。标题栏同步改成适配窄面板的紧凑布局。

v3.1.0 将原「X 互关清理助手」并入统一面板，形成「互关浇友」Tab。原有清理未回关、回关粉丝和关注候选三项任务完整保留；任一任务执行时锁定其他 Tab，防止页面与操作目标错位。旧互关插件页面永久跳转到本页，不再单独安装旧包。

时间线回复达到当前轮随机目标后刷新页面，再从顶部继续；完成本次随机轮数后按当前挡位休息，默认「中」是 2～3 小时。刷新后会保留本次计划、本轮进度、已完成轮次和下一条话术。通知回复没有轮次，只处理最近 2 小时内尚未成功互动的回复通知，处理完后按同一挡位休息。关闭对应任务标签页会停止该任务。

## 安装

1. 打开 Chrome：`chrome://extensions/`
2. 开启「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本目录：

```text
tools/x-reply-clipboard-extension
```

已经装过旧版时，在扩展管理页点这个扩展的刷新按钮。

## 使用

1. 在 Chrome 里登录 X。
2. 面板默认浮在页面右下角。标题栏齿轮里可以打开「嵌入到页面」，再挂到右侧搜索框下方。顶部依次是评论管理、点赞管理、关注管理、定时发帖；点分组内的子页签会切到对应任务窗口。
3. 互关任务按提示打开 Following / Followers 列表；回复和点赞任务在各自窗口点击开始按钮。
4. 首次运行先填写 DeepSeek API Key；配置后主面板收起密钥栏，可在右上角设置修改。
5. 工作区的单行按钮选择慢、中、快或超快。每一挡的具体数字在「频率设置」里修改；提示词和 API Key 在「模型设置」里修改，改动自动保存。
6. 需要停止时，点「停止」。
7. 要在后台看到回执，打开 `/admin/community-actions`，把回执密钥贴到设置里的「社区回执」。不填则不上传。
8. 在右上角展开操作菜单，打开「每日报告」。可按账号查看本机已存记录的累计统计，也可在月历选日期查看当天五项数字；选定单个账号后点「上传当日报告」会发送到后台「社区动作 → 浏览器插件」。需先应用 `0112_x_extension_daily_reports.sql`。重复上传同一天会更新该天汇总；「一键清空状态」保留本机报告和限制观察日志。

## 长时间运行与锁屏排查（2026-10-18）

这台 Mac 的接电源配置经 `pmset -g custom` 核对为 `sleep 0`、`displaysleep 10`：接电时允许显示器约 10 分钟后关闭，系统不因空闲自动睡眠。锁屏设置没有改动。屏幕关闭或锁定本身不等于系统睡眠；合盖、手动睡眠、断电、Chrome 退出或任务标签页停用仍可能中断自动化。检查时 `pmset -g batt` 同时显示 `AC Power` 和电池「discharging」，因此还要核对电源适配器、连接及之后的电量变化，不能仅凭接电源配置认定机器能持续运行。

Chrome「Aran」配置文件已在 `chrome://settings/performance` 核对：省内存模式原本关闭；2026-10-18 关闭了节能模式，并将 `x.com` 加入「始终让以下网站保持活跃状态」。需要保持 Chrome、扩展和已登录的 X 任务标签页打开。Chrome 设置仅减少后台标签页被节能策略停用的机会，不能唤醒已睡眠的 Mac，也不能保证 X 页面和登录态始终可用。

复盘时先在插件中启动任务，锁屏观察一段时间，再打开后台「社区动作 → X 插件监控」（`/admin/community-actions/x-monitor`）比较最近心跳、任务状态、最近确认动作和最近异常。该页面上线后才可从线上访问；本地代码存在不代表线上已部署。「有心跳」只说明插件近期能连接后台，不能单独证明任务持续执行；若心跳仍在而确认动作长期不变，应结合任务的等待截止时间、X 登录态和异常回执排查。超过 5 分钟没有心跳，先检查 Mac 是否睡眠或电池耗尽、Chrome 是否仍在运行、扩展和 X 标签页是否打开、回执密钥及网络连接。

扩展的长等待由离屏计时器处理，后台心跳通过 Chrome alarm 定期触发；这些机制均不能唤醒已经睡眠的设备。参考：[Apple 的睡眠与锁屏说明](https://support.apple.com/en-ie/guide/mac-help/mchle41a6ccd/mac)、[Chrome 始终保持网站活跃](https://support.google.com/chrome/answer/12929150)、[Chrome alarms 限制](https://developer.chrome.com/docs/extensions/reference/api/alarms)。

「定时发帖」按条选择 20% 文字配图、40% 原篇幅纯文字、40% 精简纯文字；文字配图有四种轮换版式。先取知乎和今日头条，AI HOT 作为补充；热点都没有可用素材时切换常用社会观察池。生成后放进待发列表，列表没发完不会重新抓取。正文段间留空行；面板显示下一次发布倒计时，默认「中」基础间隔 25～35 分钟，再按北京时间波浪加密（早 7–10、午 12:30–13:30、晚 18–22 更密，其他时段更疏）。发帖框已有其他内容时等待人工处理。

「关注候选」每次从 @crazypig9y、@jianlvup、@jianlvya、@kyotom08、@Chill_Alpha 里随机打开一个 Followers 页面。「清理未回关」每次操作后间隔 2 秒，不计入关注共享额度；遇到 X 限速提示暂停 15 分钟，并显示倒计时。「回关粉丝」与「关注候选」共用额度：每 2 秒操作 1 个，合计每完成 15 个暂停 30 分钟，每日合计最多 400 个。关注的今日数量、本批进度和暂停时间保存在 Chrome 扩展本地存储中，并按本地日期重置。

扩展只操作启动任务的 X 标签页。评论管理的两项、点赞管理的两项、定时发帖以及关注管理的三项各用一个任务窗口。点子页签会打开尚未创建的任务窗口，已打开则跳转；原窗口仍停在自己的页面，正在运行的任务继续跑。具体任务子页签的箭头表示跳转，悬停时旁边出现独立叉号，可关闭该任务窗口。不要把两个任务放进同一个窗口的不同页签，Chrome 会冻住被盖住的后台页签。也不要手动刷新正在执行任务的窗口。

面板中的每条间隔从发送成功后开始，按当前挡位随机抽取并计算，不包含 AI 生成、弹窗出现、编辑器写入和发送确认所需的时间。默认「中」是 5～15 秒。出现重试时，总耗时会继续增加；v3.2.0 已缩短单步超时并减少后台计时消息，避免 v3.1.6 在前台也被离屏轮询拖慢。
