# X Reply Clipboard

本地 Chrome Manifest V3 扩展。在已登录的 X 时间线上，从上往下打开每条帖子的评论弹窗，把当前剪贴板粘进去，再点 Reply。

满 35 条后刷新页面，再从顶部继续，直到点击停止。刷新后会接着累计，关闭这个标签页会停。

每一轮都会重新读取剪贴板。如果旁边开着剪贴板短语工具，回复间隔大约 2 秒，方便它切到下一条。

## 安装

1. 打开 Chrome：`chrome://extensions/`
2. 开启「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本目录：

```text
tools/x-reply-clipboard-extension
```

## 使用

1. 在 Chrome 里登录 X。
2. 打开首页、个人主页或搜索结果，把要回复的文字复制到剪贴板。
3. 点击左下角「开始回复」。
4. 需要停止时，点「停止」。

扩展只在当前这个 X 标签页里操作。切到别的标签页会暂停，回到该页后继续。
