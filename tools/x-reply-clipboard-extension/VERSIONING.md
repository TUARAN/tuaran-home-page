# X 高频互动助手版本与发版记录

1. **版本号与发布分开。** `manifest.json` 的 `version` 是当前可安装代码的唯一版本号；公开下载页和 ZIP 只表示已发布版本。未打包也可以升版，打包本身不触发升版。只改文档不升版。
2. **按交付节点升版。** 开发中的多次修改先归在同一批；准备交给人加载、测试或发布时，先验证，再升版并记录。交付过的版本内容冻结；之后改行为，即使未打包，也用新版本号。不得出现同号不同代码。
3. **按影响选号码。** 兼容修复升 PATCH（`3.6.58 → 3.6.59`）；新增兼容功能升 MINOR（`3.6.58 → 3.7.0`）；破坏已有设置或使用方式升 MAJOR（`3.x → 4.0.0`）。只用 Chrome 接受的三段数字，不用 `-beta` 后缀。
4. **记录两次状态。** 每个交付版本在 [README.md](README.md) 写一条：`vX.Y.Z（YYYY-MM-DD，本地测试）做了什么、用户受什么影响`。打包后记文件名与 SHA-256；公开下载真正可用后，把同一条标为“已发布”，补发布日期和对应提交或 Git 标记。未可下载不得写“已发布”。
5. **发版前核对。** 测试通过；`manifest.version`、面板版本、ZIP 文件名与 ZIP 内版本一致；上传完成且下载可用，再更新公开页面和资源目录。修订已发布 ZIP 必须另升版。

历史版本说明保留在 [README.md](README.md)；旧记录缺少的日期或哈希不追填猜测值。`3.12.1` 已打包，公开下载状态以线上页面验收为准。
