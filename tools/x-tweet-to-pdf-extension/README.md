# X Tweet to PDF

一个本地运行的 Chrome / Edge Manifest V3 扩展，把当前打开的 X（Twitter）推文整理成适合 A4 打印的页面，再通过浏览器原生打印功能保存为 PDF。

## 功能

- 提取当前推文的作者、账号、正文、发布时间和原文链接。
- 最多保留 4 张推文图片。
- 尽可能保留回复、转发、喜欢、浏览等页面当前可见统计。
- 独立排版页，不带 X 的侧栏、推荐和评论区。
- 全程在浏览器本地处理，不上传推文内容。
- 支持 `x.com` 与 `twitter.com`。

## 安装

1. 在 Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
2. 开启「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本目录：

```text
tools/x-tweet-to-pdf-extension
```

## 使用

1. 登录 X，点击并进入一条推文的详情页，网址应包含 `/status/数字`。
2. 点击浏览器工具栏中的扩展图标。
3. 点击「提取当前推文」。
4. 在新打开的排版页检查内容，点击「打印 / 保存 PDF」。
5. 在系统打印窗口中把目标打印机改为「另存为 PDF」，推荐关闭页眉和页脚。

## 文件说明

- `content.js`：在 X 页面中定位并提取当前推文。
- `popup.*`：扩展弹窗及操作入口。
- `print.*`：A4 排版、预览及打印入口。
- `manifest.json`：Chrome Manifest V3 配置。

## 当前限制

- 只导出当前详情页的主推文，不自动抓取整条回复串或线程。
- X 改版后 DOM 选择器可能变化；核心选择器集中在 `content.js` 中。
- 视频不会下载到 PDF，只保留正文及页面中可识别的静态图片。
