## 准备

1. 安装官方 WorkBuddy，并记录你的系统类型与 WorkBuddy 版本。
2. 从 https://github.com/comeonzhj/WorkBuddy-theme-skill/releases 获取上游 Theme Manager 对应平台版本。管理器为免费开源软件，不包含在主题售价中。
3. 请先保存正在进行的工作。不要向任何人提供账号密码、验证码、令牌或私人对话。
4. 若系统提示安装风险，请先核对发行者、来源和上游安全说明；不要为安装主题全局关闭系统保护。

## 导入

1. 打开 Theme Manager，选择“导入主题包”。
2. 选择一个 `2aran-*-1.0.0.zip` 文件，等待管理器验证完成。
3. 按主题的 light / dark 模式选择对应的 WorkBuddy 浅色或深色外观，然后应用主题。
4. 首次应用可能需要重启 WorkBuddy。请确认任务已保存，再同意管理器的重启提示。
5. 在主题库中选择其他主题即可切换。查看输入框、菜单、任务列表、代码和终端是否清晰可读。

## 恢复

在 Theme Manager 选择“恢复原生主题”。如界面显示异常，优先恢复再反馈；不要修改 WorkBuddy 安装目录、签名或 `app.asar`。如恢复按钮不能使用，请按上游 README 的恢复说明操作。
